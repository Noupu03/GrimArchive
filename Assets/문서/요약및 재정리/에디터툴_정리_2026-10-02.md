# 유니티 커스텀 에디터 기능 정리 (2026-10-02)

## 범위와 판정 기준

- 대상: `Assets/Editor`, `Assets/Script/Editor`, `Assets/Script/Wave/Editor`, `Assets/Haare/Editor`,
  `Assets/VFX/Shader/Editor`의 에디터 스크립트 38개, 그리고 런타임 스크립트에 있는 `[CreateAssetMenu]` 7개와
  `[ContextMenu]` 1개.
  (`Assets/문서/구본훈/취미생활/**/Editor`는 `.txt` 사본뿐이라 컴파일되지 않으므로 제외)
- 실제로 얼마나 자주 눌렀는지는 알 수 없다. 그래서 **코드와 에셋의 현재 상태**로 판정했다.
  - **사용 중** — 자동으로 돌거나(InitializeOnLoad, 인스펙터), 현재 게임 파이프라인이 그 결과물에 의존하거나,
    현재 코드와 맞물려 정상 동작하는 디버그 도구.
  - **미사용** — 대상이 사라졌거나, 고장 났거나, 이미 적용이 끝나 다른 도구가 같은 일을 대신하거나,
    현재 상태와 반대 방향으로 작동하는 것.
  - **굳이** — 돌리면 동작하지만 지금은 쓸 일이 없거나(1회성 작업 완료), 더 나은 경로가 따로 있는 것.
- 한 기능이 여러 칸에 걸칠 수 있다(중복 허용).

표기: ✅ 사용 중 / ❌ 미사용 / 🔶 사용 가능하지만 굳이 / ⚠️ 실행 시 주의 / 🗑️ 1차 제거됨

## 1. 현재 사용되는 기능 (✅)

### 게임 파이프라인이 결과물에 의존하는 것

- **Map Generator** — `Assets/Editor/MapGeneratorTool.cs`
  `GameSession.Initialize`가 `Resources/Data/map.json`을 읽고, 없으면 "Map Generator에서 먼저 맵을
  생성해주세요" 오류를 내고 맵 없이 시작한다. 이 파일을 만드는 경로는 이 창뿐이다(`map.json` 10-02 갱신).

- **JSON → 유닛 프리팹 생성** — `Assets/Editor/JsonToUnitPrefabConverter.cs`
  `units.json`/`skills.json`으로 `Resources/Units/` 16종 프리팹을 만든다. 16종 모두 `units.json`에 있다.
  ⚠️ **프리팹을 루트부터 새로 만든다.** 다시 실행하면 JSON에 없는 아래 항목이 사라진다.
  - 보스 골렘의 `LeftHand`/`RightHand` 자식, `BossGolemHandController`, **손 스프라이트 2장(수동 지정값)**
  - 보스 골렘의 `visualScaleIgnoresFootprint = 1`
  - 그 밖에 인스펙터에서 직접 고친 값 전부

  다시 실행했다면 16·17번 도구를 실행하고 손 스프라이트를 다시 지정해야 한다.

- **타이틀 씬 생성 / 설정 패널 생성 / 키 가이드 패널 생성**
  `Title.unity`와 `GrimArchive_TitlePanel`·`GrimArchive_SettingsPanel`·`GrimArchive_KeyGuidePanel` 프리팹이
  이 코드의 출력물이다(전부 08-26). UI를 고치려면 코드를 고치고 다시 실행하는 구조라 원본으로서는 사용 중이다.
  다만 UI를 고칠 일이 없으면 평소엔 실행할 일이 없다(🔶 겹침). 키 가이드 문구는 `GameInputScheme.cs`를
  손으로 옮겨 적은 것인데, 08-26 이후 입력 키가 바뀌지 않아 지금 문구는 맞다.

- **맵 타일 색상 테마** — `Assets/Editor/MapColorThemeWindow.cs`
  `Resources/Themes/` 프리셋 2개와 `MapColorTheme_FloorAssignments.asset`을 편집한다.

### 자동으로 도는 것

- **Addressables: Use Asset Database** — `Assets/Script/Editor/AddressablesPlayModeSetup.cs`
