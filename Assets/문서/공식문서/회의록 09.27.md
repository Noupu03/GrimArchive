### 벽 타일 자동 연결 구현안

벽은 하나의 타일맵 위에서 배치하며, 주변 벽 타일의 연결 상태를 확인해 자동으로 적절한 스프라이트로 교체한다.

필요한 기본 벽 스프라이트는 총 10종이다.

1. 직선 벽
- `Wall_Horizontal` : 가로 벽
- `Wall_Vertical` : 세로 벽

2. 바깥쪽 모서리
- `Wall_Outer_TL`
- `Wall_Outer_TR`
- `Wall_Outer_BL`
- `Wall_Outer_BR`

벽이 바깥 방향으로 꺾이는 일반적인 코너에 사용한다.

3. 안쪽 모서리
- `Wall_Inner_TL`
- `Wall_Inner_TR`
- `Wall_Inner_BL`
- `Wall_Inner_BR`

벽 내부가 파인 형태의 코너에 사용한다.

### 판정 방식

각 벽 타일은 주변 8방향을 검사한다.

```text
NW  N  NE
 W  X   E
SW  S  SE
```

`X`가 현재 벽 타일이다.

상·하·좌·우 연결 상태로 기본 방향을 판정하고, 대각선 상태를 추가로 확인하여 안쪽/바깥쪽 모서리를 구분한다.

즉 판정에 사용하는 값은:

```text
N
S
E
W

NE
NW
SE
SW
```

8개이다.

특히 안쪽 모서리는 대각선 판정이 반드시 필요하다.

예를 들어 주변 벽이 연결되어 있더라도 특정 대각선 공간이 비어 있다면 해당 방향에 `Inner Corner`를 표시한다.

### 구현 구조

Unity 기준으로는 두 방식 중 하나를 사용한다.

```text
Tilemap
 └ WallTile
     └ 주변 8방향 확인
         └ 연결 상태 계산
             └ 대응 Sprite 선택
```

가능하면 `RuleTile` 또는 RuleTile과 유사한 커스텀 타일 시스템으로 구현한다.

그래픽에서 별도로 위치를 지정하는 것이 아니라, 레벨 제작자는 벽 타일만 배치하고 실제 벽 모양은 시스템이 자동 결정하도록 한다.

### 그래픽 에셋 규칙

모든 벽 스프라이트는 다음 기준을 통일한다.

- 동일 PPU
- 동일 Pivot 기준
- 동일 Logical Cell Size
- 동일 Sorting Layer
- 동일 Order 기준
- 타일 기준점 동일

중요한 점은 **스프라이트 실제 이미지 크기와 타일의 논리 크기를 분리하는 것**이다.

현재처럼 벽 이미지가 셀 영역 밖으로 돌출되어도 상관없다.

```text
Logical Tile
┌──────┐
│      │
│ CELL │
│      │
└──────┘

Sprite
   ┌───────────
   │ 벽 그래픽
┌──┴───┐
│ CELL │
└──────┘
```

즉 타일맵상의 좌표는 동일한 크기를 사용하고, 벽 스프라이트만 셀 바깥으로 시각적으로 확장한다.

### 방향 규칙

파일명의 방향은 반드시 하나의 기준으로 통일한다.

추천 기준:

`TL / TR / BL / BR`은 **모서리가 위치한 방향**을 의미한다.

```text
TL = Top Left
TR = Top Right
BL = Bottom Left
BR = Bottom Right
```

Outer와 Inner 모두 동일한 규칙을 사용한다.

### 우선순위

자동 판정 시에는 대략 다음 순서로 처리한다.

```text
1. Inner Corner 판정
2. Outer Corner 판정
3. Horizontal / Vertical 판정
4. 예외 상태 처리
```

안쪽 모서리를 먼저 보는 이유는 단순 상하좌우 연결만 검사하면 직선이나 일반 코너로 잘못 판정될 수 있기 때문이다.

### 현재 구현 범위

우선은 아래 10종만 구현한다.

```text
Wall_Horizontal
Wall_Vertical

Wall_Outer_TL
Wall_Outer_TR
Wall_Outer_BL
Wall_Outer_BR

Wall_Inner_TL
Wall_Inner_TR
Wall_Inner_BL
Wall_Inner_BR
```

벽 끝부분이나 T자형, 십자형 연결은 현재 필요하지 않으면 제외한다.

추후 구조상 필요할 경우에만 다음을 추가한다.

```text
Wall_End_T
Wall_End_B
Wall_End_L
Wall_End_R

Wall_T_T
Wall_T_B
Wall_T_L
Wall_T_R

Wall_Cross
```

핵심은 **“벽 스프라이트 10개를 받아 배치하는 기능”이 아니라, 벽 셀 하나를 배치하면 주변 연결 상태에 따라 10종 중 적절한 모양을 자동으로 선택하는 시스템**으로 구현하는 것이다.
