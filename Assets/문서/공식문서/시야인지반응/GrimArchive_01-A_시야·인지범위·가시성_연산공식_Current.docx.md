# **01-A\_시야·인지범위·가시성\_연산공식\_Current**

v0.2 / 연산공식 문서

# **0\. 개요**

본 문서는 시야 범위, 인지 범위, 시야 방향, 공격 후 가시성 상승, 특수 원형 인지 범위와 관련된 기본 연산 기준을 정의한다.

# **1\. 기본 변수**

| 변수/값 | 기준 |
| :---- | :---- |
| 감지 스탯 최대값 | 100 |
| 기본 시야각 | 120도 |
| 기본 시야 거리 | 6칸 |
| 기본 인지각 | 60도 |
| 최대 인지각 | 120도 |
| 기본 인지 거리 | 4칸 |
| 가시성 범위 | 0\~100 |
| 공격 후 가시성 상승량 | \+10 |
| 공격 후 가시성 상승 지속시간 | 5초 |
| 기습 방향 시야 전환 기준 | 현재 근접 유닛 공격 기대값의 2배 이상 |
| 원형 인지 범위 적용 대상 | 엘리트 / 네메시스 / 보스 |

# **2\. 시야 거리 공식**

시야 거리는 기본 6칸이다. 감지 스탯 20마다 1칸씩 증가한다.

| 시야 거리 \= 기본 시야 거리 6칸 \+ 감지 스탯 20마다 1칸 증가 |
| :---- |

| 감지 스탯 | 시야 거리 |
| :---- | :---- |
| 0\~19 | 6칸 |
| 20\~39 | 7칸 |
| 40\~59 | 8칸 |
| 60\~79 | 9칸 |
| 80\~99 | 10칸 |
| 100 | 11칸 |

시야각은 감지 스탯에 의해 증가하지 않는다. 시야각은 120도로 고정된다.

# **3\. 인지 거리 공식**

인지 거리는 기본 4칸이다. 감지 스탯 20마다 1칸씩 증가한다.

| 인지 거리 \= 기본 인지 거리 4칸 \+ 감지 스탯 20마다 1칸 증가 |
| :---- |

| 감지 스탯 | 인지 거리 |
| :---- | :---- |
| 0\~19 | 4칸 |
| 20\~39 | 5칸 |
| 40\~59 | 6칸 |
| 60\~79 | 7칸 |
| 80\~99 | 8칸 |
| 100 | 9칸 |

# **4\. 인지각 공식**

인지각은 기본 60도다. 감지 스탯 10마다 6도씩 증가한다. 최대 120도까지 증가한다.

| 인지각 \= 기본 인지각 60도 \+ 감지 스탯 10마다 6도 증가 인지각 최대값 \= 120도 |
| :---- |

| 감지 스탯 | 인지각 |
| :---- | :---- |
| 0\~9 | 60도 |
| 10\~19 | 66도 |
| 20\~29 | 72도 |
| 30\~39 | 78도 |
| 40\~49 | 84도 |
| 50\~59 | 90도 |
| 60\~69 | 96도 |
| 70\~79 | 102도 |
| 80\~89 | 108도 |
| 90\~99 | 114도 |
| 100 | 120도 |

인지각이 120도에 도달하면 시야각과 같아진다. 이 경우 시야 범위 전체가 인지 범위화된다.

# **5\. 시야 범위 판정**

시야 범위는 유닛 정면 방향을 기준으로 하는 원뿔이다.

대상 타일 또는 대상 점유 영역이 시야 원뿔과 조금이라도 겹치면 시야 범위 안에 들어온 것으로 판정한다.

타일 전체가 시야 범위에 들어올 필요는 없다. 

# **6\. 인지 범위 판정**

인지 범위는 유닛 정면 방향을 기준으로 하는 내부 원뿔이다.

대상 타일 또는 대상 점유 영역이 인지 원뿔과 조금이라도 겹치면 인지 범위 안에 들어온 것으로 판정한다.

타일 전체가 인지 범위에 들어올 필요는 없다.   
대상의 일부만 인지 범위와 겹쳐도 인지 판정 대상이 된다.

# **7\. 시야 범위 내 임시 위험도/흥미도 공식**

시야 범위 안에 들어온 타일은 다음 기준을 따른다.

| 조건 | 임시 위험도 | 임시 흥미도 | 처리 |
| :---- | :---- | :---- | :---- |
| 시야 범위 안에 있음 \+ 인지 범위 밖에 있음 \+ 빈 타일 | \+0 | \+0 | 미확인 타일 위험도/흥미도 유지 |
| 시야 범위 안에 있음 \+ 인지 범위 밖에 있음 \+ 비어 있지 않은 타일 | \+5 | \+5 | 경로와 탐색 방향 판단에만 사용 |
| 인지 범위 안에 들어옴 | 제거 | 제거 | 인지 성공/실패 판정으로 전환 |

임시 위험도/흥미도는 저장값이 아니다. 현재 경로와 탐색 방향 판단에만 사용한다.

# **8\. 정확한 인지 조건**

정확한 인지는 인지 범위 안에서 인지 성공 판정이 발생했을 때만 가능하다.

| 정확한 인지 조건 1\. 대상이 인지 범위 안에 있음 2\. 대상이 완전 차단 구조 뒤에 있지 않음 3\. 인지 성공 판정 발생 |
| :---- |

정확한 인지가 발생하면 대상 유형을 판별하고, 대상 유형에 맞는 행동 후보를 등록할 수 있다.

# **9\. 공격에 따른 가시성 상승 처리**

공격한 유닛, 공격 기능을 가진 방어 건물은 고정 시간 동안 가시성이 상승한다.

| 항목 | 값 |
| :---- | :---- |
| 공격 1회당 가시성 상승량 | \+10 |
| 가시성 상승 지속시간 | 5초 |
| 지속시간 내 추가 공격 | 지속시간을 다시 5초로 초기화 |
| 가시성 최대치 | 100 |

공격한 유닛, 공격 기능을 가진 방어 건물의 가시성이 이미 100에 도달한 경우 추가 공격으로 더 상승하지 않는다.

# **10\. 비벽 오브젝트/유닛 가림 보정**

벽 또는 완전 차단 오브젝트 뒤 대상은 시야 판정이 불가능하다.

비벽 오브젝트 또는 유닛이 같은 시야 경로에 있을 경우 가림 보정을 적용한다.

| 가림 보정 기본 규칙 1\. 관찰자와 대상 사이에 비벽 오브젝트 또는 유닛이 있음 2\. 해당 오브젝트/유닛이 시야 경로 일부를 가림 3\. 뒤쪽 대상의 최종 가시성에서 가림 보정값을 차감 |
| :---- |

가림 보정값의 세부 산식은 05-A\_은신·가시성\_스테이터스연동\_연산공식\_Current에서 다룬다.

# **11\. 시야 방향 전환 우선순위**

시야 방향은 현재 유닛이 바라보는 방향이다.   
시야 방향 전환 후보는 아래 표의 상황 조건을 만족할 때 등록된다.   
여러 후보가 동시에 등록되면 우선순위가 가장 높은 후보를 최종 시야 방향으로 확정한다.   
방향 정보가 없거나, 대상이 사라졌거나, 현재 행동 때문에 적용할 수 없는 후보는 우선순위 비교에서 제외한다.   
최종 시야 방향이 확정되면 해당 방향을 기준으로 시야 범위와 인지 범위를 다시 계산한다. 

| 우선순위 | 상황 | 시야 방향 |
| :---- | :---- | :---- |
| 1 | 스킬 사용 중 | 스킬 사용 방향 |
| 2 | 고위험 기습 피격 | 기습 방향 |
| 3 | 1칸 이내 근접 전투 대상 존재 | 근접 대상 방향 |
| 4 | 현재 공격 대상 존재 | 현재 공격 대상 방향 |
| 5 | 리더 명령  | 명령 대상 방향 |
| 6 | 일반 기습 피격 | 기습 방향 |
| 7 | 소리 감지 | 소리 발생 방향 |
| 8 | 확인이 필요한 비어있지 않은 타일 또는 경로 재설정 지점 | 해당 타일 방향 |
| 9 | 경계 상태 | 경계 대상 방향 |
| 10 | 이동 중 | 이동 방향 |

스킬 사용 중에는 스킬 사용 방향을 바라본다.

전투 중 1칸 이내 근접 적이 있을 경우 기본적으로 근접 대상 방향을 유지한다.

고위협 기습 피격은 기습 피해 기대값 또는 실제 피해가 현재 근접 유닛 공격 기대값의 2배 이상인 경우를 말한다.

이 경우 1칸 이내 근접 전투 대상이 있더라도 기습 방향을 우선 확인한다.

일반 기습 피격은 위 조건을 만족하지 않는 기습 피격이다.

이 경우 1칸 이내 근접 전투 대상이 있으면 근접 대상 방향 유지가 우선된다.

같은 우선순위의 시야 방향 전환 후보가 여러 개 등록된 경우, 기존 시야 방향에 가장 가까운 후보를 우선한다. 

플레이어의 명령에 대한 시야 전환은 항상 최우선 순위가 된다.

# **12\. 소리 방향에 따른 시야 방향 갱신**

소리 감지 시 소리 방향은 시야 방향 전환 후보로 등록된다.

| 조건 | 처리 |
| :---- | :---- |
| 소리 감지 \+ 전투 중이 아님 | 소리 방향을 시야 방향 전환 후보로 등록   |
| 소리 감지 \+ 전투 중 \+ 1칸 이내 근접 대상 없음 | 소리 방향을 시야 방향 전환 후보로 등록   |
| 소리 감지 \+ 전투 중 \+ 1칸 이내 근접 대상 있음 | 근접 대상 방향 유지 우선 |

소리의 종류와 감지 범위는 08-A\_전파·소리\_간접입력\_연산공식\_Current에서 다룬다.

# **13\. 특수 원형 인지 범위**

엘리트, 네메시스, 보스는 원형 인지 범위를 가질 수 있다.

| 항목 | 값 |
| :---- | :---- |
| 적용 대상 | 엘리트 / 네메시스 / 보스 |
| 기본 반지름 | 1칸 |
| 증가 기준 | 감지 스탯 20마다 \+1칸 |
| 최대 반지름 | 3칸 |

| 감지 스탯 | 원형 인지 범위 반지름 |
| :---- | :---- |
| 0\~29 | 1칸 |
| 30\~59 | 2칸 |
| 60 이상 | 3칸 |

감지 스탯이 더 높아져도 원형 인지 범위는 최대 3칸을 넘지 않는다.
