# **1\. 문서 목적**

본 문서는 일반 탐색에서 탐색 반응으로 전환되는 조건, 각 탐색 반응의 진행 방식, 완료·중단·전환 기준을 정리한다.   
일반 탐색은 유닛이 현재 목표와 이동 경로를 따라 이동하는 기본 상태다.   
탐색 반응은 일반 탐색 중 특정 정보나 상황을 처리하기 위해 일시적으로 수행하는 행동이다.

# **2\. 탐색 반응 기본 흐름**

| 일반 탐색↓인지 결과·전파 정보·명령·상황 변화 발생↓탐색 반응 필요 여부 확인↓경계 / 조사 / 함정 대응 / 대기 / 집결 수행↓완료·중단 결과에 따라 일반 탐색, 다른 탐색 반응 또는 전투 상태로 전환 |
| :---- |

안전타일 확인처럼 추가 행동이 필요하지 않은 결과는 탐색 반응을 발생시키지 않는다.

## **2-1. 탐색 반응 기본 우선순위**

같은 시점에 둘 이상의 자율 탐색 반응 조건이 동시에 충족되면 다음 우선순위를 사용한다.

**1\.** 함정 대응

**2\.** 경계

**3\.** 조사

**4\.** 대기

집결은 리더 명령으로 발생하므로 자율 탐색 반응 우선순위에서 제외한다.   
이미 수행 중인 조사나 함정 해제는 더 높은 우선순위의 후보가 새로 발생했다는 이유만으로 자동 중단하지 않으며, 실제 중단 조건이 충족됐을 때만 중단한다.

## **2-2. 우선순위 적용 예시**

| 상황 | 우선 처리 | 후속 처리 |
| :---: | :---: | :---: |
| 함정과 조사 오브젝트를 동시에 정확 인지 | 함정 대응 | 함정 처리 후 조사 여부 재판단 |
| 수상한 타일과 조사 대상을 동시에 확인 | 경계 | 수상한 타일 확인 후 조사 여부 재판단 |
| 함정 해제 유닛을 기다리는 중 수상한 타일 확인 | 대기 유지 | 대기 목적 해결 후 수상한 타일 처리 |

# **3\. 일반 탐색**

일반 탐색 상태의 유닛은 현재 목표와 이동 경로를 따라 일반 이동속도로 이동하며 시야 확인과 인지 판정을 반복한다.

| 현재 목표를 향해 이동↓시야 범위 내 대상 확인↓인지 판정↓인지 결과에 따른 행동 결정 |
| :---- |

안전타일로 확인된 경우에는 별도 탐색 반응으로 전환하지 않고 일반 탐색을 유지한다.

| 탐색 반응 완료 후 조건 | 처리 |
| :---: | :---: |
| 기존 목표와 이동 경로가 유효함 | 일반 탐색 상태로 기존 목표·경로 수행 재개 |
| 기존 목표 또는 이동 경로가 무효화됨 | 목표·이동 경로 재설정 |

# **4\. 경계**

## **4-1. 경계의 의미와 발생 상황**

경계는 아직 적이나 위험 요소를 정확히 확인하지 못한 상태에서 특정 위치 또는 방향을 확인하는 탐색 반응이다.

**•** 수상한 타일을 확인해야 하는 경우

**•** 전투 종료 후 주변을 다시 확인하는 경우

**•** 공격자를 인지하지 못한 상태에서 공격받은 경우

**•** 공격자는 인지하지 못했지만 공격 방향을 확인한 경우

## **4-2. 경계 상태 보정**

경계 상태에서는 위험 발생에 대비하고 있으므로 감지 능력과 반응속도가 증가한다.   
감지 관련 수치는 인지 문서의 경계 감지 보정을 따른다.

| 경계 적용 반응속도 \= 기본 반응속도 × 1.2 |
| :---- |

경계 반응속도 보정은 기습 공격, 직전 시야에서 확인되지 않았던 대상의 공격, 경계 수색 중 발생한 추가 공격에 대한 최초 반응에 적용한다.   
경계 상태가 종료되면 보정을 제거하며, 적을 정확 인지해 전투 상태로 전환한 뒤에는 전투 상태의 반응속도 계산을 따른다.

## **4-3. 경계 이동속도**

| 경계 이동속도 \= 일반 이동속도의 75% |
| :---- |

경계 상태에서 위치나 방향을 확인하며 이동할 때 적용한다.

## **4-4. 수상한 타일 접근**

수상한 타일이 발생하면 유닛은 해당 타일 방향을 바라보고 경계 상태로 접근한다.

| 수상한 타일 발생↓수상한 타일 방향으로 시야 전환↓경계 상태 진입↓경계 이동속도로 접근↓2칸 이내에서 재인지 판정 |
| :---- |

수상한 타일은 실제 인지 대상이 존재할 때만 발생한다.   
빈 타일은 안전타일 확인으로 처리한다.

## **4-5. 수상한 타일 재인지 결과**

| 재인지 결과 | 후속 행동 |
| :---: | :---: |
| 적 유닛 정확 인지 | 전투 상태 전환 |
| 함정 정확 인지 | 함정 대응 전환 |
| 조사 가능 오브젝트 정확 인지 | 조사 또는 목표 판단 |
| 미인식 | 해당 타일을 안전타일로 처리 |
| 다시 수상한 타일 | 대상 위치까지 경계 접근 유지 |

## **4-6. 수상한 타일 대상의 이동**

수상한 타일을 발생시킨 대상이 이동하면 이동 1회마다 해당 대상의 가시성을 임시로 20 증가시키며, 누적된 임시 가시성을 적용해 인지 판정을 다시 수행한다.

| 이동 횟수 | 누적 임시 가시성 |
| :---: | :---: |
| 1회 | \+20 |
| 2회 | \+40 |
| 3회 | \+60 |

| 수상한 타일 대상 이동↓대상 가시성 \+20 누적↓이동한 대상의 새 위치에 인지 판정 재시도↓기존 타일은 빈 타일이므로 안전타일 확인 |
| :---- |

누적 임시 가시성은 해당 대상 추적 중에만 유지한다.  
대상을 정확 인지하거나 시야 범위 밖으로 완전히 이탈하거나 추적이 종료되면 누적값을 제거한다.

## **4-7. 적 위치 간접 인지 후 접근**

전투가 아직 발생하지 않은 적 위치를 간접 인지하고 해당 위치 접근이 목표로 선택되면 일반 탐색 상태와 일반 이동속도로 기록 위치에 접근한다.

| 적 위치 간접 인지↓해당 위치 접근이 목표로 선택됨↓일반 탐색 상태로 기록 위치 접근↓기록 위치가 일반 인지 범위에 들어옴↓전투 상태로 전환하여 기록 위치로 이동·교전 |
| :---- |

해당 위치에 접근하는 유닛은 합류 요청을 추가로 전파하지 않는다.  
(위험도 단계에 따른 전파 가능은 현 문서에서 다루지 않으며, 레벨 관련 개념이 작성된 후 다룬다.)

이미 전투가 발생한 위치의 합류 요청을 전파받은 유닛은 해당 위치에 도착하면 합류 요청을 다시 전파하지 않고 바로 전투 상태로 합류한다.

## **4-8. 전투 종료 후 경계와 집결 연결**

| 전투 종료↓10초 동안 경계 상태로 주변 이동·확인↓새로운 적이나 공격 없음↓경계 완료와 동시에 리더가 집결 명령 생성↓유닛은 집결 명령 전파를 기다림↓집결 및 파티 재정렬 |
| :---- |

경계 중 새로운 적을 정확 인지하면 전투 상태로 다시 전환한다. 

미식별 공격을 받으면 해당 공격을 기준으로 경계 수색을 시작한다.

## **4-9. 수색**

수색은 유닛이 경계 상태에서 자신이 바라보는 정면 방향으로 이동하며 적을 확인하는 행동이다.   
유닛은 바라보는 방향과 다른 방향으로 이동하지 않는다.

| 시야 방향 설정↓경계 상태 진입↓바라보는 정면 방향으로 이동↓이동 중 시야·인지 판정 반복 |
| :---- |

## **4-10. 공격 방향을 아는 경우의 수색**

공격자를 정확 인지하지 못했지만 공격 방향을 확인한 경우, 공격 방향을 바라보고 해당 방향으로 이동하며 수색한다.

| 미식별 공격 발생↓공격 방향 확인↓공격 방향으로 시야 전환↓경계 상태로 공격 방향 이동·수색↓공격자 정확 인지 시 전투 상태 전환 |
| :---- |

상호작용 보호 포메이션이 공격받아 수색으로 전환된 경우에는 모든 유닛이 공격 방향을 바라보고 같은 방향으로 이동한다.

## **4-11. 공격 방향을 모르는 경우의 수색**

일반 탐색 중 공격자와 공격 방향을 모두 인지하지 못하면 경계 상태로 전환해 주변을 확인한다.

상호작용 보호 포메이션에서 대기 중 공격 방향을 알 수 없는 경우에는 각 유닛이 배정된 방향을 바라보고 해당 방향으로 이동하는 분산 수색을 수행한다.

| 포메이션 내 위치 | 수색 방향 |
| :---: | :---: |
| 전방 유닛 | 정면 |
| 후방 유닛 | 후면 |
| 좌측 유닛 | 좌측 |
| 우측 유닛 | 우측 |
| 중앙 유닛 | 현재 수색 인원이 가장 적은 방향 |

분산 수색 중 유닛이 적을 정확 인지하면 적 위치와 전투 정보를 전파한다.   
해당 정보를 받은 유닛은 자신의 전파 범위 안에 다른 유닛이 들어오면 다시 전파하며, 전파받은 유닛은 전투 또는 전투 합류 행동을 수행한다.

## **4-12. 미식별 공격 수색 종료**

미식별 공격 수색시간은 15초다.

| 발생 결과 | 처리 |
| :---: | :---: |
| 공격자 정확 인지 | 전투 상태 전환 |
| 추가 공격 발생 | 공격 방향 정보 갱신 후 수색시간을 15초로 재설정 |
| 15초 동안 적 또는 추가 공격을 확인하지 못함 | 경계 수색 종료 후 상호작용 재개 또는 일반 탐색 전환 |

# **5\. 조사**

## **5-1. 조사 행동과 결과**

조사는 정확 인지한 비전투 오브젝트와 상호작용해 해당 오브젝트의 정보와 가중치 정보를 파악하는 탐색 반응이다. 조사 완료 후 오브젝트 설정에 따라 파괴, 회수 또는 이벤트 처리가 가능하다.

회수 가능한 대상은 회수 전용 오브젝트로 표기하며, 회수 전용 오브젝트가 아닌 대상은 조사 결과만으로 회수할 수 없다.

| 오브젝트 설정 | 조사 후 가능한 처리 |
| :---: | :---: |
| 파괴 가능 | 파괴 행동 선택 가능 |
| 회수 전용 | 회수 행동 수행 가능 |
| 이벤트 연결 | 지정 이벤트 실행 |
| 정보 제공 | 대상 정보와 가중치 정보 획득 |

## **5-2. 조사 대상**

조사 대상은 비전투 오브젝트로 통합하며, 비전투 건물, 시체, 전멸 흔적, 회수 전용 오브젝트, 일반 조사 오브젝트, 이벤트 오브젝트가 포함될 수 있다.

## **5-3. 조사 시작**

조사 오브젝트에 도달한 유닛은 다른 파티원의 도착을 기다리지 않고 즉시 상호작용을 시작한다.   
함정 대응만 별도의 합류 의사 또는 해제 유닛 도착을 기다릴 수 있다.

**•** 대상을 정확 인지함

**•** 해당 대상을 조사 대상으로 선택함

**•** 대상과 상호작용할 수 있는 위치에 도달함

**•** 전투 상태가 아님

**•** 도주·후퇴 행동 중이 아님

| 조사 대상 선택↓상호작용 위치로 이동↓대상을 정면으로 바라봄↓조사 즉시 시작 |
| :---- |

## **5-4. 조사 중 보정**

| 항목 | 조사 중 수치 |
| :---: | :---: |
| 시야 범위 | 기본값의 50% |
| 인지 범위 | 기본값의 50% |
| 반응속도 | 기본값의 50% |

| 조사 적용 반응속도 \= 기본 반응속도 × 0.5 |
| :---- |

조사가 완료되거나 중단되면 감소 보정을 제거한다.

## **5-5. 조사 완료와 정보 공유**

| 조사 완료↓오브젝트 정보와 가중치 정보 기록↓가능한 파괴·회수·이벤트 처리 확인↓조사 결과 전파 |
| :---- |

조사로 확인한 정보는 전파를 통해 파티 전체에 공유한다.   
정보를 기록한 파티원의 전파 범위 안으로 아직 해당 정보를 기록하지 않은 다른 파티원이 들어오면 정보를 다시 전파한다.

| 상호작용 유닛이 조사 정보 기록↓주변 파티원에게 전파↓정보를 기록한 파티원 주변으로 다른 파티원이 진입↓해당 파티원이 조사 정보를 재전파↓파티 전체로 점진적 공유 |
| :---- |

## **5-6. 조사 중단과 진행도**

**•** 조사 중인 상호작용 유닛이 공격받음

**•** 상호작용 유닛이 적을 정확 인지함

**•** 상호작용 유닛이 위협 콜라이더를 인지함

**•** 다른 문서의 조건에 따라 전투·도주·후퇴 상태로 전환됨

조사가 중단되면 진행된 조사량의 50%를 잃고 남은 진행도를 유지한다.

| 중단 전 조사 진행도 60%↓진행량의 50% 손실↓남은 조사 진행도 30% |
| :---- |

웨이브가 종료되면 유지 중인 조사 진행도를 제거한다.

## **5-7. 조사 재개**

| 미식별 공격 수색 15초 종료↓조사 대상과 기존 목표가 유효함↓전투가 발생하지 않음↓남은 진행도부터 조사 재개 |
| :---- |

조사 목표가 더 이상 유효하지 않으면 일반 탐색 상태로 전환하거나 목표를 재설정한다.

# **6\. 상호작용 보호 포메이션**

## **6-1. 보호 포메이션 발생**

조사 또는 함정 해제가 시작되면 상호작용 유닛은 주변 유닛에게 상호작용 사실을 전파한다.

**•** 상호작용 유닛의 전파를 받은 일반 탐색 유닛

**•** 자신의 시야 범위 안에서 상호작용 유닛을 직접 확인한 일반 탐색 유닛

| 조사 또는 함정 해제 시작↓상호작용 유닛이 상호작용 정보 전파↓일반 탐색 유닛이 정보 수신 또는 상호작용 유닛 직접 확인↓보호 포메이션 참여 |
| :---- |

보호 포메이션에 참여한 유닛은 상호작용 정보를 다시 전파하지 않는다.

## **6-2. 동시 보호 포메이션**

여러 유닛이 동시에 서로 다른 조사 또는 함정 해제를 수행할 수 있으며, 각 상호작용은 별도의 보호 포메이션을 형성한다.

이미 다른 보호 포메이션에 참여 중인 유닛은 새로운 상호작용 정보를 받거나 새로운 상호작용 유닛을 확인해도 기존 포메이션을 유지한다.

새로운 일반 탐색 유닛이 기존 보호 포메이션에 참여하면 배치 위치를 다시 계산하며, 기존 참여 유닛도 같은 포메이션 안에서 더 적합한 위치로 이동할 수 있다.

## **6-3. 포메이션 전방 기준**

상호작용 유닛은 상호작용 대상 오브젝트를 정면으로 바라본다.   
상호작용 유닛이 오브젝트를 바라보는 방향을 보호 포메이션의 정면으로 사용하며, 반대 방향을 후면으로 사용한다.

## **6-4. 근접 유닛 배치**

**1\.** 상호작용 유닛 전방

**2\.** 상호작용 유닛 좌우

**3\.** 상호작용 유닛과 가장 가까운 이동 가능 타일

상호작용 유닛 전방으로 이동할 수 없으면 좌우 타일을 사용하고, 좌우도 사용할 수 없으면 가장 가까운 이동 가능 타일을 사용한다.

## **6-5. 원거리 유닛 배치**

**1\.** 상호작용 유닛 후방에서 2칸 이상 떨어진 위치

**2\.** 상호작용 유닛의 좌우 후방

**3\.** 가장 가까운 비점유 타일

가능한 경우 상호작용 유닛과 최소 2칸 거리를 유지하며, 공간 부족으로 유지할 수 없으면 가장 가까운 비점유 타일을 사용한다.

## **6-6. 보호 포메이션 시야 방향**

상호작용 유닛은 오브젝트를 바라보고, 다른 보호 포메이션 유닛은 위치에 따라 주변 방향을 나누어 감시한다.

| 배치 구간 | 인원·위치 | 시야 방향 |
| :---: | :---: | :---: |
| 전방 | 1명 | 정면 |
| 전방 | 2명 | 좌측 유닛은 좌측 전방, 우측 유닛은 우측 전방 |
| 전방 | 홀수 인원 | 중앙은 정면, 좌측은 좌측 전방, 우측은 우측 전방 |
| 전방 | 짝수 인원 | 왼쪽 절반은 좌측 전방, 오른쪽 절반은 우측 전방 |
| 후방 | 1명 | 정후면 |
| 후방 | 홀수 인원 | 중앙은 정후면, 좌측은 좌측 후방, 우측은 우측 후방 |
| 후방 | 짝수 인원 | 왼쪽 절반은 좌측 후방, 오른쪽 절반은 우측 후방 |
| 중간 | 좌우 위치 | 좌측에 가까우면 좌측, 우측에 가까우면 우측 |
| 중간 | 중앙 잔여 인원 | 감시 인원이 적은 방향, 같으면 최근 확인되지 않은 방향 |

짝수 전방 인원으로 중앙 유닛이 없는 경우 좌우 전방 시야가 정면에서 겹치도록 처리한다.

## **6-7. 좁은 공간 시야 방향 예외**

유닛이 바라보는 정면 시야선의 50% 이상이 벽에 막히면 해당 방향을 감시 불가능한 방향으로 처리하고 인접한 유효 방향으로 재배정한다.

| 차단된 방향 | 재배정 방향 |
| :---: | :---: |
| 좌측 | 좌측 전방 또는 좌측 후방 |
| 우측 | 우측 전방 또는 우측 후방 |
| 정면 | 좌측 전방 또는 우측 전방 |
| 후면 | 좌측 후방 또는 우측 후방 |

여러 방향이 동시에 차단되면 벽에 막히지 않은 방향 중 감시 인원이 가장 적은 방향을 선택한다.

## **6-8. 보호 포메이션 종료**

| 상호작용 정상 완료↓보호 포메이션 해제↓상호작용 유닛과 보호 유닛 일반 탐색 상태 전환↓기존 목표·경로가 유효하면 이동 재개, 무효하면 재설정 |
| :---- |

# **7\. 파티 목표 오브젝트 상호작용**

## **7-1. 파티 목표 오브젝트**

파티 목표 오브젝트는 웨이브 진입 전에 파티별로 설정된 목표 오브젝트다.   
회수 파티는 지정된 회수 오브젝트, 탐사 파티는 지정된 조사 오브젝트를 목표로 가질 수 있다.

## **7-2. 상호작용과 합류**

파티 목표 여부와 관계없이 조사 오브젝트에 도달한 유닛은 다른 파티원의 도착을 기다리지 않고 즉시 상호작용을 시작한다.

대상이 웨이브 진입 전에 설정된 파티 목표 오브젝트라면 상호작용 시작과 동시에 주변에 합류 정보를 전파한다. 합류 정보를 전파받은 유닛은 현재 상태에 따라 목표 위치로 이동한다.

| 현재 상태 | 처리 |
| :---: | :---: |
| 일반 탐색 또는 일반 비전투 이동 | 현재 이동을 변경하고 파티 목표 위치로 합류 |
| 대기 | 대기를 종료하고 파티 목표 위치로 합류 |
| 다른 보호 포메이션 참여 | 기존 보호 포메이션 유지, 종료시 합류 |
| 전투 | 현재 전투 유지 |
| 도주·후퇴 | 현재 상태 유지 |

## **7-3. 파티 목표 포메이션의 시야 방향**

파티 목표 오브젝트와 상호작용할 때는 상호작용 유닛과 리더만 같은 정면 방향을 바라본다.   
리더는 상호작용 유닛이 오브젝트를 바라보는 방향과 동일한 각도로 시야 방향을 설정한다.

다른 보호 포메이션 유닛은 6-6의 전방·후방·좌우 감시 규칙을 따른다.

**1\.** 리더는 상호작용 유닛 옆에 배치

**2\.** 옆 배치가 불가능하면 좌우 후방

**3\.** 그마저 불가능하면 가장 가까운 비점유 타일

# **8\. 상호작용 중 공격 대응**

## **8-1. 상호작용 유닛이 공격받은 경우**

상호작용 중인 유닛이 직접 공격받으면 어떤 오브젝트와 상호작용 중이었는지와 관계없이 상호작용을 중단한다.

| 공격 인지 결과 | 처리 |
| :---: | :---: |
| 공격자 정확 인지 | 전투 상태 전환 |
| 공격자 미인식·공격 방향 인지 | 경계 상태로 공격 방향 수색 |
| 공격자 미인식·공격 방향 미인식 | 경계 상태로 주변 수색 |

상호작용 유닛은 오브젝트 방향 고정을 해제하고 전투 또는 경계 수색에 참여한다.

## **8-2. 보호 포메이션 유닛이 공격받은 경우**

보호 포메이션 유닛이 공격받았을 때는 현재 상호작용이 웨이브 진입 전에 설정된 파티 목표인지에 따라 상호작용 유지 여부를 결정한다.

| 현재 상호작용 | 처리 |
| :---: | :---: |
| 회수 파티의 목표 회수 또는 탐사 파티의 목표 조사 | 상호작용 유지. 공격받은 보호 유닛과 대응 가능한 보호 유닛만 전투 또는 경계로 전환 |
| 그 밖의 조사 또는 함정 해제 | 상호작용 중단 후 전투 또는 경계로 전환 |

파티 목표 상호작용이 유지된 경우 상호작용 완료 후 전투가 계속되고 있으면 상호작용 유닛도 전투에 합류한다.

## **8-3. 공격 방향 경계 포메이션**

상호작용이 중단되고 공격 방향을 확인한 경우 공격받은 유닛을 중심으로 재배치한다.   
모든 유닛은 공격 방향을 바라보고 해당 방향으로 이동하며 수색한다.

| 공격 방향 확인↓공격받은 유닛 중심으로 재배치↓모든 유닛이 공격 방향을 바라봄↓같은 방향으로 이동하며 15초 수색 |
| :---- |

## **8-4. 공격 방향 미확인 보호 포메이션 수색**

상호작용 보호 포메이션에서 공격 방향을 알 수 없으면 포메이션 위치에 따라 수색 방향을 분배하고 각 유닛이 자신의 방향으로 이동한다.   
상호작용 유닛도 오브젝트 방향 고정을 해제하고 수색에 참여한다.  
수색 중 적을 발견한 유닛은 적 위치와 전투 정보를 전파하며, 정보를 기록한 유닛은 자신의 전파 범위 안으로 다른 유닛이 들어오면 다시 전파한다.

# **9\. 함정 대응**

## **9-1. 함정 대응 행동**

함정 대응은 정확 인지한 함정을 해제, 우회, 파괴, 통과 또는 대기로 처리하는 탐색 반응이다.   
인류 유닛은 역할과 스테이터스에 따라 이 행동들을 사용할 수 있다.

## **9-2. 함정 해제 성공률**

**•** 클래스별 기본 함정 해제 성공률

**•** 유닛 레벨

**•** 해당 함정에 대한 이해도에 따른 해제 성공률 보정

미기록 함정은 예상 해제 성공률을 알 수 없다.   
최초 해제 시도 이후 오차 범위를 포함한 예상 해제 성공률을 기록하며, 이해도가 증가하면 예상 성공률의 오차 범위가 감소하고 실제 해제 성공률이 증가한다.

## **9-3. 미기록 함정 처리**

| 미기록 함정 정확 인지↓함정 정보 전파↓5초 동안 합류 의사 대기 |
| :---- |

| 5초 이내 결과 | 처리 |
| :---: | :---: |
| 더 높은 함정 해제 성공률 유닛이 합류 의사 전파 | 발견 유닛은 해당 유닛 도착까지 대기하고 합류 유닛이 해제 |
| 합류 의사 없음 | 발견 유닛이 직접 최초 해제 시도 |

## **9-4. 기록된 함정 처리**

| 발견 유닛의 예상 해제 성공률 | 처리 |
| :---: | :---: |
| 50% 초과 | 발견 유닛이 직접 해제 |
| 50% 이하 | 우회 또는 파괴 판단 |

50%는 조정 가능한 기준값이다.

## **9-5. 함정 해제 통합 흐름**

| 함정 정확 인지↓미기록 / 기록 함정 구분↓함정 정보 전파↓미기록: 5초 합류 의사 대기 후 해제 유닛 결정기록: 예상 성공률 50% 기준으로 직접 해제 또는 우회·파괴 판단↓해제 유닛이 함정 위치 도달↓상호작용 정보 전파 및 보호 포메이션 형성↓함정 해제 시작↓성공 또는 실패 결과 처리 |
| :---- |

## **9-6. 함정 해제 중 보정**

| 항목 | 함정 해제 중 수치 |
| :---: | :---: |
| 시야 범위 | 기본값의 50% |
| 인지 범위 | 기본값의 50% |
| 반응속도 | 기본값의 50% |

해제가 완료되거나 중단되면 보정을 제거한다.

## **9-7. 함정 해제 중단과 진행도**

**•** 함정 해제 유닛이 공격받음

**•** 해제 유닛이 적을 정확 인지함

**•** 해제 유닛이 위협 콜라이더를 인지함

**•** 보호 포메이션 유닛이 공격받고 파티 목표 유지 예외에 해당하지 않음

**•** 함정이 작동함

**•** 함정이 파괴됨

**•** 다른 문서의 결과로 전투·도주·후퇴 상태로 전환됨

함정 해제가 중단되면 진행된 해제량의 50%를 잃는다.   
웨이브 종료 시 유지 중인 해제 진행도를 제거한다.

## **9-8. 함정 우회**

**•** 함정 발견 후 다른 파티원의 전투 발생 정보를 전파받아 전투 합류가 우선되는 경우

**•** 기록된 예상 함정 해제 성공률이 50% 이하인 경우

| 우회 판단↓대체 경로 존재→ 우회 경로 선택대체 경로 없음→ 함정 파괴 또는 통과 판단 |
| :---- |

## **9-9. 함정 파괴**

| 예상 함정 해제 성공률 50% 이하\+대체 경로 없음↓함정 파괴 |
| :---- |

전투 중 이동 경로가 함정으로 막혔고 대체 경로가 없다면 함정을 공격해 파괴할 수 있다. (함정별 hp 존재)  
공격·피해·파괴 판정은 전투 판정 문서에서 처리한다.

## **9-10. 일반 함정 통과**

기록된 함정의 피해는 기록된 예상 피해 오차 범위 중 최대값을 사용한다.

| 통과 후 예상 HP \= 현재 HP \- 함정 최대 예상 피해 |
| :---- |

통과 후 예상 HP가 50% 이상이면 함정을 맞고 통과할 수 있다.

## **9-11. 아군 보호 목적의 함정 통과**

HP가 30% 이하인 아군에게 빠르게 이동해야 하는 경우 일반 함정 통과 기준을 완화한다.

| 함정 정보 | 통과 조건 |
| :---: | :---: |
| 기록된 함정 | 아군 HP 30% 이하 \+ 함정 경로가 우회보다 빠름 \+ 함정 최대 예상 피해 적용 후 이동 유닛 HP 30% 이상 |
| 미기록 함정 | 아군 HP 30% 이하 \+ 함정 경로가 우회보다 빠름 \+ 이동 유닛 현재 HP 60% 이상 |

# **10\. 대기**

대기는 특정 유닛의 응답이나 도착 또는 명령의 완료를 기다리는 탐색 반응이다.

**•** 미기록 함정 정보 전파 후 5초 동안 합류 의사를 기다리는 경우

**•** 적 위치 접근 전 합류 유닛의 도착을 기다리는 경우

**•** 집결 위치에 먼저 도착해 다른 파티원의 도착을 기다리는 경우

대기 중에도 시야와 인지 판정을 계속 수행한다.  
수상한 타일을 확인하더라도 대기 목적이 해결되지 않았다면 대기를 유지하며, 수상한 타일은 대기 종료 후 처리한다.

# **11\. 집결**

집결은 리더의 집결 명령을 전파받은 파티원이 지정된 위치로 모이는 행동이다.   
현재 집결은 전투 종료 후 파티를 재정렬하는 상황에서 사용한다.

| 전투 종료↓10초 동안 경계↓경계 완료와 동시에 리더가 집결 명령 생성↓유닛은 집결 명령 전파 대기↓명령 수신 후 집결 위치로 이동↓파티 집결 완료 및 포메이션 재정렬↓다음 목표 수행 |
| :---- |

일반적인 방 진입 전에는 별도의 집결을 수행하지 않는다.   
방 이동은 집결과 다른 리더 명령으로 처리한다.
