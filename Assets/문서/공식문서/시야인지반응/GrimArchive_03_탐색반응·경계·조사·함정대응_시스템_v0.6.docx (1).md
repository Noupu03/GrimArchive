# **1\. 문서 목적**

본 문서는 일반 탐색에서 탐색 반응으로 전환되는 조건, 각 탐색 반응의 진행 방식, 완료·중단·전환 기준을 정리한다.   
일반 탐색은 유닛이 현재 목표와 이동 경로를 따라 이동하는 기본 상태다.   
탐색 반응은 일반 탐색 중 특정 정보나 상황을 처리하기 위해 일시적으로 수행하는 행동이다.

# **2\. 탐색 반응 기본 흐름**

| 일반 탐색↓인지 결과·전파 정보·명령·상황 변화 발생↓탐색 반응 필요 여부 확인↓경계 / 조사 / 함정 대응 / 대기 / 집결 수행↓완료·중단 결과에 따라 일반 탐색, 다른 탐색 반응 또는 전투 상태로 전환 |
| :---- |

안전타일 확인처럼 추가 행동이 필요하지 않은 결과는 탐색 반응을 발생시키지 않는다.

## **2-1. 탐색 반응 기본 우선순위**

같은 시점에 둘 이상의 자율 탐색 반응 조건이 동시에 충족되면 다음 우선순위를 사용한다.

**1\.** 함정 대응

**2\.** 경계

**3\.** 조사

**4\.** 대기

집결은 리더 명령으로 발생하므로 자율 탐색 반응 우선순위에서 제외한다.   
이미 수행 중인 조사나 함정 해제는 더 높은 우선순위의 후보가 새로 발생했다는 이유만으로 자동 중단하지 않으며, 실제 중단 조건이 충족됐을 때만 중단한다.

## **2-2. 우선순위 적용 예시**

| 상황 | 우선 처리 | 후속 처리 |
| :---: | :---: | :---: |
| 함정과 조사 오브젝트를 동시에 정확 인지 | 함정 대응 | 함정 처리 후 조사 여부 재판단 |
| 수상한 타일과 조사 대상을 동시에 확인 | 경계 | 수상한 타일 확인 후 조사 여부 재판단 |
| 함정 해제 유닛을 기다리는 중 수상한 타일 확인 | 대기 유지 | 대기 목적 해결 후 수상한 타일 처리 |

# **3\. 일반 탐색**

일반 탐색 상태의 유닛은 현재 목표와 이동 경로를 따라 일반 이동속도로 이동하며 시야 확인과 인지 판정을 반복한다.

| 현재 목표를 향해 이동↓시야 범위 내 대상 확인↓인지 판정↓인지 결과에 따른 행동 결정 |
| :---- |

안전타일로 확인된 경우에는 별도 탐색 반응으로 전환하지 않고 일반 탐색을 유지한다.

| 탐색 반응 완료 후 조건 | 처리 |
| :---: | :---: |
| 기존 목표와 이동 경로가 유효함 | 일반 탐색 상태로 기존 목표·경로 수행 재개 |
| 기존 목표 또는 이동 경로가 무효화됨 | 목표·이동 경로 재설정 |

# **4\. 경계**

## **4-1. 경계의 의미와 발생 상황**

경계는 아직 적이나 위험 요소를 정확히 확인하지 못한 상태에서 특정 위치 또는 방향을 확인하는 탐색 반응이다.

**•** 수상한 타일을 확인해야 하는 경우

**•** 전투 종료 후 주변을 다시 확인하는 경우

**•** 공격자를 인지하지 못한 상태에서 공격받은 경우

**•** 공격자는 인지하지 못했지만 공격 방향을 확인한 경우

**•** 웨이브에 함께 진입한 파티원의 시체를 발견했으나 사망 원인을 확인할 수 없는 경우 

## **4-2. 경계 상태 보정**

경계 상태에서는 위험 발생에 대비하고 있으므로 감지 능력과 반응속도가 증가한다.   
감지 관련 수치는 인지 문서의 경계 감지 보정을 따른다.

| 경계 적용 반응속도 \= 기본 반응속도 × 1.2 |
| :---- |

경계 반응속도 보정은 기습 공격, 직전 시야에서 확인되지 않았던 대상의 공격, 경계 수색 중 발생한 추가 공격에 대한 최초 반응에 적용한다.   
경계 상태가 종료되면 보정을 제거하며, 적을 정확 인지해 전투 상태로 전환한 뒤에는 전투 상태의 반응속도 계산을 따른다.

## **4-3. 경계 이동속도**

| 경계 이동속도 \= 일반 이동속도의 75% |
| :---- |

경계 상태에서 위치나 방향을 확인하며 이동할 때 적용한다.

## **4-4. 수상한 타일 접근**

수상한 타일이 발생하면 유닛은 해당 타일 방향을 바라보고 경계 상태로 접근한다.

| 수상한 타일 발생↓수상한 타일 방향으로 시야 전환↓경계 상태 진입↓경계 이동속도로 접근↓2칸 이내에서 재인지 판정 |
| :---- |

수상한 타일은 실제 인지 대상이 존재할 때만 발생한다.   
빈 타일은 안전타일 확인으로 처리한다.

## **4-5. 수상한 타일 재인지 결과**

| 재인지 결과 | 후속 행동 |
| :---: | :---: |
| 적 유닛 정확 인지 | 전투 상태 전환 |
| 함정 정확 인지 | 함정 대응 전환 |
| 조사 가능 오브젝트 정확 인지 | 조사 또는 목표 판단 |
| 미인식 | 해당 타일을 안전타일로 처리 |
| 다시 수상한 타일 | 대상 위치까지 경계 접근 유지 |

## **4-6. 수상한 타일 대상의 이동**

수상한 타일을 발생시킨 대상이 1칸 이동할 때마다 해당 대상의 가시성을 임시로 20 증가시키며, 누적된 임시 가시성을 적용해 인지 판정을 다시 수행한다.

| 이동 횟수 | 누적 임시 가시성 |
| :---: | :---: |
| 1칸 | \+20 |
| 2칸 | \+40 |
| 3칸 | \+60 |
| 이후 1칸마다 | \+20 |

각 이동으로 추가된 임시 가시성 `+20`은 추가된 시점부터 5초 동안 유지하며, 유지시간이 끝난 증가량부터 개별적으로 제거한다. 

| 수상한 타일 대상 이동↓대상 가시성 \+20 누적↓이동한 대상의 새 위치에 인지 판정 재시도↓기존 타일은 빈 타일이므로 안전타일 확인 |
| :---- |

누적 임시 가시성은 해당 대상 추적 중에만 유지한다.  
대상을 정확 인지하거나 시야 범위 밖으로 완전히 이탈하거나 추적이 종료되면 누적값을 제거한다.

## **4-7. 적 위치 간접 인지 후 접근**

전투가 아직 발생하지 않은 적 위치를 간접 인지하고 해당 위치 접근이 목표로 선택되면 일반 탐색 상태와 일반 이동속도로 기록 위치에 접근한다.

| 적 위치 간접 인지↓해당 위치 접근이 목표로 선택됨↓일반 탐색 상태로 기록 위치 접근↓기록 위치가 일반 인지 범위에 들어옴↓전파받은 적 발견 시 전투 상태로 전환하여 교전↓적 미발견 시 전파받은 위치 주위 3칸 범위 확인↓ 적 발견 → 교전↓ 적 미발견 → 간접 인지 위치 정보 갱신 → 일반 탐색 복귀 또는 목표 재설정  |
| :---- |

간접 인지한 적 위치에 접근하는 유닛은 합류 요청을 추가로 전파하지 않고 다른 유닛을 기다리지 않으며 기록 위치로 직접 접근한다.

이미 전투가 발생한 위치의 합류 요청을 받은 유닛도 합류 요청을 다시 전파하거나 다른 유닛을 기다리지 않고 전투 위치로 직접 접근한다. 해당 유닛은 전투 위치에 도착하면 즉시 전투 상태로 합류한다.

※ 추후 정의 및 적용 예정: 유닛 레벨과 위험도 단계의 비교 방식, 접근을 중단하는 단계 차이는 09\_목표설정·이동경로·재설정\_시스템에서 정의한다. 정보를 받은 유닛의 합류·대기 판단과 파티 단위 최종 접근 조건은 추후 작성할 파티 종류·목표·포메이션 문서에서 정의한다. 

## **4-8. 수색**

수색은 유닛이 경계 상태에서 자신이 바라보는 정면 방향으로 이동하며 적을 확인하는 행동이다.   
유닛은 바라보는 방향과 다른 방향으로 이동하지 않는다.

| 시야 방향 설정↓경계 상태 진입↓바라보는 정면 방향으로 이동↓이동 중 시야·인지 판정 반복 |
| :---- |

## **4-9. 공격 방향을 아는 경우의 수색**

공격자를 정확 인지하지 못했지만 공격 방향을 확인한 경우, 공격 방향을 바라보고 해당 방향으로 이동하며 수색한다.

| 미식별 공격 발생↓공격 방향 확인↓공격 방향으로 시야 전환↓경계 상태로 공격 방향 이동·수색↓공격자 정확 인지 시 전투 상태 전환 |
| :---- |

상호작용 보호 포메이션이 공격받아 수색으로 전환된 경우에는 모든 유닛이 공격 방향을 바라보고 같은 방향으로 이동한다.

## **4-10. 공격 방향을 모르는 경우의 수색**

일반 탐색 중 공격자와 공격 방향을 모두 인지하지 못하면 경계 상태로 전환해 주변을 확인한다.

상호작용 보호 포메이션에서 대기 중 공격 방향을 알 수 없는 경우에는 각 유닛이 배정된 방향을 바라보고 해당 방향으로 이동하는 분산 수색을 수행한다.

| 포메이션 내 위치 | 수색 방향 |
| :---: | :---: |
| 전방 유닛 | 정면 |
| 후방 유닛 | 후면 |
| 좌측 유닛 | 좌측 |
| 우측 유닛 | 우측 |
| 중앙 유닛 | 현재 수색 인원이 가장 적은 방향 |

분산 수색 중 유닛이 적을 정확 인지하면 적 위치와 전투 정보를 전파한다.   
해당 정보를 받은 유닛은 자신의 전파 범위 안에 다른 유닛이 들어오면 다시 전파하며, 전파받은 유닛은 전투 또는 전투 합류 행동을 수행한다.

## **4-11. 미식별 공격 수색 종료**

미식별 공격 수색시간은 15초다.

| 발생 결과 | 처리 |
| :---: | :---: |
| 공격자 정확 인지 | 전투 상태 전환 |
| 추가 공격 발생 | 공격 방향 정보 갱신 후 수색시간을 15초로 재설정 |
| 15초 동안 적 또는 추가 공격을 확인하지 못함 | 경계 수색 종료 후 상호작용 재개 또는 일반 탐색 전환 |

**4-12. 파티원 시체 발견과 정신력 감소**  
같은 웨이브에 진입한 인류 유닛은 세부 편성 구분과 관계없이 하나의 파티로 취급한다.   
유닛이 같은 웨이브에 진입한 파티원의 시체를 정확 인지하거나 파티원의 사망 순간을 직접 목격하면 파티원 사망 발견으로 처리한다.   
수상한 타일 단계에서는 적용하지 않으며, 시체 또는 사망 사건을 정확 인지한 시점에 처리한다.

| 파티원 시체 정확 인지 또는 사망 순간 직접 목격↓최초 발견 유닛 지정↓발견 유닛 정신력 \-10↓사망 유닛·시체 위치·확인된 사망 원인 기록↓사망 정보 최초 전파 |
| :---- |

서로 다른 시점에 여러 유닛이 같은 시체를 발견한 경우 최초 발견 유닛 한 명만 직접 발견자로 처리한다.   
동일 판정 시점에 여러 유닛이 직접 발견한 경우 모두 정신력 `-10`을 적용하되, 시체와 가장 가까운 유닛 한 명을 대표 발견 유닛으로 정해 최초 전파와 수색 방향 배정을 담당한다.   
동일한 사망 사건에서 생성된 정보는 하나의 사망 사건 정보로 통합하며 중복 기록하지 않는다. 

사망 정보 기록, 정신력 감소와 최초 전파는 유닛의 현재 상태와 탐색 반응 우선순위에 관계없이 즉시 처리한다.   
경계 수색 전환 여부는 현재 행동과 탐색 반응 전환 조건에 따라 판단한다.   
**4-13. 사망 정보 수신과 재전파**

발견 유닛의 최초 전파 범위 안에서 사망 정보를 처음 받은 유닛은 정신력이 5 감소하고 해당 사망 정보를 기록한다.   
사망 정보를 기록한 유닛은 자신의 전파 범위 안에 해당 정보를 기록하지 않은 파티원이 들어오면 사망 정보를 재전파한다.   
재전파로 사망 정보를 처음 받은 유닛도 정신력이 5 감소한다.

| 사망 정보를 처음 인지한 방식 | 처리 |
| :---: | :---: |
| 최초 직접 발견 또는 사망 순간 직접 목격 | 정신력 \-10 |
| 최초 전파 또는 재전파를 통한 정보 수신 | 정신력 \-5 |
| 이미 알고 있는 사망 정보 재수신 | 추가 감소 없음 |
| 전파 수신 후 같은 시체 직접 목격 | 추가 감소 없음 |
| 동일 판정 시점에 복수 유닛이 직접 발견 | 직접 발견 유닛 모두 정신력 \-10 |

같은 유닛의 사망 정보로 인한 정신력 감소는 유닛당 한 번만 적용한다.   
직접 발견으로 정신력이 감소한 유닛과 전파를 통해 정신력이 감소한 유닛 모두 같은 사망 정보로 추가 감소하지 않는다.   
사망 정보에는 사망 유닛, 시체 위치, 사망 사실, 확인된 사망 원인, 원인이 된 적·함정·위험 요소 정보가 포함될 수 있다.

## **4-14. 사망 원인 확인과 위험도 반영**

사망 원인 확인은 유닛이 사망을 발생시킨 공격자, 함정 또는 위험 요소와 해당 사망 사건의 연결을 직접 목격하거나, 그 연결이 포함된 정보를 전파받은 경우거나 시체를 조사한 경우로 한정한다.   
시체 주변에 적·함정·위험 요소가 존재하거나 전투 흔적이 남아 있다는 이유만으로 사망 원인을 추정하지 않는다.

| 확인 상태 | 예시 |
| :---: | :---: |
| 사망 원인 확인 | 특정 몬스터의 공격으로 파티원이 사망하는 장면을 직접 목격 |
| 사망 원인 확인 | 정확 인지한 함정 또는 위험 요소의 피해로 사망하는 장면을 확인 |
| 사망 원인 확인 | 공격자·함정·위험 요소와 사망 사건의 연결 정보까지 전파받음 |
| 사망 원인 미확인 | 이동 중 시체만 발견하거나 전투 소리만 들은 뒤 시체를 발견 |
| 사망 원인 미확인 | 시체 주변에서 적이나 함정을 발견했지만 사망 사건과의 연결 정보가 없음 |

사망 원인이 몬스터로 확인되면 정보 획득 방식에 따라 대표 가중치 연산공식의 인류 유닛 처치 이벤트를 적용한다.

| 정보 획득 방식 | 적용 이벤트 | 해당 몬스터 위험도 변화 |
| :---: | :---: | :---: |
| 파티원의 사망 순간과 원인 몬스터를 직접 목격파티원의 시체 조사 후 원인 몬스터를 직접 목격 | E\_HUMAN\_KILL\_SEEN | \+3 |
| 시체 발견 후 수색·전파 정보로 사망 원인 몬스터를 확인 | E\_HUMAN\_KILL\_INDIRECT | \+1.5 |

위험도 변화량 \+3과 \+1.5는 대표 가중치 연산공식의 최종 이벤트 변화량이므로 정보 유형 배율을 다시 곱하지 않는다.  위험도는 사망 원인이 된 몬스터 개체에 적용한다.   
동일한 사망 사건에 직접 목격 위험도 증가가 이미 적용됐다면 이후 같은 사건으로 간접 파악 위험도 증가는 중복 적용하지 않는다.   
서로 다른 파티원의 사망은 각각 별도의 사망 사건으로 처리한다.  
구체적인 합산·상한·전역 반영 조건은 대표 가중치 문서를 따른다. 

**4-15. 원인 미상 파티원 사망 수색**

파티원 시체를 직접 발견했으나 사망 원인을 확인할 수 없으면 직접 발견 유닛과 발견 유닛의 최초 전파를 받은 유닛 중 현재 행동을 중단하고 경계 수색으로 전환할 수 있는 유닛이 경계 상태로 전환한다.   
이후 재전파로 사망 정보를 받은 유닛은 정보 기록과 정신력 감소만 적용하며 시체 주변 수색에는 합류하지 않는다.

| 현재 상태 | 처리 |
| :---: | :---: |
| 일반 탐색·일반 비전투 이동 | 경계 수색 참여 |
| 대기·집결 이동 | 대기·집결을 중단하고 경계 수색 참여 |
| 전투 | 현재 전투 유지, 사망 정보와 정신력 감소만 적용 |
| 도주·후퇴 | 현재 상태 유지, 사망 정보와 정신력 감소만 적용 |
| 조사·함정 해제·다른 보호 포메이션 | 현재 행동 유지, 사망 정보와 정신력 감소만 적용 |

| 사망 원인 미확인↓발견 유닛이 사망 정보 최초 전파↓발견 유닛과 최초 전파 범위 내 참여 가능 유닛 경계 전환↓시체 위치를 수색 중심으로 설정↓전방·후방·좌측·우측으로 수색 방향 분배↓배정된 방향을 바라보고 이동하며 10초 수색 |
| :---- |

| 수색 결과 | 처리 |
| :---: | :---: |
| 사망 원인이 된 몬스터 확인 | 해당 몬스터 위험도 \+1.5 적용 후 전투 상태 전환 |
| 다른 적 정확 인지 | 일반 전투 상태 전환, 사망 원인 위험도 증가는 적용하지 않음 |
| 미식별 공격 또는 위협 발생 | 공격 방향 인지 여부에 따른 경계 수색으로 전환 |
| 함정 정확 인지 | 함정 대응으로 전환 |
| 10초 동안 적·공격·위협 미확인 | 수색 전 목표가 유효하면 복귀, 무효하면 목표 재설정 |

수색 중 몬스터를 발견했다는 이유만으로 인류 유닛 처치 위험도를 적용하지 않는다.   
해당 몬스터가 확인된 정보에 의해 사망 원인으로 연결된 경우에만 E\_HUMAN\_KILL\_INDIRECT를 적용한다.   
사망 원인은 확인됐지만 원인이 된 몬스터의 현재 위치를 모르는 경우에는 시체 중심의 원인 미상 수색을 사용하지 않는다.   
공격 방향을 알고 있으면 4-9를, 마지막 확인 위치만 알고 있으면 해당 위치를 향해 4-8의 수색을 적용한다.   
원인 몬스터를 현재 정확 인지하고 있으면 즉시 전투 상태로 전환한다.

# **5\. 조사**

## **5-1. 조사 행동과 결과**

조사는 정확 인지한 비전투 오브젝트와 상호작용해 해당 오브젝트의 정보와 가중치 정보를 파악하는 탐색 반응이다. 조사 완료 후 오브젝트 설정에 따라 파괴, 회수 또는 이벤트 처리가 가능하다.

회수 가능한 대상은 회수 전용 오브젝트로 표기하며, 회수 전용 오브젝트가 아닌 대상은 조사 결과만으로 회수할 수 없다.

| 오브젝트 설정 | 조사 후 가능한 처리 |
| :---: | :---: |
| 파괴 가능 | 파괴 행동 선택 가능 |
| 회수 전용 | 회수 행동 수행 가능 |
| 이벤트 연결 | 지정 이벤트 실행 |
| 정보 제공 | 대상 정보와 가중치 정보 획득 |

## **5-2. 조사 대상**

조사 대상은 비전투 오브젝트로 통합하며, 비전투 건물, 시체, 전멸 흔적, 회수 전용 오브젝트, 일반 조사 오브젝트, 이벤트 오브젝트가 포함될 수 있다.

파티원 시체 발견에 따른 사망 정보 기록·전파·정신력 감소와 원인 미상 수색은 시체 조사와 별도로 즉시 처리한다.   
즉시 처리가 완료된 뒤에도 시체는 조사 대상으로 유지하며, 시체 조사를 통해 사망 원인, 전투 흔적, 가중치 정보 등 추가 정보를 획득할 수 있다.   
같은 시체를 조사하더라도 이미 적용된 정신력 감소는 다시 적용하지 않는다.

## **5-3. 조사 시작**

일반 조사 오브젝트에 도달한 유닛은 다른 파티원의 도착을 기다리지 않고 즉시 상호작용을 시작한다. 함정 대응은 별도의 합류 의사와 해제 유닛 도착 절차를 사용하며, 코어는 7-3의 특수 규칙을 적용한다. 

**•** 대상을 정확 인지함

**•** 해당 대상을 조사 대상으로 선택함

**•** 대상과 상호작용할 수 있는 위치에 도달함

**•** 전투 상태가 아님

**•** 도주·후퇴 행동 중이 아님

# **6\. 상호작용 보호 포메이션**

## **6-1. 보호 포메이션 발생**

조사 또는 함정 해제가 시작되면 상호작용 유닛은 주변 유닛에게 상호작용 사실을 전파한다.

**•** 상호작용 유닛의 전파를 받은 일반 탐색 유닛

**•** 자신의 시야 범위 안에서 상호작용 유닛을 직접 확인한 일반 탐색 유닛

| 조사 또는 함정 해제 시작↓상호작용 유닛이 상호작용 정보 전파↓일반 탐색 유닛이 정보 수신 또는 상호작용 유닛 직접 확인↓보호 포메이션 참여 |
| :---- |

보호 포메이션에 참여한 유닛은 상호작용 정보를 다시 전파하지 않는다.  
함정 발견 후 2초 동안 합류 의사를 기다리는 단계에서는 보호 포메이션을 형성하지 않는다.   
선정된 해제 유닛이 함정 인접 1칸에 도달하고 실제 해제를 시작할 때 상호작용 정보를 전파해 보호 포메이션을 형성한다. 

## **6-2. 동시 보호 포메이션**

여러 유닛이 동시에 서로 다른 조사 또는 함정 해제를 수행할 수 있으며, 각 상호작용은 별도의 보호 포메이션을 형성한다.

이미 다른 보호 포메이션에 참여 중인 유닛은 새로운 상호작용 정보를 받거나 새로운 상호작용 유닛을 확인해도 기존 포메이션을 유지한다.

새로운 일반 탐색 유닛이 기존 보호 포메이션에 참여하면 배치 위치를 다시 계산하며, 기존 참여 유닛도 같은 포메이션 안에서 더 적합한 위치로 이동할 수 있다.

## **6-3. 포메이션 전방 기준**

상호작용 유닛은 상호작용 대상 오브젝트를 정면으로 바라본다.   
상호작용 유닛이 오브젝트를 바라보는 방향을 보호 포메이션의 정면으로 사용하며, 반대 방향을 후면으로 사용한다.

## **6-4. 근접 유닛 배치**

**1\.** 상호작용 유닛 전방

**2\.** 상호작용 유닛 좌우

**3\.** 상호작용 유닛과 가장 가까운 이동 가능 타일

상호작용 유닛 전방으로 이동할 수 없으면 좌우 타일을 사용하고, 좌우도 사용할 수 없으면 가장 가까운 이동 가능 타일을 사용한다.

## **6-5. 원거리 유닛 배치**

**1\.** 상호작용 유닛 후방에서 2칸 이상 떨어진 위치

**2\.** 상호작용 유닛의 좌우 후방

**3\.** 가장 가까운 비점유 타일

가능한 경우 상호작용 유닛과 최소 2칸 거리를 유지하며, 공간 부족으로 유지할 수 없으면 가장 가까운 비점유 타일을 사용한다.

## **6-6. 보호 포메이션 시야 방향**

상호작용 유닛은 오브젝트를 바라보고, 다른 보호 포메이션 유닛은 위치에 따라 주변 방향을 나누어 감시한다.

| 배치 구간 | 인원·위치 | 시야 방향 |
| :---: | :---: | :---: |
| 전방 | 1명 | 정면 |
| 전방 | 2명 | 좌측 유닛은 좌측 전방, 우측 유닛은 우측 전방 |

| 전방 | 짝수 인원 | 왼쪽 절반은 좌측 전방, 오른쪽 절반은 우측 전방 |

| 후방 | 짝수 인원 | 왼쪽 절반은 좌측 후방, 오른쪽 절반은 우측 후방 |

| 중간 | 중앙 잔여 인원 | 감시 인원이 적은 방향, 같으면 최근 확인되지 않은 방향 |

짝수 전방 인원으로 중앙 유닛이 없는 경우 좌우 전방 시야가 정면에서 겹치도록 처리한다.

## **6-7. 좁은 공간 시야 방향 예외**

# **7\. 파티 목표 오브젝트 상호작용**

## **7-1. 파티 목표 오브젝트**

파티 목표 오브젝트는 웨이브 진입 전에 파티별로 설정된 목표 오브젝트다.   
회수 파티는 지정된 회수 오브젝트, 탐사 파티는 지정된 조사 오브젝트를 목표로 가질 수 있다.

※ 파티 종류, 파티별 목표, 목표 달성 기준과 파티 포메이션은 추후 작성할 파티 종류·목표·포메이션 문서에서 정의한다. 

**7-2. 일반 파티 목표 상호작용과 합류**

일반 조사 오브젝트에 도달한 유닛은 즉시 상호작용을 시작한다.   
웨이브 진입 전에 설정된 파티 목표 오브젝트에 도달한 유닛은 1초 동안 합류 정보를 전파한 뒤 상호작용을 시작한다.

| 파티 목표 오브젝트 도달↓상호작용 유닛이 1초 동안 합류 정보 전파↓전파 완료↓상호작용 시작 |
| :---- |

파티 목표 합류 정보를 받은 유닛은 현재 합류 가능한 상태라면 1초 동안 같은 정보를 재전파한 뒤 목표 위치로 이동한다.   
현재 행동을 유지해야 하는 유닛은 정보를 재전파하지 않고 기존 행동을 유지한다.

| 현재 상태 | 처리 |
| :---: | :---: |
| 일반 탐색 또는 일반 비전투 이동 | 1초 재전파 후 파티 목표 위치로 합류 (텍스트 연출) |
| 대기 | 대기를 종료하고 1초 재전파 후 합류 (텍스트 연출) |
| 다른 보호 포메이션 참여, 또는 다른 상호작용 참여 | 현재 행동 유지, 합류 정보 재전파 안 함  |
| 전투 | 현재 전투 유지, 합류 정보 재전파 안 함  |
| 도주·후퇴 | 현재 상태 유지, 합류 정보 재전파 안 함  |

같은 파티 목표 합류 정보는 유닛당 1회만 재전파한다.   
같은 정보를 다시 받아도 재전파하지 않으며 기존 이동 목표를 다시 설정하지 않는다.   
정보 수신 당시 전투, 도주·후퇴, 다른 상호작용 또는 다른 보호 포메이션으로 합류하지 못한 유닛은 현재 행동이 종료된 뒤 파티 목표가 아직 유효하면 목표 위치로 합류한다.

## **7-3. 코어 발견과 리더 조사**

## 코어는 파티 목표가 될 수 있는 특수 조사 오브젝트다.  코어를 발견한 일반 유닛은 직접 조사하지 않고 코어 정보를 전파해 리더가 조사하도록 한다. 발견 유닛의 전파 범위 안에 리더가 없으면 발견 유닛은 리더에게 이동해 코어 정보를 직접 전파한다.  (해당 유닛의 전파 범위 내 리더가 들어올 시 전파) 리더가 코어 정보를 기록하면 다른 유닛은 리더에게 코어 정보를 전달하기 위한 이동을 중단하고 기존 행동을 재개한다. 

| 일반 유닛이 코어 정확 인지↓코어 정보 전파↓발견 유닛이 리더 위치로 이동↓리더가 코어 정보 인지↓코어를 현재 파티 목표에 추가 |
| :---- |

## 리더는 현재 수행 중인 비전투 행동을 완료한 뒤 코어로 이동한다.  리더가 전투 중이거나 코어 조사 전에 적을 인지하면 해당 전투를 마무리한 뒤 코어 조사를 수행한다. 코어를 발견한 유닛은 리더에게 합류하고, 리더와 함께 코어 위치로 돌아간다.

| 리더가 코어 위치 도착↓리더가 1초 동안 파티 목표 합류 정보 전파↓전파 완료 후 리더가 코어 조사 시작 |
| :---- |

## 리더가 사망하거나 조사할 수 없는 상태가 되면 리더 승계로 새로 정해진 리더가 코어 조사를 담당한다. 

## 코어 조사 완료 시 코어 정보와 가중치 정보를 기록하고, 코어에 설정된 후속 상호작용을 활성화한다.  코어 파괴, 특정 상호작용, 인류 측 메리트와 플레이어 측 디메리트는 별도의 코어·핵심방어목표 문서에서 정의한다.

## **7-4. 파티 목표 포메이션의 시야 방향**

파티 목표 오브젝트와 상호작용할 때는 상호작용 유닛과 리더만 같은 정면 방향을 바라본다.   
리더가 직접 상호작용 유닛인 코어 조사에서는 리더가 오브젝트를 바라보는 기준 유닛이 된다.   
리더는 상호작용 유닛이 오브젝트를 바라보는 방향과 동일한 각도로 시야 방향을 설정한다.  
다른 보호 포메이션 유닛은 6-6의 전방·후방·좌우 감시 규칙을 따른다.  
코어 조사에서는 리더가 직접 상호작용 유닛이므로 아래 리더 배치 우선순위를 적용하지 않는다. 

**1\.** 리더는 상호작용 유닛 옆에 배치

**2\.** 옆 배치가 불가능하면 좌우 후방

**3\.** 그마저 불가능하면 가장 가까운 비점유 타일

# **8\. 상호작용 중 공격 대응**

## **8-1. 상호작용 유닛이 공격받은 경우**

상호작용 중인 유닛이 직접 공격받으면 어떤 오브젝트와 상호작용 중이었는지와 관계없이 상호작용을 중단한다.

| 공격 인지 결과 | 처리 |
| :---: | :---: |
| 공격자 정확 인지 | 전투 상태 전환 |
| 공격자 미인식·공격 방향 인지 | 경계 상태로 공격 방향 수색 |
| 공격자 미인식·공격 방향 미인식 | 경계 상태로 주변 수색 |

상호작용 유닛은 오브젝트 방향 고정을 해제하고 전투 또는 경계 수색에 참여한다.

## **8-2. 보호 포메이션 유닛이 공격받은 경우**

보호 포메이션 유닛이 공격받았을 때는 현재 상호작용이 유지 우선 파티 목표인지에 따라 상호작용 유지 여부를 결정한다. 

| 현재 상호작용 | 처리 |
| :---: | :---: |
| 회수 파티의 목표 회수 또는 탐사 파티의 목표 조사 | 상호작용 유지. 공격받은 보호 유닛과 대응 가능한 보호 유닛만 전투 또는 경계로 전환 |
| 리더의 코어 조사 | 조사 유지. 피격된 보호 유닛과 대응 가능한 보호 유닛만 전투 또는 경계로 전환  |
| 그 밖의 조사 또는 함정 해제 | 상호작용 중단 후 전투 또는 경계로 전환 |

파티 목표 상호작용이 유지된 경우 상호작용 완료 후 전투가 계속되고 있으면 상호작용 유닛도 전투에 합류한다.

## **8-3. 공격 방향 경계 포메이션**

상호작용이 중단되고 공격 방향을 확인한 경우 공격받은 유닛을 중심으로 재배치한다.   
모든 유닛은 공격 방향을 바라보고 해당 방향으로 이동하며 수색한다.

| 공격 방향 확인↓공격받은 유닛 중심으로 재배치↓모든 유닛이 공격 방향을 바라봄↓같은 방향으로 이동하며 15초 수색 |
| :---- |

## **8-4. 공격 방향 미확인 보호 포메이션 수색**

상호작용 보호 포메이션에서 공격 방향을 알 수 없으면 포메이션 위치에 따라 수색 방향을 분배하고 각 유닛이 자신의 방향으로 이동한다.   
상호작용 유닛도 오브젝트 방향 고정을 해제하고 수색에 참여한다.  
수색 중 적을 발견한 유닛은 적 위치와 전투 정보를 전파하며, 정보를 기록한 유닛은 자신의 전파 범위 안으로 다른 유닛이 들어오면 다시 전파한다.

# **9\. 함정 대응**

## **9-1. 함정 대응 행동**

함정 대응은 정확 인지한 함정을 해제, 우회, 파괴, 통과 또는 대기로 처리하는 탐색 반응이다.   
인류 유닛은 역할과 스테이터스에 따라 이 행동들을 사용할 수 있다.

함정 정보를 전파받은 모든 유닛이 함정 대응 행동으로 전환하는 것은 아니다. 함정 해제 유닛으로 선정되지 않은 유닛은 함정 위치만 기록하고 일반 탐색 또는 기존 행동을 계속한다. 

## **9-2. 함정 해제 성공률**

**•** 클래스별 기본 함정 해제 성공률

**•** 유닛 레벨

**•** 해당 함정에 대한 이해도에 따른 해제 성공률 보정

미기록 함정은 예상 해제 성공률을 알 수 없다.   
최초 해제 시도 이후 오차 범위를 포함한 예상 해제 성공률을 기록하며, 이해도가 증가하면 예상 성공률의 오차 범위가 감소하고 실제 해제 성공률이 증가한다.

함정을 발견하면 발견 유닛과 전파 범위 안에 있는 모든 유닛의 함정 해제 성공률을 확인한다.

다만 실제 해제 담당 유닛은 현재 행동에서 함정 대응으로 전환할 수 있는 유닛 중에서 선정한다.

전투, 도주·후퇴, 다른 조사·함정 해제, 다른 보호 포메이션 참여 등 현재 행동을 유지해야 하는 유닛은 성공률 정보 확인에는 포함되지만 해제 담당 선정에서는 제외한다. 

| 함정 해제 담당 유닛 \= 함정 대응으로 전환 가능한 유닛 중 함정 해제 성공률이 가장 높은 유닛 |
| :---- |

최고 함정 해제 성공률이 같은 유닛이 2명 이상이면 함정 인접 1칸의 해제 위치까지 예상 도착시간이 가장 짧은 유닛을 우선한다.  
**9-3. 함정 정보 전파와 2초 응답** 

| 함정 정확 인지↓발견 유닛이 함정 정보를 즉시 전파↓발견 유닛은 현 위치에서 2초 동안 응답 대기↓전파 범위 안의 대응 가능 유닛 성공률 비교 |
| :---- |

발견 유닛보다 성공률이 높은 유닛이 있으면 가장 높은 유닛 한 명이 자신이 해제하겠다는 합류 의사를 전파하고, 유닛 머리 위에 대화 텍스트를 표시한다.   
발견 유닛은 선정 유닛이 함정 위치에 도착할 때까지 대기한다.

발견 유닛보다 성공률이 높은 유닛이 없으면 2초 응답 대기 후 발견 유닛이 직접 함정을 해제한다.   
웨이브 진입 전 최고 성공률 유닛 예외에 해당하지 않는 경우, 발견 유닛이 현재 전파 범위 내 최고 성공률임을 알고 있더라도 연출을 위해 2초 대기를 유지한다.   
웨이브 진입 전에 해당 파티 내 함정 해제 성공률이 가장 높은 유닛으로 확인된 유닛이 함정을 발견한 경우, 발견 유닛을 해제 담당으로 즉시 확정하고 2초 응답 대기를 생략한다.   
이후 함정의 기록 여부와 선정 유닛의 예상 성공률에 따라 9-4의 해제·우회·파괴 판단을 수행한다.   
함정 정보를 받은 비선정 유닛은 함정 위치만 기록하고 일반 탐색 또는 기존 행동을 계속하며 응답을 기다리지 않는다.

일반 탐색 또는 기존 행동을 수행하는 비선정 유닛은 활성 함정의 인접 1칸 안으로 진입하지 않도록 경로를 재설정한다. 전투 중에는 전투 이동과 함정 통과 규칙을 우선한다.

발견 유닛은 다른 유닛이 해제 담당자로 선정된 경우에도 현 위치에서 선정 유닛의 도착을 기다린다.

##  **9-7. 선정 유닛 예상 도착시간과 미도착 처리**

선정 유닛의 예상 도착시간은 현재 위치에서 함정 인접 1칸의 해제 가능 타일까지 이동하는 데 필요한 시간으로 계산한다.

| 함정 인접 1칸의 이동 가능한 해제 타일 확인↓선정 유닛의 현재 위치에서 각 타일까지 이동 칸 수 계산↓이동 칸 수가 가장 짧은 타일 선택↓거리가 같으면 현재 방에 파티가 진입한 입구와 가까운 방향의 타일 우선 |
| :---- |

| 선정 유닛 예상 도착시간 \= 선택된 이동 경로의 칸 수 ÷ 선정 유닛의 현재 적용 이동속도 |
| :---- |

선정 유닛이 이미 해제 위치에 있으면 예상 도착시간은 0초이며, 경로가 재설정되면 현재 위치에서 남은 경로 칸 수를 기준으로 예상 도착시간을 다시 계산한다.

발견 유닛은 선정 유닛의 예상 도착시간에 3초를 더한 시점까지 도착을 기다린다.

| 선정 유닛 미도착 판정 \= 예상 도착시간 \+ 3초 |
| :---- |

| 예상 도착시간 \+ 3초까지 선정 유닛 미도착↓발견 유닛이 선정 유닛의 마지막 전파 위치로 이동 |
| :---- |

선정 유닛이 전투 중이라는 정보나 전투 소음을 확인하면 일반적인 전투 전환 규칙을 적용한다.

마지막 전파 위치에서 선정 유닛의 사망을 확인하면 4-12\~4-15의 파티원 시체 발견, 사망 정보 전파, 정신력 감소, 사망 원인 확인 및 경계 수색 규칙을 적용한다.   
사망 원인을 확인할 수 없는 경우 발견 유닛과 최초 전파 범위 안의 참여 가능 유닛이 사망 위치 주변을 10초 동안 수색한다.   
수색 중 사망 원인이 된 몬스터를 확인하면 해당 몬스터에 E\_HUMAN\_KILL\_INDIRECT의 위험도 \+1.5를 적용한 뒤 전투 상태로 전환한다.

수색 종료 후 함정 대응 목표가 유효하면 발견 유닛은 함정 위치로 복귀해 남아 있는 유닛을 대상으로 함정 정보를 다시 전파하고 2초 응답 대기부터 재시작한다.

* 도주 또는 후퇴 중인 경우

| 통과 후 예상 HP \= 현재 HP \- 함정 최대 예상 피해 |
| :---- |
