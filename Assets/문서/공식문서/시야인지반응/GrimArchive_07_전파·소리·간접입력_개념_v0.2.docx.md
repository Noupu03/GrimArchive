# **07\_전파·소리·간접입력\_개념**

v0.2 / 개념 문서

# **0\. 개요**

본 문서는 유닛이 직접 인지하지 않은 정보를 얻는 전파·소리·공격 방향의 구조와, 해당 간접입력이 시야·행동·목표·경로 판단으로 이어지는 연결 규칙을 정의한다.

직접 인지는 유닛이 자신의 인지 범위에서 대상을 직접 확인한 결과다.   
전파·소리·공격 방향은 대상이나 사건의 존재, 방향, 마지막 확인 위치, 추정 지역 등을 제공하지만 직접 인지를 대신하지 않는다.

간접입력으로 얻은 정보는 실제 대상이나 관련 위치가 인지 범위에 들어왔을 때 02의 직접 인지 판정으로 검증·갱신한다.

# **1\. 적용 대상**

일반 몬스터는 직접 인지·소리·역할군 AI를 중심으로 판단한다.   
일부 무리형 몬스터는 개체 특성에 따라 같은 무리·그룹 내부에서 전파와 재전파를 사용할 수 있다.

몬스터의 전파 범위와 청각 보정은 07\_A에서 정의하며, 감지 이후의 행동은 각 역할군 AI가 결정한다.

# **2\. 간접입력의 종류**

## **2-1. 전파**

한 유닛이 자신이 보유한 사실 정보를 다른 유닛에게 전달하는 처리다.   
전파는 시스템상 소리가 아니며, 대사나 텍스트로 표현하더라도 소리 이벤트를 발생시키지 않는다.

## **2-2. 소리**

이동·공격 실행·피격 발생 공격음·피격 비명·사망·함정 작동 등 실제 사건에서 발생하는 간접입력이다.   
감지한 유닛은 소리 종류에 따라 발생 방향 또는 추정 지역을 얻는다.

## **2-3. 공격 방향**

유닛이 공격받았을 때 공격 형태를 통해 파악할 수 있는 방향 정보다.   
공격 방향을 알아도 공격자의 정체나 정확 위치를 확인한 것은 아니다.

# **3\. 정보 보유 구조와 대표 가중치의 역할**

정보는 파티 전체가 하나로 공유하지 않고 유닛별로 개별 보유한다.   
같은 파티 안에서도 위치와 전파 여부에 따라 서로 다른 정보를 가질 수 있으며, 정보 보유자가 사망해도 이미 다른 유닛에게 전달된 사본은 유지된다.

| 구분 | 의미 | 주요 사용 |
| :---: | :---: | :---: |
| 직접 정보 | 자신의 인지 범위에서 직접 확인한 결과 | 대상의 존재·위치·정체 확인, 기록 검증 |
| 전파 정보 | 다른 유닛에게 전달받은 확인 정보 | 접근·수색·목표·경로 설정, 합류 판단 |
| 일시 간접입력 | 소리·공격 방향으로 얻은 임시 사건 정보 | 시야 전환, 경계, 확인 방향·추정 지역 설정 |

대표 가중치 3종은 전체 행동 우선순위를 대신하는 단일 점수가 아니다.   
현재 상태와 행동 우선순위가 수행할 행동 범주를 결정하고, 위험도·흥미도는 그 범주 안에서 대상·위치의 목표·경로 후보를 평가하며, 이해도는 대상 정보 활용과 대응 판단에 사용한다.

따라서 소리와 전파는 가중치와 같은 점수로 경쟁하지 않는다.   
소리는 사건 반응 입력을 만들고, 전파는 개인 기록을 갱신한다.   
일반 사실 정보를 전달받은 것 자체로 대표 가중치가 직접 변하지 않으며, 별도 예외가 정의된 사건만 해당 시스템의 가중치 규칙을 따른다.

# **4\. 전파 정보와 직접 인지의 구분**

전파받은 정보가 구체적이더라도 수신 유닛의 직접 인지 결과로 취급하지 않는다.   
특정 적의 종류와 마지막 확인 위치를 전달받았더라도 그 적이 현재 그 위치에 존재한다고 확정할 수 없다.

직접 확인이 필요한 경우는 다음과 같다. 

* 전달받은 마지막 확인 위치에 대상이 실제 존재하는지 확인  
* 수상한 위치의 원인이 된 대상의 정체 확인  
* 사망 원인이나 상태 변화처럼 직접 확인 여부가 후속 처리에 영향을 주는 사건 확인

미인식 대상의 재인지 조건과 직접 판정은 02 인지·정보판정·실패처리를 따른다.

# **5\. 전파 대상 정보**

* 확인한 타일 정보  
* 정확 인지한 적의 존재·종류·마지막 확인 위치·확인 시점  
* 함정·건물·시체의 확인 정보와 직접 확인한 상태 변화  
* 조사 완료 결과와 코어 정보  
* 파티원 사망 사실과 확인된 사망 원인 정보  
* 진행 중·완료·취소된 조사·함정 해제 등 상호작용 상태 정보  
* 함정 피해처럼 별도 시스템이 전파 가능 사실 정보로 정의한 사건 결과

각 정보의 생성 조건은 02·03 및 해당 시스템 문서를 따른다.   
본 문서는 생성된 정보의 전달·보유·재전파만 정의한다.

소리로 얻은 추정 지역과 공격 방향은 일반 사실 정보처럼 자동 재전파하지 않는다.   
단, 적을 정확 인지하기 전에 공격받은 경우의 최초 전달 예외는 7-2를 따른다.

# **6\. 일반 전파 조건**

일반 전파는 다음 조건을 모두 만족할 때 가능하다.

* 발신자와 수신자가 모두 비전투 상태다.  
* 발신자와 수신자가 같은 방 또는 같은 통로 공간에 있다.  
* 07\_A의 공통 공간 판정으로 계산한 전파 범위 안에 있다.  
* 발신자가 실제로 보유한 정보만 전달할 수 있다.  
* 수신자가 해당 정보를 모르거나 발신자가 더 최신의 갱신 정보를 보유한다.

전파 가능 정보가 새로 생성·갱신되거나, 일반 전파 조건을 만족하는 미보유 유닛이 존재하면 전파를 수행할 수 있다.   
사망 정보와 전투 진입·전투 합류의 일부 전파는 아래 예외 규칙을 우선한다.

다른 파티 사이의 전파 적용 범위와 조건은 파티 구조 확정 후 별도 문서에서 정의한다.

# **7\. 전투 진입 시 전파 예외**

## **7-1. 적을 먼저 정확 인지한 경우**

비전투 상태에서 적을 정확 인지하면 전파 가능한 경우 적 정보를 1회 전달한다.

이후 근거리 여부를 판정한다.

근거리에서는 합류 대기 없이 즉시 전투로 전환하고, 근거리가 아니면 현재 알고 있는 위험도 단계에 따라 즉시 전투 또는 합류 대기를 선택한다.   
전투로 전환한 원거리 역할 유닛은 현재 적과의 거리가 자신의 선호 교전거리보다 가까운 경우 거리 확보 행동을 수행한다. 거리 확보 시 아군 방향을 우선하며, 선호 교전거리의 설정과 실제 이동 위치·경로 선정은 전투 행동 및 09에서 정의한다. 

합류가 필요한 경우 적 정보를 받은 합류 가능 유닛은 발견자에게 합류 의사를 전달한다.   
응답자가 있으면 실제 아군이 합류할 때까지 기다리고, 응답자가 없으면 발견자가 단독으로 전투를 시작한다.   
대기 중 적이 먼저 공격하면 위험도와 합류 여부를 무시하고 즉시 전투로 전환한다.

합류 대기 중 발견자는 가장 가까운 정확 인지 적을 향해 시야를 유지하고 방어 계산을 활성화한다.   
근거리 기준, 위험도 단계별 처리와 대기 시간은 07\_A에서 정의한다.

## **7-2. 적을 정확 인지하기 전에 공격받은 경우**

적을 정확 인지하기 전에 공격받은 경우 일반 전파의 발신자 상태 조건에 대한 예외로 정보를 1회 전파할 수 있다. 

* 자신이 공격받았다는 사실  
* 공격 형태상 확인 가능한 공격 방향  
* 공격자를 이미 정확 인지했다면 해당 공격자 정보

이 예외는 발신자의 상태 조건만 예외 처리하며, 수신자의 상태·동일 공간·전파 범위 조건은 일반 전파 규칙을 따른다.

이후 상태 전환과 공격 방향에 따른 행동은 17을 따른다. 

## **7-3. 전투 합류용 예외 전파**

전투 현장에 새로운 아군이 전파 범위 안으로 처음 들어온 경우, 전투 중인 유닛은 일반 비전투 전파 제한의 예외로 현재 정확 인지 중인 적 정보를 1회 전달할 수 있다. 

* 전달: 적 존재·종류·마지막 확인 위치·확인 시점  
* 위험도·이해도 수치 자체는 전달하지 않음

수신자는 현재 전투에 합류하며 위험도 단계별 합류 대기를 다시 수행하지 않는다.

# **8\. 사망 정보 특례**

파티원 사망 정보는 일반적인 비전투 전파 조건보다 사망 정보 규칙을 우선한다.   
사망 순간을 직접 목격하거나 시체를 발견하면 사망 정보 기록·정신력 처리·최초 전파를 03의 사망 규칙에 따라 수행한다.

사망 정보의 수신과 재전파, 원인 미확인 시 시체 중심 탐색은 03 탐색반응의 사망 처리 규칙을 따른다.

# **9\. 재전파와 정보 동기화**

정보를 수신한 유닛은 해당 정보의 새로운 보유자가 된다.

* 정보를 수신한 것과 같은 전파 처리에서는 해당 정보를 다시 전달하지 않는다.

* 이후 전파 판정에서 일반 전파 조건을 만족하는 미보유 유닛이 있으면 해당 정보를 재전파할 수 있다.

* 동일 정보는 중복 처리하지 않고, 확인 시점을 가지는 정보는 더 최신 정보만 갱신한다.

* 분산된 유닛이 다시 만난 경우 서로 보유하지 않은 전파 가능 정보를 교환할 수 있다 

# **10\. 상호작용 정보와 보호 포메이션**

조사 또는 함정 해제가 실제 시작되면 상호작용 유닛은 해당 대상을 처리 중이라는 진행 중 정보를 최초 전파한다.

상호작용 유닛 본인의 최초 전파를 직접 받은 일반 탐색 유닛만 보호 포메이션 참여 대상이 된다.   
상호작용 유닛을 시야에서 직접 확인한 것만으로는 참여하지 않는다.

진행 중 정보는 일반 전파 규칙에 따라 재전파할 수 있다.   
재전파 수신자는 보호 포메이션에는 참여하지 않지만, 같은 대상에 대한 중복 조사·해제 목표를 선택하지 않는다.

상호작용 완료자는 완료 정보를 전파하며 수신자는 진행 중 기록을 완료 상태로 갱신한다.   
상호작용이 취소되면 취소 정보는 유닛이 보유하고, 전파 가능한 상태가 되면 전달하여 수신자의 진행 중 기록을 해제한다. 상호작용 수행자의 사망 사실을 직접 확인하거나 전파받은 경우에도 해당 진행 중 기록을 해제한다. 

소리 반응으로 상호작용·보호 포메이션이 중단되는 조건과 중단 이후의 진행도·재합류·재구성 처리는 16장과 03을 따른다.

# **11\. 합류 통신과 일반 정보 전파**

일반 정보 전파와 합류 통신은 구분한다.

| 구분 | 처리 |
| :---: | :---: |
| 일반 사실 정보 | 개인 기록으로 보유하며 일반 전파 조건에 따라 재전파 가능 |
| 합류 통신 | 특정 목표에 참여하기 위한 요청·의사. 장기 사실 정보로 기록하지 않으며 일반 재전파를 적용하지 않음 |

적 발견 후 합류가 필요한 경우 발견자는 적 정보를 전파한 뒤 합류 의사 응답을 기다린다.   
파티 목표에 대한 합류 요청·전달 방식은 03의 합류 규칙을 따른다.

# **12\. 전파·소리의 공간 판정**

전파와 소리는 동일한 방 또는 통로 공간 내부에서만 전달된다.

벽이나 통과 불가능한 구조를 무시하고 직선으로 관통하지 않는다.

실제 거리 계산과 도달 판정은 07\_A를 따른다. 

# **13\. 정보의 최신성과 갱신**

위치가 변할 수 있는 대상은 마지막 확인 위치와 확인 시점을 보유한다.   
전파받은 위치는 전달자가 마지막으로 직접 확인한 시점의 위치 정보다.

전파 시점이 새로운 확인 시점으로 취급되지 않으며, 전달된 위치를 대상의 현재 위치로 확정하지 않는다. 

더 최신의 확인 정보가 들어오면 마지막 확인 위치와 확인 시점을 갱신하고, 더 오래된 정보는 기존 기록을 유지한다.

기록된 위치가 인지 범위에 들어오고 해당 위치에 대상이 존재하지 않음을 직접 확인하면 기존 마지막 위치를 무효화할 수 있다.   
이후 수색·목표·경로 재설정은 03과 09가 처리한다.

소리로 얻은 넓은 추정 지역은 더 구체적인 마지막 확인 위치를 자동으로 덮어쓰지 않는다.

# **14\. 소리 발생 구조**

소리는 전투 상태 자체에서 주기적으로 발생하지 않고 실제 사건이 발생할 때 각각 생성된다.

본 문서에서 전투 관련 소리는 공격 실행음·피격 발생 공격음·피격 비명·사망음을 의미하며, 이동음과 함정 작동음은 별도로 구분한다 

* 이동 시 이동음 발생  
* 공격 실행 시 공격자 위치에서 공격 실행음 발생  
* 공격이 적중하면 피격 위치에서 별도의 피격 발생 공격음 발생  
* 큰 피해 조건을 만족하면 피격 위치에서 피격 비명 발생  
* 사망 시 사망 위치에서 사망음 발생  
* 함정 작동 시 작동 위치에서 함정 작동음 발생

공격 실행음과 피격 발생 공격음은 서로 다른 이벤트다.   
원거리 공격은 공격자 위치와 피격 위치에서 각각 별도의 소리가 발생할 수 있다.   
각 기본 범위와 피격 비명 조건은 07\_A에서 정의한다.

# **15\. 소리로 얻는 정보**

| 소리 종류 | 획득 정보 | 자동으로 알 수 없는 정보 |
| :---: | :---: | :---: |
| 이동음 | 발생 방향 | 대상 정체·정확 위치 |
| 공격 실행음 | 발생 방향 \+ 전투 관련 추정 지역 | 공격자 정체·정확한 공격자 위치 |
| 피격 발생 공격음 / 피격 비명 / 사망음 | 사건 방향 \+ 전투 관련 추정 지역 | 정확한 적 위치·사건 당사자 정체·원인 |
| 함정 작동음 | 작동 방향 \+ 더 좁은 추정 지역 | 정확한 함정 위치·종류·현재 상태 |

추정 지역은 실제 사건 위치를 중심으로 생성하지만 중심점을 정확 위치로 기록하지 않는다.   
유닛은 원형 추정 지역 전체를 미확인 영역으로 취급하고, 중심 방향은 시야 전환과 접근 계산에만 사용한다.

적 위치 전파는 다른 유닛이 직접 확인한 특정 마지막 위치와 확인 시점을 전달하지만 소리는 방향과 추정 지역만 제공한다.   
따라서 추정 지역에서는 실제 대상을 추가로 직접 확인해야 한다.

# **16\. 소리 감지와 행동 반응**

## **16-1. 공통 원칙**

소리 감지는 인류와 몬스터 모두 사용한다.   
소리 내부 우선순위는 여러 소리 중 어느 소리에 반응할지를 고르는 기준일 뿐 전체 행동 우선순위가 아니다.   
최종 행동 가능 여부는 현재 상태·행동 우선순위를 따르며, 선택된 소리 방향은 01-A의 전체 시야 방향 후보 체계에서 다른 후보와 함께 비교한다.

소리는 임시 위험도·흥미도를 생성하지 않는다.   
소리 반응으로 확인 행동이 생기고, 실제 대상·사건을 확인한 뒤 해당 시스템의 가중치·목표·경로 처리를 수행한다.

## **16-2. 이동음**

자신의 이동음과 모든 아군의 일반 이동음은 반응 대상에서 제외한다.   
적·미확인 이동음을 감지하면 더 높은 행동이 없는 경우 해당 방향으로 시야를 전환하고 인지 판정을 한 번 수행한다.   
별도 위치 추적 이동은 하지 않는다.

이동음 반응으로 적을 정확 인지하면 일반 적 인지 후 전투 진입 규칙을 따른다.   
적을 확인하지 못하면 잠시 시야를 유지한 뒤 기존 목표가 유효하면 재개한다.   
시야 유지 자체로 추가 인지 판정을 수행하지 않으며, 02에서 정의한 재인지 조건이 발생한 경우에만 새 판정을 수행한다. 

## **16-3. 추정 지역형 소리**

공격 실행음과 함정 작동음은 원인이 미확인된 사건이므로 선택되면 경계 상태로 추정 지역을 확인하러 접근한다. 

공격 실행음·함정 작동음의 확인 과정에서 적을 정확 인지하면 일반 적 인지 후 전투 진입 규칙을 따른다.

피격 발생 공격음·피격 비명·사망음의 확인 과정에서 적을 정확 인지하면 거리·위험도 단계와 관계없이 즉시 전투에 합류한다.   
피격 발생 공격음·피격 비명·사망음은 실제 피해 또는 사망 사건이 발생한 긴급 소리이므로 경계 상태의 이동속도 감속을 적용하지 않고 정상 이동속도로 현장을 확인한다. 

추정 지역의 중심이 인지 범위에 들어오는 거리까지 접근해 확인하고, 원인을 확인하지 못하면 해당 방향을 잠시 바라본 뒤 소리 확인 행동을 종료한다.   
시체를 발견하면 03의 사망·원인 탐색 규칙으로 전환한다.

## **16-4. 기존 행동과의 우선관계**

전투 관련 소리와 이동음은 일반 조사·함정 해제·보호 포메이션 참여·함정 대응 대기·일반 아군 합류 대기를 해당 소리를 감지한 유닛에 한해 중단시킬 수 있다.

| 현재 행동 | 전투 관련 소리 / 이동음 | 함정 작동음 |
| :---: | :---: | :---: |
| 일반 조사 | 중단 | 현재 행동 유지 |
| 함정 해제 | 중단 | 현재 행동 유지 |
| 보호 포메이션 참여 | 해당 소리 감지 유닛만 이탈 | 현재 행동 유지 |
| 함정 대응 대기 | 중단 | 현재 행동 유지 |
| 일반 아군 합류 대기 | 중단 | 현재 행동 유지 |
| 정확 인지 적에 대한 전투 합류 대기 | 현재 적 대상 행동 우선 | 현재 적 대상 행동 우선 |
| 파티 목표·코어 상호작용 당사자 | 현재 행동 유지 / 소리 반응 안함 | 현재 행동 유지 / 소리 반응 안함 |

함정 작동음처럼 현재 행동을 중단시키지 않는 소리는 07\_A의 유효시간·보류 조건을 만족하는 경우, 현재 행동 종료 시점에도 정보가 유효하면 확인 행동을 시작할 수 있다. 

`‘소리 반응 안함’`으로 처리된 소리는 보류하지 않는다. 

중단 이후 진행도 손실, 보호 포메이션 해제·재합류·재구성 처리는 03을 따른다.

## **16-5. 전투·도주·후퇴·퇴각 중 소리**

* 현재 공격 목표가 있으면 소리로 시야 전환·확인 행동·보류를 하지 않는다.  
* 현재 공격 목표가 없으면 공격 실행음·피격 발생 공격음·피격 비명·사망음·이동음을 새 전투 목표 후보 탐색 입력으로 사용할 수 있다.  
* 함정 작동음은 전투 상태의 새 공격 목표 탐색 입력에서 제외한다.

전투 중 새 목표 선정과 이동 방식은 전투 타겟 변경 규칙과 09에서 정의한다.

도주 또는 상태 악화에 따른 후퇴 중에는 소리 반응을 사용하지 않는다.

* 목표 완료 후 퇴각 중에는 이동을 유지한 채 소리 방향으로 시야만 전환하고 새 확인 목표를 만들지 않는다.  
* 퇴각 중 이동음은 별도 2초 정지를 적용하지 않는다.  
* 퇴각 중 적이 근거리 즉시 전투 기준 안에 있거나 선공하면 전투로 전환한다.   
  더 먼 적은 기록·전파 후 퇴각을 계속한다.

## **16-6. 몬스터**

몬스터는 소리 감지와 방향·추정 지역 획득까지만 공통 규칙을 사용한다.   
인류의 조사 중단·합류 대기·연출 대기 규칙은 사용하지 않고 각 역할군 AI가 감지 결과를 해석한다.

# **17\. 공격 방향 간접입력**

직접 피격은 피격 사실과 피해를 확정하지만 공격자의 정확 인지를 의미하지 않는다.

공격 방식상 방향을 확인할 수 있으면 공격 방향을 간접입력으로 획득한다.   
근접 공격은 공격원 방향, 투사체·원거리·투사체 마법은 진행 방향을 사용할 수 있으며, 방향을 특정할 수 없는 광역·지면 영역 공격은 방향 정보를 생성하지 않는다.   
함정은 공격 방향 입력을 사용하지 않는다.

공격자를 정확 인지하면 전투로 전환한다.   
공격자를 인지하지 못했지만 방향을 알면 경계 상태에서 해당 방향을 확인하며 접근하고, 방향도 알 수 없으면 경계 상태에서 주변을 확인한다.

공격 방향은 일반 재전파 대상이 아니다. 단, 7-2의 선공 예외에서 최초 전달 정보로 포함될 수 있다.
