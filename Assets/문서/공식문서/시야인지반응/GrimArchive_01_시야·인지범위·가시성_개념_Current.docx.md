# **01\_시야·인지범위·가시성\_개념\_Current**

v0.2 / 개념 문서

# **0\. 개요**

본 문서는 GrimArchive의 시야 범위, 인지 범위, 시야 방향, 대상 기본 가시성의 개념을 정의한다.

시야는 유닛이 전방 공간을 확인하는 구조다.   
인지는 그중 실제 대상을 판별하고 행동 후보를 만들 수 있는 구조다.   
가시성은 대상이 얼마나 잘 드러나는지를 나타내며, 인지 성공/실패에 직접 영향을 준다.

본 문서는 세부 수치와 계산식을 다루지 않는다.   
시야 거리, 인지 거리, 인지각, 공격 후 가시성 상승량, 시야 방향 전환 후보 처리 과정과 우선순위는 01-A 연산공식 문서에서 다룬다.

# **1\. 시야 시스템의 2단 구조**

| 구분 | 의미 | 주요 결과 |
| :---- | :---- | :---- |
| 시야 범위 | 유닛 정면의 넓은 원뿔형 확인 범위 | 타일 위치, 비어 있지 않은 타일 존재, 임시 위험도/흥미도, 경로 판단 정보 |
| 인지 범위 | 시야 범위 안쪽의 실제 판정 범위 | 유닛/오브젝트 인지 판정, 안전 확인, 행동 후보 생성 |

시야 범위에 들어왔다고 해서 대상을 정확히 인지한 것은 아니다.   
정확한 인지는 인지 범위 안에서 인지 성공 판정이 발생했을 때 가능하다.

# **2\. 시야 범위**

시야 범위는 유닛 정면의 넓은 원뿔형 범위다.   
유닛은 시야 범위를 통해 전방의 공간 구조와 비어 있지 않은 타일 존재를 먼저 파악한다.

시야 범위에서 가능한 처리는 다음이다.

| 1\. 타일 위치 확인 2\. 미확인 타일 위험도/흥미도 유지 3\. 시야 범위 내 비어 있지 않은 타일 존재 4\. 비어 있지 않은 타일에 임시 위험도/흥미도 적용 5\. 경로 판단 정보 생성 |
| :---- |

비어 있지 않은 타일은 시야 범위 단계에서 정확한 정체를 모르는 타일이다.

| 시야 범위 안에 어떤 대상이 있음 ↓ 해당 타일은 비어 있지 않은 타일로 처리 ↓ 정확히 유닛인지, 함정인지, 건물인지, 시체인지, 전멸 흔적인지는 아직 모름 ↓ 임시 위험도/흥미도 적용 ↓ 인지 범위에 들어오면 인지 판정 수행 |
| :---- |

# **3\. 시야 범위 내 임시 위험도/흥미도**

시야 범위에 들어온 빈 타일은 미확인 타일의 위험도/흥미도를 유지한다.

| 상태 | 처리 |
| :---- | :---- |
| 빈 타일 | 미확인 타일 위험도/흥미도 유지 |
| 비어 있지 않은 타일 | 미확인 타일 위험도/흥미도 \+ 임시 위험도/흥미도 |

이 임시값은 저장값이 아니다. 현재 유닛 또는 파티가 경로와 탐색 방향을 판단할 때만 사용하는 임시 판단값이다.

| 인지 범위 진입 ↓ 임시 위험도/흥미도 제거 ↓ 인지 성공/실패 판정 ↓ 인지 결과에 따라 실제 판단으로 전환 |
| :---- |

# **4\. 인지 범위**

인지 범위는 시야 범위 안쪽의 실제 판정 범위다.

인지 범위 안에서는 다음 처리가 가능하다.

| 1\. 유닛 인지 판정 2\. 오브젝트(함정, 건물, 시체, 전멸 흔적) 인지 판정 3\. 직접 인지 처리 4\. 안전 확인 처리 5\. 안전 확인 조건 충족 시 타일 위험도/흥미도 감소 |
| :---- |

인지 범위는 시야 범위 안에 존재한다.   
인지각이 감지 스탯에 의해 최대치까지 증가하면, 시야 범위 전체가 인지 범위화될 수 있다.

**5\. 안전 확인과 안전 타일**

안전 확인은 인지 범위 안에서 해당 타일을 직접 확인한 뒤, 현재 인지 가능한 적 유닛, 위험 오브젝트가 없다고 판단하는 처리다.  
위험 오브젝트는 함정 또는 공격/피해/경로 차단/전투 불리/정신력 감소를 유발할 수 있는 모든 오브젝트를 말한다. 

안전 타일은 안전 확인이 완료된 타일이다. 

| 안전 확인 조건은 다음과 같다. 1\. 해당 타일이 인지 범위 안에 있음 2\. 완전 차단 구조로 가려져 있지 않음 3\. 현재 인지 가능한 적 유닛이 없음 4\. 현재 인지 가능한 위험 오브젝트가 없음 |
| :---- |

안전 확인 조건을 충족하면 해당 타일의 위험도/흥미도 감소가 가능하다.   
실제 감소 처리와 수치는 03\_가중치판단\_인지결과연동 문서에서 다룬다.

안전 타일은 실제로 완전히 안전하다는 뜻이 아니다.   
인지 실패로 미인식 처리된 경우, 실제로는 위험 요소가 존재해도 유닛은 해당 타일을 안전하다고 오판할 수 있다.

# **6\. 오브젝트 범주**

본 문서에서 오브젝트는 유닛이 아닌 인지 대상이다.

| 오브젝트 ├─ 함정 ├─ 건물 ├─ 시체 └─ 전멸 흔적 |
| :---- |

오브젝트는 인지 성공 후 종류에 따라 조사, 해제, 우회, 파괴, 위험도 증가, 흥미도 판단 등으로 연결된다. 

| 대상 | 연결 문서 |
| :---- | :---- |
| 함정 대응 | 탐색반응/함정 대응 문서 |
| 건물 조사 | 조사 문서 및 가중치 연동 문서 |
| 시체/전멸 흔적 조사 | 조사 문서 및 위험도 증가 공식 |

# **7\. 범위 판정 기준**

시야 범위와 인지 범위는 타일 전체가 원뿔 안에 들어올 필요가 없다.

| 1\. 타일 일부가 시야 범위와 겹치면 시야 판정 대상이 된다. 2\. 타일 일부가 인지 범위와 겹치면 인지 판정 대상이 된다. 유닛과 오브젝트도 마찬가지다. 대상의 위치 또는 점유 영역이 시야 범위나 인지 범위와 일부라도 겹치면 판정 대상이 된다. |
| :---- |

이 기준은 방이나 복도 가장자리에 걸친 대상을 자연스럽게 처리하기 위한 기준이다.

# **8\. 감지 스탯의 영향**

감지 스탯은 시야와 인지에 모두 영향을 준다.

| 1\. 시야 거리 2\. 인지 거리 3\. 인지각 4\. 인지 확률 |
| :---- |

시야각은 감지 스탯의 영향을 받지 않는다. 시야각은 고정이다.

인지각은 감지 스탯의 영향을 받는다.   
감지 스탯이 높아질수록 유닛은 더 멀리 보고, 더 멀리 인지하며, 더 넓은 인지각을 가지게 된다.

# **9\. 대상 기본 가시성**

대상 기본 가시성은 대상이 기본적으로 얼마나 잘 드러나는지를 나타낸다.

대상 기본 가시성 적용 대상은 다음이다.

| 1\. 유닛 2\. 오브젝트 3\. 특수 타일 4\. 벽, 일반 타일 |
| :---- |

일반 타일은 가시성  100으로 벽은 0으로 처리한다.   
일반 타일 가시성과 다른 타일 가시성은 일부 특수 타일에만 사용한다.  
오브젝트나 유닛이 존재하는 타일의 가시성은 무효화되고 각 유닛, 오브젝트의 가시성으로 처리한다.

가시성이 높으면 인지 성공 확률이 증가하고, 가시성이 낮으면 미인식 또는 수상한 타일 가능성이 증가한다.

가시성은 대상 자체의 기본 가시성, 은신, 거리, 가림 보정, 공격 후 노출 상태에 의해 달라진다.

# **10\. 은신과 가시성**

은신은 유닛의 가시성을 낮추는 세부 스탯이다.

| 은신(Stealth) → 유닛 최종 가시성을 낮춤 → 인지 실패 가능성 증가 |
| :---- |

은신이 높은 유닛은 시야 범위나 인지 범위 안에 들어와도 쉽게 식별되지 않는다.  
이 경우 유닛은 미인식되거나 수상한 타일로 처리될 수 있다.

# **11\. 오브젝트/유닛 가림 보정**

시야 경로상 대상 앞에 비벽 오브젝트나 유닛이 있으면 뒤쪽 대상의 가시성이 낮아진다.

벽이나 완전 차단 오브젝트 뒤의 대상은 시야 판정이 불가능하다.

| 상황 | 처리 |
| :---- | :---- |
| 벽/완전 차단 오브젝트 뒤 대상 | 시야 판정 불가 |
| 비벽 오브젝트/유닛이 같은 시야 경로상에 있음 | 뒤쪽 대상 가시성 감소 |

가림 보정은 완전 차단이 아니다. 대상은 여전히 시야 범위 안에 있을 수 있으나, 인지 성공 확률이 낮아진다.

이미 인지된 대상은 비벽 오브젝트나 유닛 뒤로 이동해 가시성이 낮아져도 미인식이나 수상한 타일로 바뀌지 않는다.   
다만 시야 범위 밖으로 완전히 벗어나거나 완전 차단 구조 뒤로 이동한 후에는 인지 판정을 다시 한다.

# **12\. 공격에 따른 가시성 상승**

가림 보정이나 낮은 기본 가시성 때문에 잘 드러나지 않던 대상도 공격하면 가시성이 상승한다.

| 대상이 공격함 ↓ 공격한 유닛 또는 공격 기능을 가진 방어 건물의 가시성 상승  ↓ 인지 재판정 가능 |
| :---- |

공격 후 가시성은 일정 시간 동안 상승한다.   
고정 시간 안에 추가 공격이 발생하면 지속 시간이 초기화된다.   
가시성이 최대치에 도달한 경우 추가 공격으로 더 상승하지 않는다.

# **13\. 시야 방향**

시야 방향은 유닛이 현재 바라보는 방향이다.   
시야 범위와 인지 범위는 시야 방향을 기준으로 생성된다.

| 상황 | 시야 방향 |
| :---- | :---- |
| 이동 중 | 이동 방향 |
| 전투 중 | 현재 공격 대상 방향 |
| 스킬 사용 중 | 스킬 사용 방향 |
| 경계 상태 | 경계 대상 방향 |
| 소리 감지 | 조건부로 소리 방향 |
| 기습 피격 | 기습 방향 |
| 리더 명령 | 명령 대상 방향 |
| 플레이어 명령 | 지정 목표 방향 |
| 경로 재설정 후보 등록 | 확인이 필요한 타일 방향 |

스킬 사용 중에는 스킬 사용 방향을 바라본다.

전투 중 1칸 이내 근접 적이 있는 경우에는 기본적으로 근접 대상 방향을 유지한다.   
다만 기습 피해 기대값 또는 실제 피해가 현재 근접 유닛 공격 기대값보다 충분히 높으면, 기습 방향으로 시야 방향을 갱신할 수 있다.

시야 방향 전환의 세부 우선순위는 연산공식 문서에서 다룬다.

# **14\. 소리와 시야 방향**

소리는 직접 인지가 아니라 간접 입력이다. 소리를 감지하면 해당 방향이 시야 방향 전환 후보로 등록 될 수 있다.

| 소리 감지 ↓ 소리 방향 확인 ↓ 현재 전투 상태 확인 ↓ 조건 충족 시 소리 방향을 시야 방향 전환 후보로 등록  |
| :---- |

전투 중 1칸 이내 근접 적이 있는 경우에는 소리 방향 전환보다 현재 근접 대상 유지가 우선될 수 있다.

# **15\. 특수 원형 인지 범위**

일부 특수 유닛은 원뿔형 인지 범위 외에 원형 인지 범위를 가진다.

| 1\. 엘리트 2\. 네메시스 3\. 보스 |
| :---- |

원형 인지 범위는 정면을 보지 않아도 주변 위협을 감지하는 보조 범위다.   
원형 인지 범위는 일반 유닛에게 기본 적용하지 않는다.

# **16\. 인류와 몬스터의 차이**

시야와 인지 구조는 인류와 몬스터 모두 사용한다. 하지만 인지 이후 판단 방식은 다르다.

| 진영 | 인지 이후 판단 |
| :---- | :---- |
| 인류 | 대표 가중치 3종 → 파티 목표 / 리더 명령 / 클래스 역할 반영 → 행동 결정 |
| 몬스터 | 역할군 AI → 탐색 우선순위 → 행동 결정 |

몬스터는 정신력 보정이 없다.   
몬스터는 전파를 사용하지 않는다.   
몬스터는 소리와 역할군 AI를 중심으로 판단한다.

플레이어가 명령을 내리면 플레이어 진영 몬스터는 해당 명령을 우선 반영한다.
