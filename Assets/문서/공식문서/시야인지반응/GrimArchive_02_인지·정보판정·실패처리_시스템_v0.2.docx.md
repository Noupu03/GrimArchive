**02\_인지·정보판정·실패처리\_시스템**

*v0.2 / 시스템 문서 / 수정용 초안*

# **0\. 개요**

본 문서는 인지 판정, 정확 인지, 인지 실패, 미인식, 수상한 타일, 직접 인지, 간접 인지의 구조를 정의한다.

시야 범위와 인지 범위가 “대상이 판정 대상이 되는가”를 정하는 구조라면, 본 문서는 그 대상이 실제로 어떻게 인식되는지, 인식에 실패했을 때 어떤 상태로 처리되는지, 그리고 그 결과가 어떤 후속 시스템으로 연결되는지를 다룬다.

# **1\. 인지 시스템의 목적**

인지 시스템은 유닛이 “무언가를 보았다”와 “정확히 무엇인지 알아차렸다”를 구분하기 위해 필요하다.

인지 시스템이 필요한 핵심 목적은 다음과 같다.

1\. 은신과 기습을 비롯한 전략의 폭을 넓히기 위해

2\. 은신 유닛과 낮은 가시성 대상을 표현하기 위해

3\. 플레이어가 배치한 함정, 몬스터, 방어 구조물이 항상 즉시 드러나지 않게 하기 위해

4\. 인류 파티의 목표 설정과 이동 경로 판단에 필요한 정보를 구분하기 위해

5\. 직접 확인한 정보와 간접적으로 전달받은 정보를 구분하기 위해

시야 범위에 들어온 모든 대상과 타일이 즉시 정확히 판별되면 전략이 단순해진다.

따라서 시야 범위와 인지 범위를 구분하고, 인지 범위 안에서 정확 인지, 수상한 타일, 미인식, 안전 확인을 나누어 처리한다.

# **2\. 인지 판정 대상**

인지 판정은 인지 범위 안에 들어온 유닛, 오브젝트, 일반 타일을 대상으로 발생한다.   
다만 모든 대상이 같은 방식의 확률 판정을 사용하는 것은 아니다.

| 대상 | 인지 판정 여부 | 처리 방식 |
| :---- | :---- | :---- |
| 유닛 | O | 가시성/은신 기반 확률 판정 |
| 함정 | O | 기본 가시성 기반 확률 판정 |
| 건물 | O | 기본 가시성 또는 가시성 100 기반 판정 |
| 시체 | O | 가시성 100 기반 판정 |
| 전멸 흔적 | O | 가시성 100 기반 판정 |
| 미확인 일반 타일 | O | 안전 확인 판정 |
| 특수 타일 | 현재 02 문서에서는 독립 인지 대상으로 다루지 않음 | 유닛 또는 오브젝트가 존재하는 타일이 특수 타일일 경우, 해당 타일의 추가 조건은 11\_타일·지형효과·특수타일\_시스템 문서에서 다룬다.  |

시야 범위에서 미확인 타일로 관리되던 일반 타일이 인지 범위 안에 들어오면 안전 확인 판정 대상이 된다.   
해당 타일에 현재 인지 가능한 유닛, 함정, 건물, 시체, 전멸 흔적이 없으면 안전타일로 취급된다.  
안전 확인 이후 위험도/흥미도 감소는 03\_인지결과·가중치입력\_시스템 문서에서 다룬다.  
특수 타일은 별도 문서에서 다룬다.

# **3\. 인지 판정의 기본 결과**

인지 판정은 인지 범위 안에 들어온 대상 또는 타일이 관찰자에게 어떻게 인식되는지를 결정한다.

| 결과 | 의미 | 기본 후속 |
| :---- | :---- | :---- |
| 정확 인지 | 대상의 유형과 위치를 식별함 | 인지 결과 정보 생성, 반응 후보 생성 |
| 수상한 타일 | 무언가 있다는 것은 느꼈지만 정체를 식별하지 못함 | 경계 상태로 접근해 확인 |
| 미인식 | 대상을 전혀 인식하지 못함 | 안전타일로 인지됨 |
| 안전 확인 | 일반 타일 또는 미인식 결과를 안전타일로 처리함 | 일반 타일과 동일하게 취급, 03 문서의 가중치 감소로 연결 |
| 간접 인지 | 직접 확인이 아니라 전파/전투음/공격 방향 추정 등으로 정보를 얻음 | 방향 정보, 위험 정보, 목표/경로 판단 정보 생성 |

정확 인지는 단순히 “시야에 들어왔다”는 뜻이 아니다.   
대상의 정체를 판별하고, 그에 맞는 반응 후보를 만들 수 있는 상태를 의미한다.

# **4\. 인지 판정 발생 조건**

인지 판정은 대상 또는 타일이 실제로 인지 범위 안에 들어오고, 관찰자가 그 대상을 판정할 수 있는 조건을 만족할 때 발생한다.

| 1\. 대상 또는 미확인 일반 타일이 인지 범위 안에 처음 들어옴 2\. 기존에 인지했던 대상이 시야 범위 밖으로 벗어난 뒤 다시 시야/인지 범위에 들어옴 3\. 기존에 인지했던 대상이 완전 차단 구조 뒤로 이동한 뒤 다시 나타남 4\. 수상한 타일에 2칸 이내로 접근함 5\. 인지 범위 안에 있으나 미인식 또는 수상한 타일로 처리된 대상이 공격한 경우, 공격 후 가시성 증가를 반영해 인지 판정을 다시 수행. |
| :---- |

인지 판정은 매 프레임 반복되는 처리가 아니다.   
대상 진입, 시야 밖 이탈 후 재진입, 완전 차단 후 재등장, 수상한 타일 접근처럼 명확한 갱신 조건이 있을 때 수행한다.

조사와 상호작용은 인지 판정 발생 조건이 아니다.   
조사와 상호작용은 인지 성공 이후 선택될 수 있는 반응이다.

직접 피격, 전투음, 전파, 공격 방향 추정은 그 자체로 인지 판정 발생 조건이 아니다.   
이 입력들은 방향 정보 또는 위험 정보를 제공하며, 시야 방향 전환 후보, 목표 재설정 후보, 경로 재설정 후보로 연결된다.

# **5\. 인지 판정 기본 조건**

| 1\. 대상 또는 미확인 일반 타일이 인지 범위 안에 있음 2\. 대상 또는 타일이 벽 또는 완전 차단 구조 뒤에 있지 않음 3\. 관찰자가 인지 판정을 수행할 수 있는 상태임 |
| :---- |

| 상태 | 처리 |
| :---- | :---- |
| 기절 | 인지 판정 불가 |
| 수면 | 인지 판정 불가 |
| 마비 | 인지 판정 불가 |
| 행동 불능 | 인지 판정 불가 |

이 목록은 차후 상태이상 문서에서 수정 또는 추가될 수 있다.

# **6\. 가시성 산출 기준**

가시성은 대상이 얼마나 잘 드러나는지를 나타낸다.   
가시성은 높을수록 잘 보이는 값이다.

| 대상 유형 | 가시성 산출 방식 |
| :---- | :---- |
| 은신 스탯 보유 대상 | 은신 스탯을 가시성으로 변환 |
| 은신 스탯 미보유 대상 | 대상 기본 가시성 사용 |
| 함정 | 대상 기본 가시성 사용 |
| 특정 건물 | 대상 기본 가시성 사용 |
| 일반 건물 | 가시성 100 |
| 시체 | 가시성 100 |
| 전멸 흔적 | 가시성 100 |
| 일반 타일 | 유닛/오브젝트 가시성 없음. 안전 확인 대상으로 처리 |

유닛은 은신 스탯을 보유할 수 있다.   
함정과 특정 건물은 기본 가시성을 사용한다.   
일반 건물, 시체, 전멸 흔적은 가시성 100으로 처리한다.  
특정 건물 여부는 건물 데이터에서 지정한다.

# **7\. 은신 기반 가시성 공식**

은신 스탯을 보유한 대상은 기본 가시성을 사용하지 않고, 은신 스탯을 가시성으로 변환한다.

은신 기반 가시성 \= 100 \- 은신 스탯

은신 스탯에는 최대치 제한을 두지 않는다.   
따라서 은신 기반 가시성은 0 미만으로 내려갈 수 있다.

| 은신 스탯 | 은신 기반 가시성 |
| :---- | :---- |
| 0 | 100 |
| 50 | 50 |
| 100 | 0 |
| 120 | \-20 |
| 150 | \-50 |

가시성이 0 이하인 대상은 실제 확률 적용 시 가시성 0 이하 구간으로 처리한다.   
다만 계산식 안에서는 음수 값을 유지한다.

예를 들어 은신 기반 가시성이 \-50인 대상도 감지 보정이나 공격 후 가시성 증가를 통해 최종 계산 가시성이 0을 초과할 수 있다.

은신 기반 가시성 \-50  
\+ 감지 보정 \+40  
\+ 공격 후 가시성 증가 \+10  
\= 최종 계산 가시성 0

최종 계산 가시성이 0 이하라면 실제 확률 적용 시 0 이하 구간으로 처리한다.

# **8\. 최종 가시성 계산**

인지 판정에 사용하는 최종 가시성은 대상 가시성에 감지 보정, 정신력 보정, 경계 상태 보정, 공격 후 가시성 증가를 더해 산출한다.

최종 계산 가시성 \= 대상 가시성 \+ 경계 반영 감지 보정 \+ 정신력 보정 \+ 공격 후 가시성 증가 

| 항목 | 설명 |
| :---- | :---- |
| 대상 가시성 | 기본 가시성 또는 은신 기반 가시성 |
| 경계 반영 감지 보정 | 기본적으로 감지 스탯을 사용하며, 경계 상태에서는 감지 스탯 \+20으로 계산  |
| 정신력 보정 | 인류 전용 상태 보정 |
| 공격 후 가시성 증가 | 대상이 공격한 뒤 일정 시간 적용되는 가시성 증가 |

감지 보정 \= 감지 스탯

감지 스탯이 높을수록 은신 유닛, 함정, 특정 건물을 인지할 가능성이 높아진다.

# **9\. 정신력 보정**

정신력 보정은 인류 유닛에게만 적용한다. 몬스터는 정신력 보정을 사용하지 않는다.

| 정신력 단계 | 상태 예시 | 가시성 보정 |
| :---- | :---- | :---- |
| \+2 | 흥분 | \+10 |
| \+1 | 냉정 | \+5 |
| 0 | 안정 | 0 |
| \-1 | 긴장 | \-5 |
| \-2 | 공포 | \-15 |
| \-3 | 공황 | \-30 |

정신력이 높으면 인지 판정에 유리해지고, 정신력이 낮으면 인지 판정에 불리해진다.

# **10\. 경계 상태 보정**

경계 상태는 수상한 타일, 간접 인지, 위험 가능성이 있는 방향을 더 조심스럽게 확인하는 상태다.

경계 상태에서는 감지 계산에 임시 감지 보정 \+20을 추가한다. 

경계 중 감지 보정 \= 감지 스탯 \+ 20 

이 값은 인지 판정뿐 아니라 시야 거리, 인지 거리, 인지각에도 반영 된다.

01-A 기준에서 감지 20마다 시야 거리와 인지 거리가 1칸 증가하므로, 경계 상태 보정 \+20은 경계 중 시야/인지 확인 범위를 넓히는 역할도 한다.

# **11\. 공격 후 가시성 증가**

대상이 공격하면 일정 시간 동안 가시성이 증가한다.   
공격 후 가시성 증가는 01-A 기준을 따른다.

| 항목 | 값 |
| :---- | :---- |
| 공격 후 가시성 증가량 | \+10 |
| 지속 시간 | 5초 |
| 지속 시간 내 추가 공격 | 지속 시간 5초로 초기화 |

공격 후 가시성 증가는 대상 가시성에 더해진다.

은신 스탯 130  
은신 기반 가시성 \= \-30

공격 후 가시성 증가 \+10  
감지 보정 \+30

최종 계산 가시성 \= 10

공격 후 가시성 증가 시간이 끝나도, 이미 정확 인지된 대상이 즉시 미인식으로 바뀌지 않는다.

# **12\. 인지 결과 확률표**

인지 결과는 최종 계산 가시성 구간에 따라 확률로 결정된다.

인지 확률이 낮아도 정확 인지될 수 있고, 인지 확률이 높아도 미인식될 수 있다. 

현재 확률표는 임시 기준이며, 차후 밸런스에 따라 수정 가능성이 높다.

| 최종 계산 가시성 | 정확 인지 | 수상한 타일 | 미인식 |
| :---- | :---- | :---- | :---- |
| 0 이하 | 0% | 5% | 95% |
| 1\~19 | 10% | 20% | 70% |
| 20\~39 | 25% | 35% | 40% |
| 40\~59 | 50% | 35% | 15% |
| 60\~79 | 75% | 20% | 5% |
| 80 이상 | 90% | 8% | 2% |

# **13\. 일반 타일 안전 확인**

일반 타일은 유닛/오브젝트 확률 판정 대상은 아니지만, 인지 범위에 들어오면 안전 확인 판정 대상이 된다.

시야 범위 내 미확인 타일은 인지 범위 안에 들어왔을 때 직접 확인된 타일로 전환된다.   
이때 해당 타일에 현재 인지 가능한 유닛 또는 위험 오브젝트가 없다면 안전타일로 취급한다.

시야 범위 내 미확인 타일  
↓  
인지 범위 진입  
↓  
유닛/오브젝트 존재 여부 확인  
↓  
현재 인지 가능한 위험 요소 없음  
↓  
안전타일로 취급

안전타일은 인지한 일반 타일과 동일하게 취급한다.

안전 확인 결과로 인한 위험도/흥미도 감소는 03\_인지결과·가중치입력\_시스템 문서에서 다룬다.

# **14\. 정확 인지**

정확 인지는 관찰자가 대상의 유형과 위치를 식별한 상태다.

| 분류 | 예시 |
| :---- | :---- |
| 유닛 | 인류, 몬스터, 보스, 네메시스 |
| 오브젝트 | 함정, 건물, 시체, 전멸 흔적 |

정확 인지의 핵심 결과는 두 갈래다.

정확 인지  
↓  
1.인지 결과 정보 생성  
2\. 반응 후보 생성

인지 결과 정보 생성은 가중치 판단 시스템이 사용할 정보를 넘기는 처리다.

반응 후보 생성은 유닛이 실제 행동을 선택하기 위한 후보를 만드는 처리다. 

가중치 판단은 반응 후보가 아니다.  
가중치 판단은 정확 인지로 얻은 정보를 입력받아 이해도, 위험도, 흥미도에 반영하는 별도 시스템이다.

가중치 입력과 반영 방식은 03\_인지결과·가중치입력\_시스템 문서에서 다룬다.

# **15\. 정확 인지 후속 처리**

| 정확 인지 대상 | 생성되는 반응 후보 |
| :---- | :---- |
| 적 유닛 | 전투 반응 후보, 타겟 후보, 우회 후보, 전파 후보 |
| 함정 | 경계 후보, 함정 해제 후보, 우회 후보, 파괴 후보, 전파 후보 |
| 건물 | 조사 후보, 파괴 후보, 우회 후보, 전파 후보 |
| 시체 | 조사 후보, 경계 후보, 전파 후보 |
| 전멸 흔적 | 조사 후보, 경계 후보, 전파 후보 |

적 유닛도 우회 후보가 될 수 있다.   
인지한 적이 항상 전투 대상으로 고정되는 것은 아니며, 파티 목적, 위험도, 리더 명령, 현재 전투 상태에 따라 우회가 선택될 수 있다.

# **16\. 직접 인지**

직접 인지는 관찰자가 자신의 인지 범위 내 확인한 정보다.

| 1\. 인지 범위 내 유닛 확인 2\. 인지 범위 내 오브젝트 확인 3\. 인지 범위 내 일반 타일 안전 확인 |
| :---- |

오브젝트 조사와 상호작용은 직접 인지 조건이 아니다.  
조사와 상호작용은 인지 성공 이후 선택될 수 있는 반응이다.

# **17\. 직접 피격과 공격자 인지**

직접 피격은 피해 발생으로 인해 확정되는 별도 피격 정보 입력이다.   
다만 직접 피격이 곧 공격자의 정확 인지를 의미하지는 않는다.

| 항목 | 처리 |
| :---- | :---- |
| 피격 사실 | 확정 |
| 피해량 | 확정 |
| 공격자 정체 | 인지 범위 내 인지 판정 필요 |

공격 방향 정보는 공격 형태에 따라 다르게 처리된다.

| 공격 형태 | 방향 정보 |
| :---- | :---- |
| 근접 공격 | 공격자 위치 기준으로 방향 확인 가능 |
| 투사체 | 맞은 공격의 진행 시점 기준 방향 확인 가능 |
| 원거리 공격 | 맞은 공격의 진행 시점 기준 방향 확인 가능 |
| 투사체 마법 | 맞은 공격의 진행 시점 기준 방향 확인 가능 |
| 광역 마법 | 방향 불명 |
| 장판 마법 | 방향 불명 |
| 함정 | 공격 방향 정보 사용하지 않음 |

공격자 정체는 공격자가 인지 범위 안에 있을 때 인지 판정을 통해 확인한다.    
공격자 정체를 확인하지 못한 경우, 확인 가능한 공격 방향은 시야 방향 전환 후보, 목표 재설정 후보, 경로 재설정 후보로 연결될 수 있다.

기습 및 방어 반응은 06\_전투반응·기습·방어반응\_시스템 문서에서 다룬다.

# **18\. 인지 실패**

인지 실패는 대상이 인지 판정 대상이 되었지만 정확히 식별되지 않은 상태다.

| 실패 결과 | 의미 | 후속 |
| :---- | :---- | :---- |
| 수상한 타일 | 무언가 있다는 것은 느꼈지만 정체를 식별하지 못함 | 경계 상태로 접근해 확인 |
| 미인식 | 아무것도 인식하지 못함 | 안전타일로 인지됨 |

인지 실패는 대상이 존재하지 않는다는 뜻이 아니다.   
대상은 실제로 존재하지만, 관찰자가 그것을 정확히 식별하지 못한 상태다.

# **19\. 미인식**

미인식은 대상이 실제로 존재하지만 관찰자가 전혀 인식하지 못한 상태다.

미인식된 대상은 현재 관찰자의 판단에서 안전타일로 처리된다. 

안전타일은 인지한 일반 타일과 동일하게 취급한다.

# **20\. 수상한 타일**

수상한 타일은 대상의 정확한 정체는 식별하지 못했지만, 해당 위치에 무언가 이상한 요소가 있다고 판단한 상태다.

수상한 타일은 인지 판정 결과로 발생한다. 

| 항목 | 처리 |
| :---- | :---- |
| 정확한 대상 유형 확인 | X |
| 공격 대상으로 지정 | X |
| 전파 | X |
| 경계 상태로 접근 | O |
| 시야 방향 전환 후보 | O |
| 임시 위험도 증가 | O |
| 임시 흥미도 증가 | O |

수상한 타일은 전파 대상이 아니다.   
인류 유닛이 “무언가 이상하다”고 느낄 수는 있지만, 그것을 다른 유닛에게 정확한 적/함정/오브젝트 정보로 전달할 수는 없다.

수상한 타일로 판정된 경우 유닛은 경계 상태로 접근해 해당 타일을 확인한다.   
경계 접근과 확인 절차의 세부 행동은 04\_탐색반응·경계·조사·함정대응\_시스템 문서에서 다룬다.

# **21\. 수상한 타일 임시 위험도/흥미도**

수상한 타일은 임시 위험도와 임시 흥미도를 함께 증가시킨다.

| 항목 | 값 |
| :---- | :---- |
| 임시 위험도 | \+5 |
| 임시 흥미도 | \+5 |

수상한 타일의 임시 위험도/흥미도는 저장값이 아니다.   
현재 유닛 또는 파티가 해당 위치를 어떻게 확인할지 판단하는 임시 위치 판단값이다.

| 1\. 2칸 이내 재인지 판정에서 정확 인지됨  2\. 2칸 이내 재인지 판정에서 미인식되어 안전타일로 처리됨  3\. 2칸 이내 재인지 판정에서도 수상한 타일로 남아 해당 타일로 직접 이동을 시도한 뒤, 유닛/건물 점유 또는 함정 작동으로 확인 절차가 종료됨  |
| :---- |

위 경우 수상한 타일의 임시 위험도/흥미도는 제거된다.  
이해도, 위험도, 흥미도에 어떻게 입력되는지는 03\_인지결과·가중치입력\_시스템 문서에서 다룬다.

# **22\. 수상한 타일 확인 흐름**

수상한 타일이 발생하면 유닛은 경계 상태로 접근한다.

수상한 타일 판정  
↓  
경계 상태로 접근  
↓  
2칸 이내 접근 시 재인지 판정  
↓  
재인지 결과에 따라 분기

2칸 이내 재인지 판정은 일반 인지 확률표를 사용한다.   
다만 경계 상태 보정이 적용된다.

2칸 이내 재인지 판정  
\= 일반 인지 판정  
\+ 경계 상태 보정

| 재인지 결과 | 처리 |
| :---- | :---- |
| 정확 인지 | 수상한 타일 임시 위험도/흥미도 제거, 인지 결과 정보 생성 |
| 미인식 | 수상한 타일 임시 위험도/흥미도 제거, 안전타일로 인지, 경계 해제 |
| 수상한 타일 | 해당 타일로 직접 이동 시도 |

2칸 이내 재인지 판정에서도 다시 수상한 타일로 판정되면, 유닛은 해당 타일로 직접 이동을 시도한다.

| 실제 대상 | 처리 |
| :---- | :---- |
| 유닛 | 해당 타일로 이동하려 하나 대상 점유로 인해 이동하지 못함. 이후 인지 결과 정보 생성 |
| 건물 | 해당 타일로 이동하려 하나 대상 점유로 인해 이동하지 못함. 이후 인지 결과 정보 생성 |
| 함정 | 해당 타일에 도착하면 함정 작동. 이후 인지 결과 정보 생성 |

함정은 해당 타일 도착 시 작동한다.

# **23\. 안전 확인과 인지 실패의 관계**

안전 확인은 인지 범위 안에서 해당 타일을 직접 확인한 뒤, 현재 인지 가능한 적 유닛과 위험 오브젝트가 없다고 판단하는 처리다.

일반 타일은 인지 범위 안에 들어오면 안전 확인 대상으로 처리된다. 

해당 타일에 현재 인지 가능한 위험 요소가 없으면 안전타일로 취급된다.

인지 판정 결과가 미인식이면 실제로 유닛, 함정, 건물 등이 존재하더라도 해당 타일은 안전타일로 인지된다. 이 안전타일은 일반 타일 안전 확인 결과와 동일하게 취급한다. 

안전 확인 이후 위험도/흥미도 감소는 03 문서에서 다룬다.

# **24\. 간접 인지**

간접 인지는 관찰자가 직접 보거나 확인한 것은 아니지만, 전파, 전투음, 공격 방향 추정, 아군 반응/명령 등을 통해 얻은 정보다.

간접 인지는 정확 인지가 아니다.   
간접 인지는 위치, 방향, 위험 가능성, 대상 존재 가능성을 제공할 뿐 대상의 정확한 유형을 직접 확정하지 않는다.  
일반 소리와 소음 감지는 08\_전파·소리·간접입력\_시스템 문서에서 다룬다.

| 간접 입력 | 생성 정보 |
| :---- | :---- |
| 전파 | 전달받은 대상 정보 또는 위치 정보 |
| 전투음 | 전투 위치 |
| 공격 방향 추정 | 공격이 온 방향 |
| 아군 반응/명령 | 적/위험/목표 여부와 위치 정보 |

간접 인지는 유닛 또는 오브젝트가 있을 가능성이 있는 방향으로 시야 방향을 전환하게 만들 수 있다.   
이후 대상 또는 타일이 인지 범위 안에 들어오면 직접 인지 판정을 수행한다.  
간접 인지 이후의 인지 판정 결과에 따라 경로, 목표, 반응 후보가 달라진다.

# **25\. 간접 인지의 임시 위험도/흥미도**

간접 인지는 대상의 성격에 따라 임시 위험도 또는 임시 흥미도를 부여한다.

| 간접 인지 결과 | 처리 |
| :---- | :---- |
| 전투 위치 | 해당 위치 주변 타일에 임시 위험도 \+10 |
| 시체 전파 | 해당 위치 주변 타일에 임시 흥미도 \+3 |
| 전멸 흔적 전파 | 해당 위치 주변 타일에 임시 흥미도 \+3 |
| 건물 전파 | 해당 위치 주변 타일에 임시 흥미도 \+3 |

전투 위치를 간접 인지한 경우, 전투 중이 아니라면 해당 위치를 목표 후보로 올린다.   
전투 중이라면 현재 전투, 생존, 명령을 우선하고, 간접 인지 위치 목표 우선순위 상승은 적용하지 않는다.

적이 아닌 대상의 간접 인지는 목표 우선순위를 조정하지 않는다.   
시체, 전멸 흔적, 건물 전파는 임시 흥미도만 부여한다.

비적 간접 인지의 임시 흥미도는 아군이 해당 대상을 조사한 뒤 전파를 통해 제거될 수 있다.   
이 경우 전파받은 대상 정보는 기록된다.

A 유닛이 시체 위치를 전파  
↓  
파티 또는 주변 유닛의 해당 위치 주변 타일에 임시 흥미도 \+3  
↓  
B 유닛이 해당 시체를 조사  
↓  
조사 결과를 전파  
↓  
임시 흥미도 제거  
↓  
전파받은 대상 정보 기록

간접 인지 임시값의 세부 유지 시간과 전파 범위는 08 문서에서 다룬다.

# **26\. 인류와 몬스터의 차이**

| 항목 | 인류 | 몬스터 |
| :---- | :---- | :---- |
| 인지 판정 | 사용 | 사용 |
| 정신력 보정 | 적용 | 없음 |
| 직접 인지 | 사용 | 사용 |
| 전파 | 사용 | 없음 |
| 전투음/위험 방향 반응 | 사용 | 사용 |

인류는 인지 결과를 대표 가중치, 파티 목표, 리더 명령, 전파와 연결한다.   
몬스터는 대표 가중치와 전파를 사용하지 않는다.

몬스터는 직접 인지, 전투음, 위험 방향, 역할군 AI를 중심으로 반응한다.  
특수 몬스터만 별도 리더/명령 구조를 가질 수 있다.
