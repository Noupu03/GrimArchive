# **07\_A\_전파·소리·간접입력\_연산공식**

v0.2 / 연산공식·수치 문서

# **0\. 문서 목적**

본 문서는 07\_전파·소리·간접입력\_개념에서 정의한 규칙 중 실제 적용에 필요한 거리·범위·시간·소리 내부 우선순위·정보 갱신·전투 합류 판정값을 정의한다.

대표 가중치와의 관계 및 일반 전파의 가중치 비연동 원칙은 07의 정보 보유 구조와 대표 가중치 규칙을 따른다. 

# **1\. 전파·소리 공통 공간 거리 판정**

## **1-1. 공간 선판정**

| 공간 판정식 동일 방 또는 동일 통로 \= 거리 판정 진행 방↔통로, 방↔다른 방, 통로↔다른 통로 \= 거리와 관계없이 도달 실패 출입구가 열려 있어도 공간 경계를 넘지 않는다. |
| :---- |

## **1-2. 거리 계산**

* 장애물이 없는 경우: 발생 지점을 중심으로 한 원형 주위 N칸을 사용한다.  
* 벽·이동 불가 지형으로 직선 접근이 불가능한 경우: 같은 공간 안에서 이동 가능한 최단 경로 거리를 사용한다.

도달 가능한 경로가 없으면 실패한다.

* 최종 도달 판정: 계산 거리 ≤ 적용 범위.

예: 직선거리가 2칸이지만 벽을 돌아 실제 최단 경로가 4칸이면 범위 3은 실패하고 범위 4는 성공한다.

소리 추정 지역도 발생한 동일 방·통로 내부로 제한하며 다른 공간으로 확장하지 않는다.

# **2\. 전파 범위**

## **2-1. 인류 전파 범위**

| 카리스마 | 범위 보정 |
| :---: | :---: |
| 0\~24 | \+0칸 |
| 25\~49 | \+1칸 |
| 50\~74 | \+2칸 |
| 75\~99 | \+3칸 |
| 100 | \+4칸 |

| 인류 최종 전파 범위 기본 3칸 \+ 카리스마 범위 보정 |
| :---- |

카리스마의 전파 범위 효과는 플레이 테스트 결과에 따라 축소 또는 삭제할 수 있다.

## **2-2. 전파 가능 무리형 몬스터**

* 카리스마 보정을 사용하지 않는다.  
* 최종 전파 범위는 몬스터·종별 데이터로 정의하며 일반 기준값은 주위 3칸이다.

| :---- |

# **4\. 소리 이벤트와 기본 범위**

| 소리 | 발생 위치 | 기본 범위 |
| :---: | :---: | :---: |
| 이동음 | 이동 유닛 위치 | 주위 2칸 |
| 공격 실행음 | 공격자 위치 | 주위 3칸 |
| 피격 발생 공격음 | 피격 위치 | 주위 5칸 |
| 피격 비명 | 피격 위치 | 주위 6칸 |
| 사망음 | 사망 위치 | 주위 7칸 |
| 함정 작동음 | 함정 발동 위치 | 주위 5칸 |

* 공격 실행음은 명중 여부와 관계없이 공격 실행 시 발생한다.  
* 공격이 적중하면 공격 실행음과 별도로 피격 위치에서 피격 발생 공격음이 발생한다.  
* 함정·공격·유닛 개별 데이터가 별도 범위를 가지면 해당 값을 우선한다.

## **4-1. 피격 비명 발생 기준**

| 피격 비명 판정 최종 HP 감소량 ≥ 최대 HP × 10% → 피격 비명 발생 |
| :---- |

방어·피해 감소 등 모든 처리가 끝난 뒤 실제 적용된 최종 HP 감소량을 사용한다.

# **5\. 소리 감지 범위**

| 최종 감지 | 소리 범위 보정 |
| :---: | :---: |
| 0\~24 | \+0칸 |
| 25\~49 | \+1칸 |
| 50\~74 | \+2칸 |
| 75\~99 | \+3칸 |
| 100 | \+4칸 |

| 인류 소리 감지 범위 소리 기본 범위 \+ 감지 보정 |
| :---- |

## **5-1. 경계 상태 감지**

| 경계 상태 최종 감지 최종 감지 \= min(기본 감지 \+ 20, 100\) |
| :---- |

경계 상태에서는 감지 \+20을 먼저 적용한 뒤 범위 보정을 계산한다.

## **5-2. 몬스터 청각 보정**

| 몬스터 소리 감지 범위 소리 기본 범위 \+ 감지 보정 \+ 종별·개체 청각 보정 |
| :---- |

일반 몬스터의 청각 보정 기준값은 \+2칸이다.   
종별·개체 데이터가 있으면 해당 값을 사용한다.

# **6\. 소리로 획득하는 방향·추정 지역**

| 소리 | 획득 위치 정보 | 추정 지역 |
| :---: | :---: | :---: |
| 이동음 | 방향만 획득 | 없음 |
| 공격 실행음 | 발생 방향 \+ 추정 지역 | 실제 사건 위치 중심 주위 2칸 |
| 피격 발생 공격음 | 사건 방향 \+ 추정 지역 | 실제 사건 위치 중심 주위 2칸 |
| 피격 비명 | 사건 방향 \+ 추정 지역 | 실제 사건 위치 중심 주위 2칸 |
| 사망음 | 사건 방향 \+ 추정 지역 | 실제 사건 위치 중심 주위 2칸 |
| 함정 작동음 | 작동 방향 \+ 추정 지역 | 실제 발동 위치 중심 주위 1칸 |

* 추정 지역의 시스템상 중심은 실제 사건 위치를 사용하지만 유닛 기록에서 중심점을 정확 위치로 확정하지 않는다.  
* 시야 전환과 접근 계산에는 중심 방향을 사용하고, 정보로는 원형 추정 지역 전체를 미확인 영역으로 취급한다.

# **7\. 복수 소리 선택·유효시간**

## **7-1. 소리 내부 우선순위**

다음 순위는 동시에 감지된 여러 소리 중 어느 소리에 반응할지를 선택하는 소리 내부 우선순위다.   
전체 행동 우선순위는 03과 현재 상태 규칙을 따르며, 선택된 소리 방향 후보는 01-A의 전체 시야 방향 후보 체계에서 다시 비교한다.

| 순위 | 소리 |
| :---: | :---: |
| 1 | 사망음 / 피격 비명 |
| 2 | 피격 발생 공격음 |
| 3 | 함정 작동음 |
| 4 | 공격 실행음 |
| 5 | 이동음 |

동일 순위 후보가 여러 개면 가까운 소리를 우선하고, 거리도 같으면 현재 시야 방향과 가까운 방향을 우선한다.

## **7-2. 반응 중 새 소리**

* 새 소리 우선순위가 현재 확인 중 소리보다 높으면 새 소리로 교체한다.  
* 같거나 낮으면 기존 소리 확인을 유지한다.  
* 높은 우선순위 소리로 교체되면 이전 확인 대상은 폐기하며 이후 다시 돌아가지 않는다.  
* 같은 공격에서 공격 실행음→피격 발생 공격음→비명이 연속 발생해도 당시 가장 높은 후보로 갱신한다.

## **7-3. 유효시간과 보류 수**

| 항목 | 기준 |
| :---: | :---: |
| 일반 소리 유효시간 | 발생 후 5초 |
| 확인 행동 시작 기한 | 5초 안에 시작 |
| 시작 후 5초 초과 | 확인 행동 계속 수행 |
| 유닛당 보류 소리 | 1건 |
| 이동음 | 저장하지 않고 즉시 반응 여부만 판정 |

# **8\. 소리 확인 판정·연출 시간** 

## **8-1. 이동음 반응**

| 이동음 반응 순서 '?' 표시 → 이동음 방향으로 시야 전환 → 인지 판정 1회 → 2초간 해당 방향 시야 유지 |
| :---- |

## **8-2. 추정 지역형 소리 반응**

| 추정 지역 확인 순서 '?' 표시 → 추정 지역 중심이 인지 범위 안에 들어오는 거리까지 접근 → 인지 판정 1회 원인을 정확 인지하지 못하면 '...?' 표시 → 2초간 해당 방향 시야 유지 → 확인 행동 종료 |
| :---- |

8-1과 8-2 모두 2초의 시야 유지 자체로 자동 재인지 판정을 발생시키지 않는다.   
재판정은 02에서 정의한 재인지 조건이 발생한 경우에만 수행한다. 

# **9\. 적 인지 후 전투 시작·합류 판정**

## **\-9-1. 근거리 공통 규칙**

| 즉시 전투 판정 비전투 상태에서 적을 정확 인지 \+ 적과 거리 ≤ 2칸 → 위험도 단계와 관계없이 즉시 전투 |
| :---- |

근접 역할의 실제 공격 가능 여부와 원거리 역할의 거리 확보 행동은 전투 행동 및 09에서 정의한다.

## **9-2. 거리 2칸 초과**

| 위험도 단계 | 처리 |
| :---: | :---: |
| 미확인 | 즉시 전투 |
| 0 | 즉시 전투 |
| 1 | 즉시 전투 |
| 2 | 합류 대기 |
| 3 이상 | 현재 2단계 규칙 임시 적용 |

위험도 단계 구간 자체는 대표 가중치 문서를 따른다.

## **9-3. 합류 시간**

| 판정 | 시간 / 처리 |
| ----- | ----- |
| 합류 의사 응답 대기 | 2초 |
| 2초 내 응답 없음 | 발견자 단독 전투 시작 |
| 응답 있음 | 응답자 중 최소 1명의 실제 합류 대기 |
| 실제 합류 최대 대기 | 임시 5초 |
| 대기 중 적 선공 | 위험도·합류 조건 무시하고 즉시 전투 |

실제 합류 최대 대기 5초 초과 후 행동은 09에서 정의한다.
