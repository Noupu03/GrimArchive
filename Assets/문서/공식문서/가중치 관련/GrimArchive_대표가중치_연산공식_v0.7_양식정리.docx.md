# **1\. 가중치 관리 범위** 개별 대상 단위의 가중치는 아래 범위 안에서 관리한다. 

| 대상 | 관리 범위 |
| :---: | :---: |
| 이해도 | 0\~100 |
| 개별 유닛 위험도 | 0\~999 |
| 종별 위험도 | 0\~999 |
| 타일 위험도 | 0\~999 |
| 오브젝트 위험도 | 0\~999 |
| 타일 흥미도 | 0\~999 |
| 오브젝트 흥미도 | 0\~999 |
| 유닛 흥미도 | 0\~999 |

다음 값은 내부 합산값이므로 999를 초과할 수 있다. 

| 대상 | 처리 |
| :---: | :---: |
| 던전 전체 위험도 | 999 이상 누적 가능 |
| 던전 전체 흥미도 | 999 이상 누적 가능 |
| 방 위험도 | 999 이상 누적 가능 |
| 방 흥미도 | 999 이상 누적 가능 |

* 가중치는 내부적으로 소수점 단위까지 저장할 수 있다.  
* AI 판단, 조건 비교, 화면 표기에는 소수점 이하를 버린 정수 적용값을 사용한다.

| 저장값 2.7 → 적용값 2저장값 3.0 → 적용값 3 |
| :---- |

# **2\. 정보 유형 배율 기준값**

| 정보 유형 | 포함 내용 | 배율 |
| :---: | ----- | :---: |
| 직접 경험 | 직접 피격, 직접 상호작용 | 1.0 |
| 직접 목격 | 시야 안에서 사건을 직접 목격 | 0.5 |
| 간접 파악 | 상호작용 목격, 전파, 소리 | 0.25 |

정보 유형 배율은 직접 경험, 직접 목격, 간접 파악 사이의 정보 신뢰도 차이를 정하기 위한 기준값이다.

본 문서의 3장 이벤트 표에는 이벤트별 최종 변화량을 직접 작성한다.  
어떤 이벤트는 직접 경험만 존재하고, 어떤 이벤트는 직접 목격까지만 존재하며, 어떤 이벤트는 간접 파악까지 존재할 수 있기 때문이다.   
따라서 3장 표에 적힌 이해도 / 위험도 값은 그대로 사용하며, 정보 유형 배율을 다시 곱하지 않는다.

정보 유형 배율은 새 이벤트를 추가할 때 직접 경험 기준 변화량을 바탕으로 직접 목격 / 간접 파악 변화량을 산정하기 위한 참고 기준으로 사용한다.

# **4\. 개인 가중치 계산** 유닛이 던전 안에서 사건을 경험하거나 목격하면 개인 가중치가 먼저 갱신된다.

| 개인 변화량 \= 3장 이벤트 표에 적힌 해당 이벤트의 변화량개인 계산값 \= 현재 개인 저장값 \+ 개인 변화량  |
| :---- |

## **예시**

| 현재 대상 위험도 \= 2.0이벤트 \= E\_HUMAN\_KILL\_SEEN3장 이벤트 표의 위험도 변화량 \= 3 개인 위험도 변화량 \= 3개인 위험도 계산값 \= 2.0 \+ 3 \= 5.0적용값 \= 5  |
| :---- |

# **5\. 신규 진입 유닛 정보**

## **5-1. 기억이 없는 유닛**

* 개인 기억이 없는 신규 유닛은 최신 인류 전역 지도 정보와 미표기 정보를 기본값으로 가진다.  
* 던전 내부에서 새로 얻은 정보는 개인 정보에 추가 반영된다.

| 신규 유닛 개인 지도 정보 \= 최신 전역 지도 정보신규 유닛 개인 미표기 정보 \= 최신 전역 미표기 정보개인 정보 계산값 \= 입장 시 부여받은 정보 \+ 던전 내부에서 획득한 변화량 |
| :---- |

## **5-2. 기억이 있는 유닛**

* 기억이 있는 유닛은 자신의 개인 기억을 우선 사용한다.  
* 같은 웨이브에 함께 들어간 동료가 동일 대상을 더 늦은 시점에 확인했고, 그 시점에서 가중치가 변경된 경우 해당 정보는 전역 반영 시 함께 병합된다.  
* 병합 시에는 6장 생존자 전역 반영 규칙을 따른다.

즉, 생환 유닛들의 정보는 동일 IncidentID 기준으로 분류하고,  
동일 수치 정보는 중복 제거한 뒤, 직접 경험 : 직접 목격 : 간접 파악 \= 5 : 3 : 2 비율값을 적용해 전역 반영량을 계산한다.  
예시:

| 유닛 A가 몬스터 M을 직접 목격함.같은 웨이브의 유닛 B도 몬스터 M을 더 늦게 직접 목격했고, 그 사이 몬스터 M의 위험도 값이 변경됨.이 경우 유닛 A의 정보와 유닛 B의 더 늦은 정보는 생환 후 전역 반영 시 6장 규칙에 따라 함께 계산된다. |
| :---- |

세부 병합 방식은 지도 기록 / 저장 문서와 기억 문서에서 작성한다.

# **6\. 생존자 전역 반영**

디펜스 종료 또는 웨이브 종료 후, 살아 돌아온 유닛의 개인 정보가 인류 전역 정보에 반영된다.  
전역 반영에는 생존, 후퇴, 도주에 성공한 유닛의 정보만 사용한다.

## **6-1. 정보 유형 비율값** 

| 정보 유형 | 비율값 | 기본 반영 비율 |
| :---: | :---: | :---: |
| 직접 경험 | 5 | 0.5 |
| 직접 목격 | 3 | 0.3 |
| 간접 파악 | 2 | 0.2 |

| 직접 경험 : 직접 목격 : 간접 파악 \= 5 : 3 : 2 |
| :---- |

## **예시 1\. 직접 목격과 간접 파악만 존재하는 경우** 

| 직접 목격 비율값 \= 3간접 파악 비율값 \= 2비율값 합 \= 3 \+ 2 \= 5직접 목격 반영 비율 \= 3 / 5 \= 0.6간접 파악 반영 비율 \= 2 / 5 \= 0.4  |
| :---- |

## **예시 2\. 직접 경험과 간접 파악만 존재하는 경우** 

| 직접 경험 비율값 \= 5간접 파악 비율값 \= 2비율값 합 \= 5 \+ 2 \= 7직접 경험 반영 비율 \= 5 / 7 \= 0.714… \-\> 0.71간접 파악 반영 비율 \= 2 / 7 \= 0.285... \-\> 0.29 |
| :---- |

전역 반영 비율을 소수로 표기할 경우 소수점 둘째 자리까지 표기한다.  
셋째 자리에서 반올림하며, 셋째 자리가 5 미만이면 내림 처리한다. 

## **예시 3\. 직접 목격만 존재하는 경우** 

| 직접 목격 비율값 \= 3비율값 합 \= 3직접 목격 반영 비율 \= 3 / 3 \= 1.0  |
| :---- |

## **6-2. 동일 수치 정보 중복 처리**  같은 사건에서 같은 수치 정보가 여러 생환자에게서 들어오면 중복 입력으로 처리한다. 중복 처리 기준은 다음과 같다.

| 기준 | 내용 |
| :---: | :---: |
| EventID  | 3장 이벤트 표의 이벤트 종류 ID   |
| IncidentID  | 실제로 발생한 사건 고유 ID |
| TargetID  | 동일 대상  |
| WeightType  | 동일 가중치 종류  |
| InfoType  | 동일 정보 유형  |
| ChangeValue  | 동일 수치 변화량  |

## **예시: 같은 사건을 여러 생환자가 가져온 경우**

생환자 B,C는 같은 사건에서 같은 수치 정보를 가져옴 \= 1회만 기록

| 사건: 몬스터 A가 인류 유닛 1명을 처치함IncidentID: INCIDENT\_001TargetID: Monster\_AWeightType: 위험도 생환자 B: E\_HUMAN\_KILL\_SEEN, 직접 목격, 위험도 \+3생환자 C: E\_HUMAN\_KILL\_SEEN, 직접 목격, 위험도 \+3생환자 D: E\_HUMAN\_KILL\_INDIRECT, 간접 파악, 위험도 \+1.5 직접 목격 위험도 \+3은 중복 정보이므로 1회만 기록한다.생환자 D의 정보는 같은 IncidentID에서 나온 정보지만 EventID, InfoType, ChangeValue가 다르므로 중복 제거하지 않는다.간접 파악 위험도 \+1.5는 정보 유형별 대표 변화량 산출 대상으로 남기며, 이후 6-4 전역 반영량 계산에서 직접 목격 정보와 함께 비율값을 적용해 반영한다.  |
| :---- |

## **6-3. 같은 정보 유형 안에서 정보 오차로 수치가 다른 경우** 

# 같은 정보 유형 안에서도 수치가 다를 수 있다. 대표적인 경우는 다음과 같다.

| 경우 | 설명 |
| :---: | :---: |
| 정보 오차 발생  | 정신력 저하(공포 / 공황) 단계 상태 때문에 같은 사건을 다르게 기록한 경우  |

# 동일 정보 유형 안에서 수치가 다르면, 중복 제거 후 해당 정보 유형 내부 평균값을 구한다. 

| 정보 유형별 대표 변화량 \=같은 정보 유형 안의 서로 다른 변화량 합 / 해당 정보 유형 안의 서로 다른 변화량 개수  |
| :---- |

# 예시: 정신력 상태에 따른 오차로 수치가 다르게 기록된 경우 

| 사건: 몬스터 A가 인류 유닛을 처치함 IncidentID: INCIDENT\_020EventID: E\_HUMAN\_KILL\_SEENInfoType: 직접 목격TargetID: Monster\_AWeightType: 위험도 생환자 B: 정상 상태, 위험도 \+3생환자 C: 정상 상태, 위험도 \+3생환자 D: 정신력 공포 상태, 위험도 \+3.2  생환자 B와 C의 기록은 동일 수치 정보이므로 1회만 남긴다.생환자 D의 기록은 같은 직접 목격 정보지만 정신력 상태로 인해 수치 오차가 발생했으므로 중복 제거하지 않는다.  직접 목격 대표 변화량 \= (3 \+ 3.2) / 2 \= 3.1  |
| :---- |

# **6-4. 전역 반영량 계산**  전역 반영량은 정보 유형별 대표 변화량과 정보 유형 비율값을 사용한다. 

| 전역 반영량 \= (정보 유형별 대표 변화량 × 정보 유형별 비율값)의 합 / 존재하는 정보 유형의 비율값 합  |
| :---- |

# 계산 결과가 소수로 나올 경우 저장값은 소수로 유지하고, 적용값은 정수로 사용한다.  예시 1\. 직접 경험, 직접 목격, 간접 파악이 모두 존재하는 경우

| 사건: 몬스터 A가 인류 유닛 B에게 일정 피해량 이상 피해를 입힘 IncidentID: INCIDENT\_010TargetID: Monster\_AWeightType: 위험도 | 생환자 | EventID | InfoType | 위험도 변화량 || 생환자 B | E\_HIT\_HEAVY\_SELF | 직접 경험 | \+0.3 || 생환자 C | E\_HIT\_HEAVY\_SEEN | 직접 목격 | \+0.15 || 생환자 D | E\_HIT\_HEAVY\_INDIRECT | 간접 파악 | \+0.075 | 정보 유형별 대표 변화량:직접 경험 대표 변화량 \= 0.3직접 목격 대표 변화량 \= 0.15간접 파악 대표 변화량 \= 0.075 전역 반영량 \= (0.3 × 5 \+ 0.15 × 3 \+ 0.075 × 2\) / (5 \+ 3 \+ 2\)\= (1.5 \+ 0.45 \+ 0.15) / 10\= 2.1 / 10\= 0.21 전역 저장값에는 \+0.21을 반영한다.적용값은 소수점 이하를 버려 0으로 사용한다.  |
| :---- |

# **10\. 위험도 증가**

* 위험도 증가는 인류 유닛이 일정 피해량 이상을 받았거나, 인류 유닛 처치, 상태이상, 특수 행동, 함정 피격, 전멸 관련 사건이 발생했을 때 적용한다.   
* 기준 피해량 미만의 약한 타격은 피격이나 목격만으로 위험도를 증가시키지 않는다.  
* 일정 피해량 이상 기준은 유닛별 데이터 테이블에서 작성한다.

| 위험도 변화량 \= 3장 이벤트 표에 적힌 위험도 변화량위험도 계산값 \= 현재 위험도 저장값 \+ 위험도 변화량  |
| :---- |

## **예시**

| 현재 위험도 \= 2.0이벤트 \= E\_HIT\_HEAVY\_SELF3장 이벤트 표의 위험도 변화량 \= 0.3 위험도 계산값 \= 2.0 \+ 0.3 \= 2.3적용값 \= 2 |
| :---- |

# **11\. 위험도 감소**

위험도 감소값은 3-1 이벤트 변화량 표를 따른다.   
위험도 감소가 발생해도 대상별 최저 위험도 이하로 내려가지 않는다. 

| 대상 | 최저 위험도 |
| :---: | :---: |
| 일반 유닛 | 3 |
| 함정 | 3 |
| 방어건물 | 3 |
| 보스 / 네메시스 | 10 |

## **11-1. 총 피해량 기준 위험도 감소 판정**

총 피해량 기준 위험도 감소 판정은 몬스터 유닛이 처치된 경우 해당 몬스터 종 위험도에 적용된다.

| 항목 | 값 |
| :---: | :---: |
| 위험도 감소 판정 기준값 | \-1 |

| 위험도 감소 판정값 \= 처치 참여 인류 유닛이 받은 총 피해량 \- 해당 대상의 기준 총 피해량 위험도 감소 판정값 ≤ \-1 이면 위험도 감소 조건 충족 |
| :---- |

## **예시**

| 처치 참여 인류 유닛이 해당 유닛에게 받은 피해량 \= 2 대상 기준 피해량 \= 12  위험도 감소 판정값 \= 2 \- 12 \= \-10 위험도 감소 조건 충족 → 해당 몬스터 종 위험도 \-1 |
| :---- |

## **11-2. 타격 1회별 기준 피해량 미만 판정** 

몬스터의 공격이 인류 유닛에게 적중했지만, 인류 유닛의 방어력 또는 저항 수치 때문에 실제 피해량이 몬스터에게 설정된 타격 1회별 기준 피해량보다 낮게 들어간 경우, 해당 몬스터의 위험도는 소폭 감소할 수 있다.

이 감소는 타격 1회마다 기록하되, 같은 전투 안에서 누적 최대 감소량을 제한한다. 

| 항목 | 값 |
| :---: | :---: |
| 타격 1회 위험도 감소값  | \-0.01 |

| 타격 1회 피해량 차이 \= 몬스터의 타격 1회별 기준 피해량 \- 실제 적용 피해량  타격 1회 피해량 차이 ≥ 1이면 해당 타격은 위험도 감소 조건을 충족한다. 단, 같은 전투에서 이 조건으로 감소할 수 있는 최대 누적값은 \-1로 제한한다.  |
| :---- |

## **13-3. 전멸 전투 참여 유닛의 전멸 당시 사용 스킬 목격**

# **15\. 타일 위험도**

| 타일 상태 | 위험도 |

인류 유닛이 해당 타일을 시야로 확인하고, 위험도 단계별 안전 확인 시간 동안 새로운 위험 요소가 발견되지 않으면 타일 위험도는 0으로 감소한다.

| 위험도 단계 1 | 100\~299 | 2초 |
| 위험도 단계 2 | 300\~599 | 3초 |
| 위험도 단계 3 | 600\~799 | 4초 |
| 위험도 단계 MAX | 800\~999 | 5초 |

| 위험 유닛이 있었던 타일↓유닛 사라짐↓기록 위험도 유지↓해당 타일 시야 확인 및 안전 확인↓위험도 단계별 안전 확인 시간 동안 위험 요소 없음↓타일 위험도 0  |
| :---- |

# **16\. 타일 흥미도**

| 타일 상태 | 흥미도 |
| :---: | :---: |
| 미탐사 타일 기본 흥미도 | 5 |
| 탐사 완료 타일 기본 흥미도 | 0 |

| 타일 최종 흥미도 \= 타일 기본 탐사 흥미도 \+ 현재 타일 위 오브젝트 흥미도 |
| :---- |

## **예시**

| 미탐사 타일 기본 흥미도 \= 5 / 오브젝트 흥미도 \= 120타일 최종 흥미도 \= 5 \+ 120 \= 125 |
| :---- |

오브젝트 회수 완료 시:

| 해당 타일의 오브젝트 흥미도 \= 0오브젝트 상태 \= 인류 유닛 운반 상태  |
| :---- |

* 타일 기본 탐사 흥미도는 오브젝트 흥미도와 별도로 처리한다.

# **17\. 오브젝트 흥미도 감소 / 복구**

오브젝트 흥미도는 오브젝트 데이터의 기본값을 사용한다.

| 조건 | 처리 |
| :---: | :---: |
| 조사 완료 | 오브젝트 흥미도 50% 감소 |
| 회수 완료 | 오브젝트 흥미도 0 |
| 파괴 / 소모 | 오브젝트 흥미도 0 |

## **조사 완료 예시**

| 현재 오브젝트 흥미도 \= 120 조사 완료 감소율 \= 50% 감소량 \= 120 × 0.5 \= 60조사 후 오브젝트 흥미도 \= 60 |
| :---- |

## **회수 중 유닛 사망으로 오브젝트 드랍**

* 회수 전 오브젝트는 조사 완료 상태로 본다.  
* 회수 중 유닛이 사망해 오브젝트를 떨어뜨리면, 조사 완료 후 50% 감소된 흥미도 값을 다시 적용한다.

| 드랍 후 오브젝트 흥미도 \= 오브젝트 데이터 기본 흥미도 × 0.5 |
| :---- |

예시:

| 오브젝트 기본 흥미도 \= 120회수 중 유닛 사망오브젝트 드랍 드랍 후 오브젝트 흥미도 \= 120 × 0.5 \= 60 |
| :---- |

**18\. 유닛 흥미도와 이해도 관계**

| 일반 유닛 흥미도 \= 유닛 기본 흥미도 × (100 \- 이해도 적용값)% |
| :---- |

* 이해도 1당 일반 유닛 흥미도는 1% 감소한다.  
* 이해도 적용값이 100이면 일반 유닛 흥미도는 0이 된다.  
* IsInterestTarget 값이 true인 유닛은 위 공식을 사용하지 않거나, 별도 감소식을 사용한다.

## **예시**

| 유닛 기본 흥미도 \= 100 이해도 적용값 \= 35 일반 유닛 흥미도 \= 100 × 65% \= 65 |
| :---- |

# **19\. 시체 / 흔적 흥미도**

전멸한 파티의 시체 / 흔적이 전멸 흔적과 각각 발견될 경우 합산하지 않고 전멸 흔적으로 계산한다.

| 흔적 유형 | 기본 흥미도 |
| :---: | :---: |
| 시체 / 흔적 | 10 |
| 전멸 흔적 | 25 |

시체와 흔적은 인류 유닛이 확인하면 원인 확인 여부와 관계없이 해당 흔적의 흥미도를 제거한다.

| 조건 | 처리 |
| :---: | :---: |
| 시체 / 흔적 확인 | 흔적 흥미도 0 |
| 전멸 흔적 확인 | 전멸 흔적 흥미도 0, 전멸 흔적 발견 정보 생성  |

시체 / 흔적 확인으로 이해도와 위험도가 증가할 수 있다.   
이 경우 E\_CORPSE\_TRACE\_CHECK 이벤트 기본값을 사용한다.

전멸 흔적 발견 정보의 전역 던전 위험도 반영값은 13-2장 전멸 흔적 규칙을 따른다. 

전멸시킨 존재의 위험도 단계에 따라 흥미도가 증가한다.

| 시체, 흔적 흥미도 \=시체, 흔적 기본 흥미도 \+ 원인 대상 위험도 단계 보정값 위험도 단계 0: \+0위험도 단계 1: \+5위험도 단계 2: \+10위험도 단계 3: \+15위험도 단계 MAX: \+20  |
| :---- |

# **20\. 방 위험도**

| 항목 | 값 |
| :---: | :---: |
| 일반 미탐사 방 기본 위험도  | 20 |
| 보스방 미탐사 기본 위험도  | 70 |
| 탐사 진행 중 일반방 기본 위험도 | 10 |
| 탐사 진행 중 보스방 기본 위험도 | 35 |

인류 유닛은 방 전체 크기를 모른다.

따라서 전체 타일 수, 미확인 타일 비율, 탐사 진행률을 정확히 계산할 수 없다.

탐사 진행 중 방은 확인되지 않은 영역이 남아 있다는 사실만 반영하여 고정값을 사용한다.

| 미탐사 방 위험도 \= 미탐사 방 기본 위험도 적용탐사중인 방 위험도 \= 확인된 방 내부 유닛 위험도 합산 \+ 확인된 방 내부 오브젝트 위험도 합산 \+ 탐사 진행 중 방 위험도 고정값 탐사 완료한 방 위험도 \= 확인된 방 내부 유닛 위험도 합산 \+ 확인된 방 내부 오브젝트 위험도 합산 |
| :---- |

* 타일 위험도는 방 위험도에 합산하지 않는다.

## **예시**

| 방 내부 유닛 위험도 합산 \= 650 방 내부 전투 오브젝트 위험도 합산 \= 480 방 위험도 \= 1130 |
| :---- |

# **22\. 던전 전체 위험도 / 흥미도**

던전 전체 위험도와 흥미도는 내부 합산값이므로 999를 초과할 수 있다.

방의 탐사 상태 정의는 20장과 21장을 따른다.

던전 전체 위험도와 흥미도는 각 방의 최종 위험도 / 흥미도를 합산해 산출한다.

탐사 완료 방의 위험도와 흥미도는 0으로 고정하지 않는다.

탐사 완료 방의 최종 위험도와 흥미도는 방 내부에 남아 있는 유닛, 오브젝트, 흔적 등 위험도/흥미도 요소의 총합으로 결정한다.

| 던전 전체 위험도 \=모든 기록된 방 위험도 합산\+ 파티 전멸 던전 위험도 누적값\+ 전멸 흔적 발견 전역 반영값 누적  던전 전체 흥미도 \= 모든 기록된 방 흥미도 합산 |
| :---- |

# **23\. 정보 오차**

| 정보 상태 | 위치 오차 | 수치 오차 |
| :---: | :---: | :---: |
| 직접 경험 | 0타일 | 0% |
| 직접 목격 | 0타일 | ±5% |
| 간접 파악 | ±1타일 | ±10% |
| 정신력 공포 단계 | ±1타일 | ±15% |
| 정신력 공황 단계 | ±2타일 | ±25% |

수치 오차는 실제값에 오차율을 곱한 범위 안에서 정수값으로 인식한다.

## **예시**

| 실제 위험도 \= 100 정보 상태 \= 간접 파악 수치 오차 \= ±10% 인식 범위 \= 90\~11090\~110 사이 정수값 중 하나를 랜덤값으로 추출 후 고정해 기록 위험도로 사용한다.이는 실제 위험도 or 정보 상태가 달라질 때마다 변한다. |
| :---- |

* 전역 정보에서 발생한 수치 오차는 파티 입장 시 한 번만 산출하며, 같은 파티의 모든 유닛은 동일한 기록 수치를 공유한다.  
* 던전 내부에서 개별 유닛이 새로 획득한 정보는 유닛별 정보 상태에 따라 별도로 오차를 산출한다.  
* 정신력 상태로 인한 오차가 정보 유형 오차보다 클 경우, 더 큰 오차를 사용한다.

# **25\. 공황 단계 정보 평균 처리**

공황 단계 유닛의 정보는 우선순위가 높더라도 단독으로 완전한 최우선 정보로 처리하지 않는다.

| 정보 | 가중치 |
| :---: | :---: |
| 공황 단계 유닛 기록값 | 0.3 |
| 다음 우선순위 유닛 기록값 | 0.7 |

| 최종 기록값 \= 공황 단계 유닛 기록값 × 0.3 \+ 다음 우선순위 유닛 기록값 × 0.7 |
| :---- |

## **예시**

| 공황 단계 유닛 기록 위험도 \= 140 / 다음 우선순위 유닛 기록 위험도 \= 100 최종 기록 위험도 \= 140 × 0.3 \+ 100 × 0.7 \= 112 |
| :---- |

위치 정보의 경우, 공황 단계 유닛의 위치 기록은 정상 또는 공포 단계 유닛의 위치 기록이 함께 존재할 때 단독 확정값으로 사용하지 않는다.   
공황 단계 유닛만 생환한 경우 해당 유닛의 기록값을 단독 확정값으로 사용한다.
