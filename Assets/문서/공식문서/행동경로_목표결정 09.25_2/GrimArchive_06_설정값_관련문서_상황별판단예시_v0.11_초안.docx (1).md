# **1\. 조정 가능한 초기값 목록**

표의 수치는 조정 가능한 초기값이다.   
역할 배율·종류 배율·거리·HP·시간을 각각 조정하고, 변경 시 해당 규칙과 설정값 목록을 함께 갱신한다.   
20% 점수 차이는 대상 변경에 적용하며, 같은 대상을 향한 경로 변경에는 적용하지 않는다.

# **2\. 후속 문서에서 정할 수치와 조건**

| 판단에 사용할 정보 | 지금 정의한 사용 방식 | 관련 문서차후 작성 예정 |

| 파티 종류별 임무·흥미도 가중치 | 01의 범주와 점수에 입력 | 파티 종류·목표·진형 |

| 방 탐색 최소 미완료 방 K·추가 방 E | 임무 발급 시 B+E 할당 | 침입·웨이브 / 파티 종류·목표·진형 |
| 몬스터 종류별 처치 수 반영 배율 | 시스템이 공통 임무에 중복 없이 합산 | 침입·웨이브 / 파티 종류·목표·진형 |
| 회수 완료·반출·분실의 실제 사건 | 개인 행동 완료와 임무의 회수 수량에 반영 | 전리품·회수물 |

| 도주·후퇴 시작·종료·우회 허용 | 강제 상태와 차단 적 대응에 입력 | 정신력·도주·후퇴 |

| 인원·역할별 진형 간격·분산 범위 설정 | 실제 이동 목적지·진형 자리 제공 | 파티 종류·목표·진형 |
| 보스방 발견 후 다음 웨이브 선택 | 보스 임무 후보·편성 시점 제공 | 침입·웨이브 |
| 문 개폐·파괴의 소요 시간과 수리·전투 경계 상세 | 개폐 권한은 04번 10항 확정 규칙 적용. 후속 문서는 소요 시간·수리·전투 경계 등의 세부 결과 제공 | 문·증원·전투 경계 |
| 스킬 취소·투사체·상태이상 처리 | 실제 실행·중단·완료 사건 제공 | 전투·스킬·상태이상 |

위 항목의 세부 수치·조건은 차후 작성 예정이다.   
값이 정해지면 해당 행동과 아래 상황별 판단 예시에 적용해 결과를 확인한다.

# **5\. 검증 문서 연결**

검증할 내용·기대 결과·검증 의도는 같은 폴더의 07번 문서 「검증 항목과 설계 의도 및 판정 기준」을 따른다. 게임 저장·불러오기에 관한 검증은 07번 문서 8번 항목 「후속 문서 작성 후 검증할 내용」에서 확인한다. 저장 기능의 적용 시점과 범위를 정한 뒤, 진행 중인 행동·대기시간·임무 수량이 해당 기준에 맞게 이어지는지 검증한다.
