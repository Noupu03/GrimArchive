몬스터 배치 프리셋 프로그래머 지시서 (08.19, 실제 구현 반영 — 2026-08-20 갱신)
목적
몬스터 개별 유닛에 디펜스 시작 시 이동할 위치를 지정할 수 있도록 한다.

핵심 조작 레퍼런스는 RimWorld의 소집 기능으로 두었으나, 실제 구현은 "개별 유닛 우클릭 이동" 방식이 아니라 점령한 방 단위로 진입하는 전용 배치 모드로 구현되었다(아래 기본 개념 참고).

---

기본 개념
배치는 "점령한 방" 단위로 진입한다 — 배치 대상 방을 먼저 고른 뒤, 그 방 안에서만 몬스터 선택과 위치 지정이 가능
배치 지정 단위는 개별 몬스터(같은 방에서 여러 몬스터를 한 번에 골라 순서대로 배치 가능)
전용 배치 모드로 진입하며, 진입 중에는 게임 시간이 멈춘다(원안에는 없던 사항 — 사용자 요청으로 추가)
기존 셀렉트 기능(드래그 박스/더블클릭/Ctrl+클릭)은 몬스터 선택 단계에서 그대로 재사용
개별 유닛 우클릭 이동은 배치 지정에 쓰이지 않는다 — 아래 "배치 위치 지정" 참고
각 몬스터는 별도의 디펜스 시작 위치 데이터를 보유(원안과 동일)

---

배치 모드 진입/종료
R 키를 누르거나(선택된 유닛 유무와 무관), 화면 하단 메뉴의 "소집 배치" 버튼을 누르면 배치 모드를 토글한다.

진입 조건: 인류 웨이브가 오지 않은 대기 상태(웨이브 진행 중에는 진입 불가 — 안내 문구 표시)
진입 시: 게임 시간이 멈춘다(스페이스바 일시정지와 동일한 방식). 이전에 이미 일시정지 상태였다면 종료 시 그 상태를 그대로 복원
종료 시: 이 시점까지 지정된 배치 위치만 저장된 채로 남고, 몬스터들의 실제 행동에는 아무 영향을 주지 않는다(즉시 이동하지 않음)
다른 하단 메뉴(설치 등)로 전환하거나 소집 배치 버튼을 다시 누르면 모드가 종료된다

---

배치 흐름
방 선택 → 몬스터 선택(다중 선택 가능) → 타일 선택으로 전환 → 방 안 타일을 순서대로 클릭/드래그해 배치 → (필요시 반복) → R 키 또는 메뉴로 배치 모드 종료

세부 규칙:

1. 방 선택 단계 — 점령한(플레이어 진영) 방만 선택 가능. 화면에 선택 가능한 방 전체가 테두리로 표시된다.
2. 몬스터 선택 단계 — 선택한 방 "안에" 있는 몬스터만 선택 대상이 된다(방 밖 유닛은 선택 자체가 안 됨). 기존 드래그 박스/더블클릭(동일 유형 근처 일괄 선택)/Ctrl+클릭 추가 선택을 그대로 사용.
3. 타일 선택 단계로 전환하면, 그 시점에 선택돼 있던 몬스터들이 배치 대기열에 순서대로 쌓인다.
4. 방 안의 타일을 클릭(또는 드래그로 여러 칸 연속 지정)하면 대기열 맨 앞 몬스터부터 순서대로 그 위치에 배치된다. 벽/건물 등 이동 불가능한 타일에는 배치할 수 없다.
5. 이미 배치가 끝난 타일을 다시 클릭하면 그 배치를 취소하고 해당 몬스터를 대기열 맨 앞으로 되돌린다(재배치 가능).
6. 몬스터 선택 단계로 언제든 다시 돌아가 다른 몬스터를 추가로 고를 수 있다.

방 선택 후에는 화면에 남은 대기열(유닛 유형별 개수)과 이미 배치된 위치의 반투명 실루엣이 항상 표시된다.

---

디펜스 시작 시 동작
"디펜스 시작"의 실제 시점은 해당 웨이브의 인류 파티가 0층에 소환되는 순간이다(웨이브 카운트다운이 끝나기 조금 전, 사전 스폰 시점).

이 시점에 모든 플레이어 진영 몬스터가 일괄 "소집" 상태로 전환된다.

디펜스 시작 위치가 지정된 몬스터 → 그 위치로 이동 명령이 내려진다
디펜스 시작 위치가 지정되지 않은 몬스터 → 이동하지 않고 제자리에서 소집 상태로 전환된다(원안의 "기존 기본 행동 기준 유지"에서 변경 — 탐색 등 평소 행동 대신 그 자리에서 대기)
소집된 몬스터는 침입 방향(시작방이면 계단 방향, 그 외의 방이면 침입자가 들어올 문 방향)을 바라보고 대기한다

소집 상태는 몬스터가 실제 전투 위협을 인지하는 순간 자동으로 해제되며, 그 뒤로는 기존 몬스터 AI(전술/전투 판단)를 그대로 따른다 — 플레이어가 다시 조작할 필요는 없다.

본 기능은 전투 AI를 변경하는 시스템이 아니라 디펜스 시작 전 초기 배치 위치를 지정하는 기능이라는 원안의 취지는 그대로 유지된다.

---

데이터 분리
아래 두 값은 서로 분리하여 관리한다(원안과 동일하게 유지됨).

현재 이동 목적지
디펜스 시작 위치

일반 탐색, 이동, 전투 중 발생하는 위치 변경이 저장된 디펜스 시작 위치를 덮어쓰지 않는다.

디펜스 시작 위치는 배치 모드의 타일 선택 단계에서만 갱신된다.

---

다중 선택
여러 몬스터를 동시에 선택한 상태에서도 동일하게 동작한다(몬스터 선택 단계 한정).

드래그 박스/더블클릭/Ctrl+클릭 → 선택된 방 안에서 여러 몬스터 한 번에 선택
타일 선택 전환 → 선택된 몬스터 전원이 대기열에 순서대로 쌓임
타일을 순서대로 클릭/드래그 → 대기열 순서대로 한 마리씩 배치

---

구현 범위
실제 구현된 항목은 다음과 같다.

R 키 또는 하단 메뉴 버튼으로 배치 모드 진입/종료 토글(웨이브 대기 중에만 가능)
배치 모드 진입 시 게임 시간 정지, 종료 시 이전 상태로 복원
점령한 방을 먼저 선택해야 그 방 안에서 배치 가능(방 단위 진입)
방 안 몬스터 다중 선택(드래그/더블클릭/Ctrl+클릭 재사용)
방 안 타일을 순서대로 클릭/드래그해 대기열 기반으로 순차 배치
이미 배치된 위치 재클릭 시 배치 취소(대기열로 복귀)
몬스터별 디펜스 시작 위치 데이터 유지, 일반 이동 목적지와 분리 관리
0층 인류 소환 시점에 저장 위치로 이동 명령 + 미배치 몬스터 제자리 소집 처리
소집 상태 자동 해제(전투 위협 인지 시) 후 기존 AI 복귀
배치 가능 방 테두리 표시, 선택 방 강조, 타일 격자 강조, 배치 완료 실루엣 등 시각 피드백

프리셋 슬롯 저장, 여러 배치안 전환, 별도 배치 UI(전용 화면)는 이번 구현 범위에 포함하지 않는다 — 이 부분은 원안과 동일하게 범위 밖으로 유지된다.
