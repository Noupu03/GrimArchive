몬스터 배치 프리셋 프로그래머 지시서 (08.19)
목적
몬스터 개별 유닛에 디펜스 시작 시 이동할 위치를 지정할 수 있도록 한다.

핵심 조작 레퍼런스는 RimWorld의 소집 기능으로 두며, 기존 몬스터 선택 및 우클릭 이동 조작을 최대한 그대로 활용한다.

---

기본 개념
배치 지정 단위는 개별 몬스터
여러 몬스터를 동시에 선택하여 일괄 지정 가능
별도의 배치 전용 화면은 사용하지 않음
기존 셀렉트 및 우클릭 이동 기능을 재사용
각 몬스터는 별도의 디펜스 시작 위치 데이터를 보유

---

소집 토글
몬스터가 선택된 상태에서 R 키를 누르면 소집 상태를 토글한다.

소집 활성화
선택된 몬스터의 기본 행동인 탐색을 중단
현재 위치에서 대기 상태로 전환
이후 우클릭 이동 명령 사용 가능

소집 비활성화
몬스터를 다시 기존 탐색 행동으로 복귀
소집 상태에서 마지막으로 지정된 배치 위치를 해당 몬스터의 디펜스 시작 위치로 저장

여러 몬스터가 선택되어 있을 경우 R 키 입력은 선택된 몬스터 전체에 적용한다.

---

배치 위치 지정
소집 상태의 몬스터를 선택한 뒤 기존과 동일하게 우클릭 이동 명령을 사용한다.

흐름:

몬스터 선택 → R 키로 소집 → 우클릭 위치 지정 → 이동 → R 키로 소집 해제

소집 상태에서 지정된 최종 위치는 일반 이동 목적지와 별개로 디펜스 시작 위치로 저장한다.

---

디펜스 시작 시 동작
디펜스가 시작되면 각 몬스터는 자신에게 저장된 디펜스 시작 위치를 확인한다.

저장된 위치가 존재할 경우 해당 위치로 이동
저장된 위치가 없는 경우 기존 기본 행동 기준을 유지
지정 위치로 이동한 이후 실제 전투 행동은 기존 몬스터 AI를 따른다

본 기능은 전투 AI를 변경하는 시스템이 아니라 디펜스 시작 전 초기 배치 위치를 지정하는 기능이다.

---

데이터 분리
아래 두 값은 서로 분리하여 관리한다.

현재 이동 목적지
디펜스 시작 위치

일반 탐색, 이동, 전투 중 발생하는 위치 변경이 저장된 디펜스 시작 위치를 덮어쓰지 않도록 한다.

디펜스 시작 위치는 소집 상태에서 배치 위치를 지정한 경우에만 갱신한다.

---

다중 선택
여러 몬스터를 동시에 선택한 상태에서도 동일하게 동작한다.

R 키 입력 → 선택 몬스터 전체 소집
우클릭 이동 → 기존 다중 유닛 이동 방식 적용
소집 해제 → 각 몬스터의 최종 배치 위치를 개별 저장

다중 유닛의 실제 이동 및 위치 분산 방식은 기존 이동 시스템을 그대로 사용한다.

---

구현 범위
이번 단계에서 구현할 항목은 다음과 같다.

선택된 몬스터 대상 R 키 소집 토글
소집 시 탐색 행동 중지
소집 상태에서 기존 우클릭 이동 사용
소집 해제 시 디펜스 시작 위치 저장
몬스터별 디펜스 시작 위치 데이터 유지
디펜스 시작 시 저장 위치로 이동
다중 선택 상태 지원

프리셋 슬롯 저장, 여러 배치안 전환, 별도 배치 UI 등은 이번 구현 범위에 포함하지 않는다.
