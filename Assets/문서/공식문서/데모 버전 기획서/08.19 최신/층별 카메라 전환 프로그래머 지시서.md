층별 카메라 전환 프로그래머 지시서
목적
각 층이 하나의 화면에 동시에 노출되지 않도록 층별 카메라 관찰 영역을 분리하고, 플레이어가 키 입력으로 층 사이를 전환할 수 있도록 한다.

---

층 배치
각 층은 동일한 맵 공간 안에 배치하되, 서로 충분한 물리적 거리를 두고 분리한다.

0층, 1층 및 이후 층을 서로 떨어진 위치에 배치
한 층을 보고 있을 때 다른 층이 화면에 함께 들어오지 않도록 간격 확보
별도의 Fog of War 또는 렌더링 분리 시스템은 사용하지 않음

---

층 전환 조작
플레이어는 다음 키, 층 전환 ui를 사용하여 현재 관찰 층을 변경한다.

[ : 이전 층 (화면 내 중앙 왼쪽에 < 버튼 배치)
] : 다음 층 (화면 내 중앙 왼쪽에 > 버튼 배치)

층 전환은 유닛의 이동이 아니라 카메라 관찰 위치 변경으로 처리한다.

---

전환 시 카메라 위치
층 전환이 발생하면 카메라를 전환된 층의 중앙 지점으로 이동시킨다.

기존 층에서 마지막으로 보고 있던 카메라 위치는 현재 단계에서는 별도로 저장하지 않는다.

기본 흐름:

층 전환 입력 → 대상 층 결정 → 대상 층 중앙으로 카메라 이동

---

카메라 이동 범위
각 층에는 별도의 카메라 이동 가능 영역을 설정한다.

현재 선택된 층의 영역 안에서만 카메라 이동 가능
카메라를 가장자리까지 이동하더라도 다른 층 영역으로 넘어갈 수 없도록 제한
카메라 줌아웃 상태에서도 다른 층이 동시에 노출되지 않도록 층간 물리적 거리를 확보

---

구현 범위
이번 단계에서는 다음 항목을 구현한다.

층별 물리적 위치 분리
현재 관찰 층 데이터 관리
[ / ] 키, ui 버튼기반 층 전환
전환 시 대상 층 중앙으로 카메라 이동
층별 카메라 이동 영역 제한
다른 층이 한 화면에 동시에 노출되지 않도록 층간 거리 조정
