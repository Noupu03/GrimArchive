자원 경제 · 유닛 생산 구현현황 (2026-11-05)
════════════════════════════════════════════════════════════════════════
작성 목적: `GrimArchive 자원 경제와 유닛 생산 설계명세서 v0.2 개정 (2026-10-29)`의 구현 범위·구조·판단·자리표시자·검증 결과를 기록한다. 자원·시설·생산·시체 정제·연구·진화·건설/수리/코어 수복/분해 이동을 다시 손댈 때는 이 문서부터 확인한다(다른 구현현황 문서와 같은 관례).
사용자 확정 (2026-11-05 질문 3건 답):
  ① 구현 범위: **Phase 1~4 전체 순차 구현** — 외부 미작성 명세 영역(진화 분기 목록·연구 상세 목록·배치모드 세부·실제 통합 엑셀 수치)은 명세서 공통 정산·연출 엔진 + 프로토타입 기본값/스텁(`🔶 자리표시자`)으로 연결.
  ② 건설·수리·수복·분해 전환 수준: **명세서(5·16~20항) 기준 현장 작업자 진행·수리 추가피해 차액 수동 승인·코어 잔해(50% 감면) 수복·1타일 이동용 분해까지 모두 적용**.
  ③ 자원 교체 및 시작방 초기 배치: **`Wood/Stone`을 `LifeEnergy/SoulShard`로 전면 교체 + 처치 즉시 보상 제거 + 시작방에 생명 에너지 시설·시체 보관·정제 통합시설·유닛 생산시설 + 작업 특화 몬스터 자동 배치(25-1항)**.

■ 문서가 뒤집은 것 (이전 구현과 달라진 점)
────────────────────────────────────────────────────────────────────────
· 자원 체계 전면 교체: `ResourceType.Wood` / `ResourceType.Stone` 삭제 → **`LifeEnergy(생명 에너지)` + `SoulShard(영혼 파편)`** 2종 체계(`Assets/**/*.cs` 내 `Wood`/`Stone` 참조 0건). 내부 잔고는 `double` 소수로 정밀 유지하되 UI 표시는 정수 버림(`FloorDisplay`, `N (-M)` 선배정 대기 표기), 소수 비용 결제는 정수 올림(`CeilCost`), 환급·해체·보조금과 구분해 외부 순유입만 누적 집계(`CumulativeEarned`, `CountsTowardCumulativeEarned`).
· 인류·야생 처치 즉시 자원 지급 전면 제거: `HumanFactionBehavior.OnUnitDied` / `WildMonsterBehavior.OnUnitDied`의 즉시 지급을 없애고, **시체를 회수해 통합 정제시설에서 정제 완료해야만** 생명 에너지·영혼 파편을 얻는다. 다음 웨이브 시작 시 기존 시체를 일괄 삭제하던 `GameSession.DespawnCorpsesForNewWave`도 비활성화했다(필드/운반 중 기본 180초 부패 소멸, 시설 내 보관 중 부패 시계 정지).
· 건물 즉시 설치·자동 주기 생산 폐기: 청사진 현장을 먼저 세우고 작업자가 상하좌우 인접 타일에 도착해 **실제 착공하는 순간** 비용을 차감한다(자원 부족 시 청사진 유지·착공 보류). 생명 에너지 시설도 작업자 0명이면 생산하지 않고 현재 구간 게이지를 유지한 채 정지하며, 작업자 최대 4기 공동 작업 배율(`1.0 / 0.7 / 0.5 / 0.3`)과 작업 특화 몬스터 산출량 보너스를 구간 기여 비례(`AdvanceSegmentByGaugeRatio`)로 합산한다.
· 손상 시설 가동 정지 및 추가 피해 차액 수동 승인: 완공 시설의 현재 HP가 최대 HP 미만이면 최대 HP까지 수리하기 전에는 일반 기능(생명 에너지 채취·유닛 생산·시체 정제·연구)과 업그레이드가 정지된다. 수리 또는 코어 수복 도중 적 공격으로 추가 피해가 생기면 차액을 자동 결제하지 않고 진행을 멈추며 UI의 `[추가 수리비 승인]` / `[추가 수복비 승인]` 수동 클릭을 기다린다.
· 코어 수복 즉시 완료(`RestoreStoneCost = 300`) 폐기: `CoreSystem.RestoreLifeEnergyCost = 300`(생명 에너지) + 현장 작업자 투입 진행(`CoreRestoreSession`)으로 전환. 같은 코어방 안에 미회수 코어 잔해(`CoreSalvage`)가 있고 수복 시작 시 선택하면 수복 비용 50% 감면(잔해는 수복 완료 시 소모, 수복 취소 시 필드로 반환).
· 유닛 생산 묶음 예약·대기 감축·선두 교체 정산·출현 중재: 1~99기 묶음 항목 등록, 선두 1기만 비용 선점 + 후속 미지불 대기(`N (-M)`), 비선두 감축 및 다수 묶음 잔여 대기 수량 1기 감축은 환급 없이 예약만 해제, 선두 취소가 진척 > 0%일 때만 취소 수수료 공제 환급, 비선두↔선두 순서 변경 시 기존 선두 전액 무수수료 환급 후 신규 선두 즉시 선점(잔고 부족 시 순서 변경 거부), 진행도 100% 도달 시 조건 미충족이면 `생산 완료 · 출현 대기`로 멈추고 방 단위 다중 시설 출현 중재(`SpawnArbitrator`, 완료 시각 → 시설 고유 번호 오름차순)로 처리.
· 영혼 파편 해금·전역 연구 원장·개체 진화: 첫 코어 완전 활성화 시 `영혼 파편` 소비 및 `연구시설` 건설이 영구 해금(`ResourceManager.UnlockSoulShardAndAdvancedSystems`). 연구 진척은 시설 로컬이 아니라 전역 원장(`GlobalResearchLedger`)에 보존되며, 수동 취소는 환급 + 진척 보존(재개 시 전액 재결제), 시설 파괴·철거는 지불 상태 + 진척 보존(다른 연구시설에서 추가 비용 0으로 이어서 재개). 개체 진화(`EvolutionSession`)는 조건 충족 시점 자동 진화가 아니라 플레이어 수동 실행 즉시 결제 + 초 단위 연출 잠금(피격은 허용·사망 시 환급 없음·완료 시 기존 이동/공격 명령 복원 + `StatModifierLedger` 능력치 반영)이며, 진화 완료 몬스터 사망 시 시체 영혼 파편 보상에 `누적 기준 진화 비용 × 20%`가 가산된다.

■ 장별 구현 현황 (✅구현 / 🔶부분·자리표시자 / ❌미구현)
────────────────────────────────────────────────────────────────────────
1~2항 자원 정의·단위·표시  ✅ `LifeEnergy` / `SoulShard` 2종 전면 교체, 소수 내부 잔고, 소수 비용 올림(`CeilCost`), 표시 정수 버림(`FloorDisplay`), 미차감 예약 합계 `N (-M)` 병기, 부족 시 필요/보유/부족량 안내, 일시정지 중 진행 0·예약 입력 허용, 코어 완전 활성화 시 영혼 파편 소비 영구 해금(코어 일시 파괴 중에도 해금 유지).
3항 누적 획득량            ✅ 외부 순유입만 `CumulativeEarned`에 합산, 취소 환급·시설 해체·야생 시설 전리품·아군 시체 회수 보조금은 현잔고만 증가하고 누적 획득량 제외(`CountsTowardCumulativeEarned`). 🔶 누적 획득량 임계치에 반응하는 특수 습격·던전 황폐화 이벤트 자체는 별도 침공/이벤트 명세 소관이라 조회 프로퍼티·스냅샷만 열어 둠.
4~5항 작업 유닛·공동 작업  ✅ 전투 유닛 일반 작업 가능, 상하좌우 인접 타일 도착 시 작업 참여, 최대 4기 공동 작업 배율(`1.0 / 0.7 / 0.5 / 0.3`, 빠른 작업자 내림차순 정렬), 5번째 작업자 진입 거부, 작업 중 자동 교전 차단 및 타 명령·사망·공포 이탈 시 작업자 수 즉시 재계산. 🔶 배치모드 방어 위치 `[이동 적용]` 버튼과의 연동은 외부 배치모드 UI 명세 소관이라 `BuildingManager.NotifyWorkerCommandChanged(unit)` 단일 진입점으로 훅 제공.
6~7항 시설 해금·분류       ✅ 초기 해금 3종(`생명 에너지 시설`, `시체 보관·정제 통합시설`, `유닛 생산시설`), 첫 코어 완전 활성화 시 `연구시설` 영구 해금, 손상 시설(HP < 최대 HP) 일반 가동·업그레이드 정지, 담당 코어 파괴 중 신규 건설·생산·연구·업그레이드 차단 및 진행도 보존 정지(수복 시 재개). 🔶 함정·방어건물 카탈로그 확장은 별도 방어시설 명세 소관.
