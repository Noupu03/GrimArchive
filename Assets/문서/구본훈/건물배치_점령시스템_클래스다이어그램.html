점령(Offense) 실행 흐름
# 호출 지점 처리 내용
1
 GameSession.ProcessUnitAction() PlayerMonster 이동 후 TryTriggerOffenseForUnit(unit) 호출
2
 OffenseProcessor.TryStartOffense() 야생 방(RoomFaction == Wild)이면 _activeOffenseRooms에 추가. 빈 방이면 즉시 TryClaimEmptyRoomOnEntry()로 무혈 점령
3
 OffenseProcessor.UpdateProcess() 매 프레임 CheckOffenseSuccess(room) 폴링. Normal 방: 야생 유닛 전멸 확인. Spawner 방: 거점(DungeonCore) 파괴 확인
4
 OffenseProcessor.OnOffenseSuccess() room.RoomFaction 변경 → IMapColorizer.ChangeRoomColor() → CreateMap.SetRoomOccupationState()로 Chunks.occupationState 동기화
5
 GameSession.RemoveDeadUnit() 유닛 사망 시 OffenseProcessor.TryFlipRoomOwnershipOnDeath(deadUnit) → TryResolveRoomOwnership(room, ...)로 방 소유권 재계산
6
 GameSession.RefreshRoomGateStates() 단일 진영만 남은 방의 Gate.isDoorClosed를 false로 갱신. 웨이브 시작 시에는 CloseAllDoorsForWaveStart()로 전체 문 잠금
건물(Building) 배치 흐름
# 호출 지점 처리 내용
1
 GameSession.SpawnInitialBuildings() 시작 방(StartRoom)에서 설치 가능한 타일 탐색 후 자원 건물·유닛 생산 건물 자동 배치
2
 BuildingManager.CanInstallAt(pos) CreateMap.IsPositionPlayerOwned()로 플레이어 지배 타일인지 확인 + 기존 건물 없는지 체크
3
 BuildingManager.InstallResourceBuilding() / InstallProductionBuilding() BuildingData 생성 → buildingGrid[pos] 등록 → CreateMap 해당 타일 obstacle 갱신 → 시각 오브젝트 생성
4
 BuildingManager.UpdateProcess() 자원 건물: 5초마다 ResourceManager에 자원 +5. 생산 건물: Queue의 ProductionRule을 소비하며 생산 시간 경과 시 SpawnUnitFromBuilding() 호출
