BT (Behavior Tree) 다이어그램

각 FSM 상태의 BT 구조  |  2026-07-28

Selector (OR) — 첫 Success/Running 반환
Sequence (AND) — 첫 Failure/Running 반환
Condition — bool → Success/Failure
Leaf — 실제 행동 실행
🎮 PlayerCommandFSMState — BT
  • Selector[OR]
    • Sequence[AND]
      • Condition: HasPlayerAttackTarget
      • Leaf: ExecutePlayerAttack
    • Sequence[AND]
      • Condition: HasPlayerMoveCommand
      • Leaf: ExecutePlayerMove
      • Leaf: CompletePlayerCommand
  • ExecutePlayerAttack: 적 유효하면 스킬 범위 내 → 공격, 아니면 MoveTowardsTarget. 막히면 FindNearbyOpenTile로 우회.
  • ExecutePlayerMove: 목표 도착 시 Success. 막히면 fallback 재지정 → 구조적 완전 차단 시 명령 포기(로그 출력).
  • CompletePlayerCommand: playerMoveTarget=null, isManualMoveCommand=false, oneTimeReactUsed=false.
⚔️ CombatFSMState — BT
  • Leaf: ExecuteCombat[단일 노드]
ExecuteCombat 내부 우선순위 (코드 순서)
  1. isCastingAttack? → 즉시 Running 반환 (공격 모션 중 대기)
  2. GetClosestEnemy → target 선택 (같은 층, 같은 방 제한 적용)
  3. 우선순위 높은 사용 가능 스킬 선택 (bestSkill)
  4. bestSkill이 원거리(hitRange ≥ 4) && 적이 위험거리(range/2) 이하 → 키팅: MoveAwayFromTarget
  5. bestSkill의 히트박스 안에 적 포함 → 스킬 Execute
  6. 그 외 → MoveTowardsTarget (접근)
  7. 모든 스킬 쿨다운 시 → 원거리면 안전거리 유지, 근거리면 거리 조정
  • IsRoomConfined: MovementAlgorithm이 RoomConfinedMovement인 경우 방 밖 적 무시.
  • evadeCooldown > 0: 이동 행동 스킵 (회피 쿨다운 중).
🧠 TacticalFSMState — BT
  • Selector (TacticalBehaviorPriorityConfig 순서)[OR]
    • Sequence — Panic[AND]
      • Condition: IsPanic (mental < maxMental×0.3)
      • Leaf: Panic (50% 확률 무작위 이동)
    • Selector — TrapResponse[OR]
      • Sequence — 선정 유닛 수색 중[AND]
        • Condition: IsSearchingForMissingUnit
        • Leaf: TrapSearchForMissingUnit
      • Sequence — 선정 유닛 대기[AND]
        • Condition: IsAwaitingSelectedUnit
        • Leaf: TrapAwaitSelectedUnit
      • Sequence — 해제 (Disarm)[AND]
        • Condition: CanDisarm (해제 가치 있음 && 피격/위협 없음)
        • Leaf: TrapJoinWait (합류 대기)
        • Leaf: MoveToTrap (Chebyshev≤1까지 이동)
        • Leaf: TrapDisarmPerform (진행도 타이머 → 성공/실패)
      • Leaf: TrapBypass (길 비켜서 우회)
      • Leaf: TrapPass (HP 계산 후 통과 감수)
      • Leaf: TrapDestroy (함정 파괴)
    • Sequence — Alert (경계)[AND]
      • Condition: HasAlert (currentAlertSearch != null)
      • Selector[OR]
        • Leaf: DeathSearchMove (4-15장: 원인미상 사망 수색)
        • Leaf: AlertApproach (목표 지점으로 접근)
        • Leaf: AlertPerimeterSearch (주변 순찰)
    • Sequence — Investigate (조사)[AND]
      • Condition: CanInvestigate (Human && 타깃 있음 && 피격/위협 없음)
      • Leaf: MoveToInvestigateTarget (Chebyshev≤1까지 이동)
      • Leaf: InvestigatePerform (진행도 타이머 → 파티 공유)
      • Leaf: PickUpObject (Loot면 회수 → 탈출 스타트)
    • Sequence — Wait (대기)[AND]
      • Condition: HasWait (Human && currentWait != null && 피격/적 없음)
      • Leaf: ExecuteWait (집결지 이동 → 도착 시 CheckRallyComplete)
    • Sequence — Formation (포메이션)[AND]
      • Condition: HasFormationNeed (HasProtectiveFormationNeed)
      • Sequence[AND]
        • Selector[OR]
          • Leaf: MoveToMeleeSlot (근거리 슬롯)
          • Leaf: MoveToRangedSlot (원거리 슬롯)
        • Leaf: HoldFormation (감시 방향 배정, 벽 차단 시 재배정)
    • Sequence — Core (리더 전용)[AND]
      • Condition: CanContinueCore (리더 && PendingCore && 같은 층 && 피격없음)
      • Leaf: MoveToCore (Chebyshev≤1, 코어 타일 위면 StepOff)
      • Leaf: CoreInvestigatePerform (전파→진행도→파티 공유→Loot회수)
  • TacticalBehaviorPriorityConfig 에셋이 있으면 그 order/enabled 순서로 Selector 구성. 없으면 위 기본 순서.
  • 함정 해제/조사 중단(피격·위협) 시 PenaltyActive=true인 경우만 진행도 50% 손실 적용(중복 방지).
  • CanInvestigate: 파티 목표 오브젝트(HumanWaveManager.dummyTarget)면 호위 피격 시에도 조사 유지.
  • Formation 감시 방향: 전방/후방 구간·좌우 인원수 기준 표 배정 → 벽 50% 차단 시 인접 방향으로 재배정.
🗺️ NavigationFSMState — BT
  • Selector[OR]
    • Sequence — 계단 이동[AND]
      • Condition: HasPendingStairs
      • Leaf: MoveToStairs (비어있는 가장 가까운 계단 접근 타일로)
      • Leaf: CrossStairs (2×2 블록 Chebyshev≤1 → 층 이동)
    • Leaf: RandomExplore (BFS 미탐색 타일 탐색)
HasPendingStairs 판정 순서
  1. pendingStairTargetFloor 있고 현재 층과 다름 → true
  2. currentFloor == 0 → false (웨이브 시작 전 자동 이동 방지)
  3. personalMap에 다음 층 계단 위치가 밝혀짐 → pendingStairTargetFloor 세팅 후 true
RandomExplore 동작
  1. currentExplorationTarget이 아직 미탐색(terrain==0)이면 유지, 아니면 BFS로 새 타깃 탐색
  2. BFS는 personalMap(개인 지도) 기준 — 공유 지도 쓰면 남이 밝힌 곳을 이미 가본 줄 앎
  3. A* 경로 탐색 실패(닿을 수 없음) → 타깃을 벽(2)으로 치부하고 MoveRandomlyValid 폴백
  4. MoveRandomlyValid: 8방향 중 이동 가능한 첫 방향으로 이동
  • BFS 최대 탐색 노드: 30,000 (맵 횡단 가능)
  • 탐색 완료(미탐색 타일 없음)시에도 MoveRandomlyValid로 폴백 — 영구 정지 없음.
BTStatus 반환값 의미
값Sequence 해석Selector 해석대표 사용
Success 다음 자식으로 진행 즉시 Success 반환 (이 자식 성공) 조건 충족, 행동 완료
Failure 즉시 Failure 반환 (중단) 다음 자식으로 진행 조건 불충족, 수행 불가
Running 즉시 Running 반환 (대기) 즉시 Running 반환 (대기) 이동 중, 타이머 진행 중
