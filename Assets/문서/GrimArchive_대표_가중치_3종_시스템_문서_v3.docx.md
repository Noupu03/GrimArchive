# **GrimArchive 대표 가중치 3종 시스템 문서 v3**

작성 기준: 이해도 / 위험도 / 흥미도 시스템 정리본

# **1\. 문서 목적**

본 문서는 GrimArchive의 인류 AI 판단에 사용되는 대표 가중치 3종인 이해도, 위험도, 흥미도의 정의, 적용 대상, 갱신 구조, 정보 반영 방식, 게임 내 사용 범위를 정리한다.

대표 가중치 3종은 인류 유닛이 던전 내 대상과 위치를 판단하는 기준값이다.

이 값들은 디펜스 도중 유닛별로 획득되며, 각 유닛은 자신이 획득한 정보를 개인 판단에 즉시 반영한다.   
지도 기록과 도감 기록에는 살아나간 유닛의 정보만 반영되며, 해당 정보는 다음 웨이브의 인류 판단에 적용된다.

# **2\. 대표 가중치 3종 개요**

| 가중치 | 범위 | 핵심 의미 | 주요 적용 대상 |
| :---- | :---- | :---- | :---- |
| 이해도 | 0\~100 | 대상의 정보와 대응법을 얼마나 파악했는가 | 유닛, 전투 관련 오브젝트, 함정, 방어건물 |
| 위험도 | 0\~999 | 대상이나 위치가 인류에게 얼마나 위협적으로 인식되는가 | 던전, 방, 유닛, 타일, 전투 관련 오브젝트 |
| 흥미도 | 0\~999 | 대상이나 위치가 조사·회수·탐사 대상으로 얼마나 가치 있게 인식되는가 | 던전, 방, 타일, 비전투 오브젝트, 특정 유닛, 시체, 흔적 |

위험도와 흥미도는 모두 경로와 목표 판단에 사용될 수 있으나, 최종 해석은 파티 종류, 파티 목적, 현재 체력/정신력 상태, 리더 판단에 따라 달라진다.

# **3\. 공통 수치 규칙**

## **3-1. 수치 범위**

개별 대상 단위의 위험도와 흥미도는 0\~999 범위 안에서 관리한다.  
다만 던전 전체 위험도, 던전 전체 흥미도, 방 위험도, 방 흥미도는 여러 대상의 합산값이므로 999를 초과할 수 있다. 

| 가중치 | 최소값 | 최대값 |
| :---- | :---- | :---- |
| 이해도 | 0 | 100 |
| 위험도 | 0 | 999 |
| 흥미도 | 0 | 999 |

## **3-2. 가중치 최종 판단값 처리**

대표 가중치의 최종 판단값은 정해진 범위를 넘지 않도록 처리한다.

예시: 최소 0 최대 100일때

| 현재 이해도 95이해도 증가량 \+10계산 결과 105최종 이해도 100 |
| :---- |

# **4\. 이해도 시스템**

## **4-1. 정의**

이해도는 인류가 특정 유닛 또는 전투 관련 오브젝트의 정보와 대응법을 얼마나 파악했는지를 나타내는 학습값이다.

이해도는 다음 정보와 연결된다.

* 대상의 외형 이미지 (도감)  
* 대상 설명, 묘사 (도감)  
* 대상의 근접/원거리 포지션 (포지션에 따른 공격 방식 변경)  
* 대상의 내부 추정 정보

(미표기 내부 정보는 도감에 직접 표시하지 않지만, 인류 AI의 타겟 판단, 카운터 판단, 전투 대응 판단에 사용된다.)

* 함정 또는 방어건물의 해제/무시 방법 (성공률)

## **4-2. 적용 대상**

이해도는 타일에 부여하지 않는다.

이해도 적용 대상은 다음과 같다.

* 유닛  
* 전투 관련 오브젝트 (함정, 방어건물 등)  
* 특정 공격 타입

## **4-3. 일반 유닛 이해도**

일반 유닛은 종별 이해도만 사용한다.

| 일반 유닛 이해도 \= 종별 이해도 0\~100 |
| :---- |

모든 종별 이해도는 0에서 시작한다. 인류가 해당 종에 대한 이해도 증가 조건을 충족할 때마다 증가한다.

## **4-4. 특수 유닛 이해도**

보스, 네메시스 등 특수 유닛은 종별 이해도와 개별 이해도를 함께 사용한다.

특수 유닛의 개별 이해도는 일반 유닛보다 개체 단위 정보의 비중이 높다.

종별 / 개별 이해도 합산 비율은 대표 가중치 연산공식 문서 7-1장에서 작성한다. 

## **4-5. 이해도와 도감 기록, 미표기 정보**

이해도는 도감 정보의 공개 범위와 정보 오차 범위에 영향을 준다.

흐름은 다음과 같다.

| 이해도 증가 ↓ 도감 내 묘사 텍스트 증가 ↓ 만났을 때의 상황 기록 추가 ↓ 사망 원인, 생존자 증언, 흔적 해석 추가 ↓ 네메시스/주요 인물은 서사적 기록 추가 ↓미표기 내부 정보 오차 범위 감소↓미표기 내부 정보를 타겟 공식, 카운터 판단에서 참조 |
| :---- |

도감은 스테이터스와 스킬을 직접 표시하지 않는다.

도감은 인류가 남긴 야전기록 형식으로 구성하며, 이해도에 따라 묘사, 증언, 상황 기록, 흔적 해석, 서사 기록이 추가되는 방식으로 확장된다. 

도감의 단계별 공개 범위, 기록 텍스트, UI 표시 방식은 도감 문서에서 작성한다. 

도감 데이터 테이블에는 다음 항목을 둔다. 

* 유닛 일러스트  
* 단계별 기록 텍스트

미표기 정보는 도감 화면에 직접 표시되지 않지만, 인류 AI 판단과 카운터 판단에 내부적으로 사용되는 정보이다.

미표기 정보에는 다음 항목이 포함된다. 

| \- 근접/원거리 유형 내부 태그 \- 스테이터스 내부 추정값 \- 약점 태그 \- 대응 장비 태그 \- 대응 스킬 태그  |
| :---- |

이해도가 오를수록 기록 텍스트 안에서 공격 방식, 대응 경험, 약점 추정, 생존자 증언의 형태로 간접적으로 드러난다. 

## **4-6. 이해도 영향**

이해도는 다음에 영향을 준다.

| 구분 | 영향 |
| :---- | :---- |
| 도감 | 기록 텍스트 확장, 묘사 정밀화, 생존자 증언 추가, 네메시스/주요 인물 서사 기록 추가  |
| 전투 대응 | 방어 수단 선택 정확도, 함정 해제/무시 가능성, 내부 태그 기반 대응 판단  |
| 장비/클래스 | 미표기 내부 정보를 바탕으로 카운터 장비, 카운터 클래스 등장 가능성 증가 |
| 반응 | 특정 대상에 대한 반응 시간 보정 가능 |
| 타겟 판단 | 도감에 직접 표시되지 않는 내부 정보를 통해 타겟 공식에 간접 반영  |

타겟 우선순위 공식은 별도 타겟 변경 문서에서 작성한다.

## **4-7. 이해도 증가 조건**

| 정보 유형 | 조건 |
| :---- | :---- |
| 직접 피격 | 해당 공격을 직접 맞음 |
| 직접 목격 | 공격, 사망 원인, 상태이상 발생 등을 직접 봄 |
| 간접 파악 | 전파, 소리, 상호작용 목격 등을 통해 원인을 추정 |
| 상호작용 | 함정 해제 성공, 방어건물 해제 성공 |

상태이상 경험, 소환/버프/디버프 목격은 이해도 증가 조건에 포함할 수 있으나 증가량은 낮게 둔다.

## **4-8. 사망 원인과 이해도**

사망 자체만으로 이해도가 오르지는 않는다. 사망 원인을 확인했을 때 이해도가 증가한다.

| 상황 | 처리 |
| :---- | :---- |
| 생존자가 사망 원인대상을 직접 목격(흔적 미목격시 발동 X) | 이해도 증가량 높음 |
| 시체/흔적 조사로 원인대상 추정 | 이해도 증가량 낮음 |

## **4-9. 이해도 감소 및 총량 한도**

이해도는 인류 전체 공통 총량 한도를 가진다.

| 인류 전체 이해도 총량 \= 모든 이해도 수치의 합산 한도 |
| :---- |

이해도 총량이 가득 찬 상태에서 새로운 이해도 증가가 필요하면, 오래된 이해도 일부가 감소한다.

감소 대상 선정 기준은 다음과 같다.

| 1순위: 가장 오랫동안 갱신되지 않은 이해도2순위: 최대치에 도달한 이해도 |
| :---- |

현재 기준은 2웨이브 이상 갱신되지 않은 이해도부터 감소 대상으로 본다.

감소 방식은 다음과 같다.

| 새 이해도 증가량만큼 오래된 이해도를 감소시켜 총량을 유지한다. |
| :---- |

감소 하한은 다음과 같다.

| 한 번 습득한 이해도는 0까지 떨어지지 않는다.현재값의 일정 비율까지만 감소한다.해당 하한까지 감소한 뒤에는 추가 감소하지 않는다. |
| :---- |

# 이해도가 감소한다고 이미 공개된 도감 기록 텍스트가 제거되지는 않는다. 다만 미표기 내부 정보의 오차 범위가 다시 증가하거나, 카운터 판단에 사용하는 내부 정보의 오차가 다시 높아질 수 있다. 세부 감소 방식은 대표 가중치 연산공식 문서 8장에서 작성한다. 

# **5\. 위험도 시스템**

## **5-1. 정의**

위험도는 인류가 특정 대상이나 위치를 얼마나 위협적으로 인식하는지를 나타내는 값이다.

## **5-2. 적용 대상**

위험도 적용 대상은 다음과 같다.

* 던전  
* 방  
* 유닛  
* 타일  
* 전투 관련 오브젝트  
* 함정  
* 방어건물

## **5-3. 위험도 저장 구조**

몬스터, 함정, 방어건물 등 전투 관련 대상의 위험도는 기본 위험도, 종별 누적값, 개별 누적값을 함께 고려한다.

개별 위험도는 해당 개체가 실제 전투에서 남긴 결과에 따라 상승할 수 있다.

정확한 최종 위험도 계산식은 대표 가중치 연산공식 문서 12-1장에서 작성한다. 

## **5-4. 위험도 단계**

위험도는 0\~999 범위를 가지며, 위험도 단계는 다음과 같이 둔다.

동일 단계 개체끼리는 수치로 판단한다.

| 단계 | 범위 |
| :---- | :---- |
| 위험도 단계 0 | 0\~99 |
| 위험도 단계 1 | 100\~299 |
| 위험도 단계 2 | 300\~599 |
| 위험도 단계 3 | 600\~799 |
| 위험도 단계 MAX | 800\~999 |

위험도 단계는 다음 항목에 관여한다.

* 정신력 하락  
* 인류 유닛 Lv과 위험도 단계 차이에 따른 도주 판단  
* 압도적 격차 발생 시 공황/상태이상 가능성

## **5-5. 위험도 단계와 유닛 Lv 관계**

위험도 단계와 인류 유닛 Lv 사이에는 상관 공식이 필요하다.

기본 방향은 다음과 같다.

| 낮은 Lv 유닛이 높은 위험도 단계 대상을 확인하면,공황 상태가 아니어도 도주 확률이 발생할 수 있다. |
| :---- |

위험도 단계와 유닛 Lv 차이가 클수록 도주 확률이 증가한다.   
차이가 클수록 정신력 수치와 무관하게 즉시 공황 상태에 빠지거나 스턴 같은 상태이상이 발생할 수 있다.

| 상황 | 결과 방향 |
| :---- | :---- |
| Lv가 충분한 유닛이 낮은 위험도 단계 대상 확인 | 정신력 영향 낮음 |
| Lv가 낮은 유닛이 높은 위험도 단계 대상 확인 | 도주 확률 발생 |
| Lv 1 유닛이 2\~3챕터 보스급 대상 확인 | 즉시 공황 또는 스턴 가능 |

정확한 공식은 전투 연산 공식 문서에서 작성한다.

## **5-6. 위험도 영향**

위험도는 다음에 영향을 준다.

| 구분 | 영향 |
| :---- | :---- |
| 전투 | 시야 고정, 경계 상태, 방어 우선, 적 주시 |
| 정신력 | 위험도 단계에 따른 정신력 감소 |
| 생존 판단 | 후퇴/도주 판단, 생존 우선 판단 |
| 경로 선정 | 위험 타일 회피, 경로/목표 재평가 |
| 파티 판단 | 파티 종류와 목적에 따른 목표 판단 |
| 디펜스 후 | 웨이브 밸류, 파티 종류 선정, 다음 웨이브 반영 |

## **5-7. 생존 우선 판단**

생존 우선 판단은 일반 전투/탐색 판단보다 높은 예외 처리로 작동한다.

평상시에는 파티 목적이 우선되지만, 다음 조건 중 일부가 임계치에 도달하면 생존 우선 판단이 최상위로 올라간다.

* 현재 HP가 일정 비율 이하로 감소  
* 현재 정신력이 일정 기준 이하로 감소  
* 위험도 단계와 유닛 Lv 차이가 일정 기준 이상  
* 파티 내 사망자 또는 중상자가 발생  
* 위 조건 중 하나 이상 발생한 상태에서 도주 경로 또는 후퇴 경로가 위협받음

생존 우선 판단은 다음 항목에 영향을 준다.

* 후퇴/도주 후보  
* 공격 대상 우선순위 재평가  
* 방어력 증가 스킬 우선 사용  
* 저항 증가 스킬 우선 사용  
* 회복 스킬 우선 사용

정신력 상태가 낮아질 경우, 유닛은 기존 진형을 무시하고 더 안전한 공간으로 개개인이 이동할 수 있다.   
이때 목표 위치는 다음 조건을 우선한다.

| 1\. 적 타겟 우선순위에서 벗어나기 쉬운 위치2\. 방어형 유닛 근처 또는 아군 뒤쪽 위치3\. 위 조건 내에서 위험도가 낮은 타일 |
| :---- |

이 이동은 다른 아군에게 어그로가 옮겨질 수 있도록 하는 위치를 목표로 할 수 있다. 

생존 우선 판단의 세부 수치, 도주 확률, 정신력 감소량, 이동 위치 선정 공식은 전투 연산 또는 파티 이동 문서에서 작성한다.

## **5-8. 위험도 증가 조건**

위험도 증가량은 정보 획득 방식에 따라 차이를 둔다.

기본 우선순위는 다음과 같다.

| 인류 유닛 처치 \> 직접 피격 \> 직접 목격 \> 간접 파악 |
| :---- |

| 조건 | 처리 |
| :---- | :---- |
| 인류 유닛 처치  | 해당 대상이 인류 유닛을 처치 높은 위험도 증가  |
| 직접 피격 | 일정 피해량 이상을 직접 받을 경우 중간 위험도 증가 |
| 직접 목격 | 일정 피해량 이상이 발생한 공격을 직접 볼 경우 낮은 위험도 증가 |
| 간접 파악 | 전파, 소리, 상호작용 목격 등을 통해 낮은 위험도 증가 |
| 소환/버프/디버프 목격 | 별도 중간값으로 처리하되, 증가 가능한 최대 수치 제한 |
| 전멸 흔적 발견 | 전멸 흔적 발견은 일반 위험도 증가와 별도로 처리되며, 전멸 원인 대상의 위험도 단계에 따라 던전 위험도 전역 반영값이 보정될 수 있다.  |

인류 유닛 처치로 인한 위험도 증가는 해당 사건을 목격하거나, 생존자가 사망 원인 또는 흔적을 전달할 수 있을 때 지도/도감 기록에 반영된다.

모든 인류 유닛이 사망하여 정보가 회수되지 못한 경우, 해당 위험도 정보는 다음 웨이브 전역 기록에 반영되지 않으나,

던전의 위험도가 크게 증가한다.   
이 경우 어떤 대상이 위험했는지는 알 수 없으며, 던전 전체에 대한 경계와 웨이브 밸류 상승으로 처리한다. 

위협 범위 자체에는 위험도를 부여하지 않는다.   
위협 범위 안의 유닛은 반응 시스템으로 처리된다.

## **5-9. 위험도 감소 조건**

| 조건 | 처리 |
| :---- | :---- |
| 시야로 확인 후 적 없음(타일) | 해당 타일 위험도 감소 |
| 적 사망/이탈 | 해당 개체의 현재 전투 영향 제거 |
| 함정 해제/소모 | 해당 오브젝트 위험도 감소 |
| 일정 피해량 이하로 처치 | 웨이브 이후 처치한 유닛 위험도 감소 판정 |
| 오차 정보 갱신 | 잘못 기록된 위치나 수치를 새 정보로 갱신 |

일정 피해량 이하로 처치한 경우, 해당 몬스터 종 위험도 감소 판정이 발생한다.

이 판정은 처치 참여 인류 유닛이 해당 대상에게 받은 총 피해량을 기준으로 한다.

세부 기준값과 감소량은 대표 가중치 연산공식 문서 11-1,11-2장에서 작성한다. 

## **5-10. 타일 위험도**

인류 유닛이 탐사하지 못한 모든 타일은 탐사한 타일보다 높은 일정 수치의 위험도를 가진다. (흥미도 \> 위험도)  
미탐사 타일의 기본 위험도와 기본 흥미도는 실제 적이나 오브젝트의 값이 아니라, 인류가 미확인 공간에 부여하는 탐색용 추정값이다.

따라서 해당 값은 방 위험도/방 흥미도 합산에는 포함하지 않고, 이동 경로 선택과 경계 방향 판단에 사용한다. 

적이 있거나 있었던 타일에는 해당 적의 기록 위험도를 기준으로 타일 위험도를 부여한다.

인류 유닛이 해당 타일을 직접 확인하고 위험 요소가 없다고 판단하면, 해당 타일의 위험도는 감소한다.

확인 전까지는 기록된 타일 위험도가 유지된다.

위험도가 부여된 타일을 목격한 인류 유닛이 살아 돌아갈 경우, 해당 정보는 정보 우선순위와 생존자 전역 반영 규칙에 따라 지도 기록에 반영된다.

기록된 타일 위험도는 이후 웨이브에서 인류 측 목표 경로 결정, 경계 방향, 시야 고정에 영향을 준다. 

## **5-11. 위험도 인지 시 재판정**

위험도 인지 시 정신력 영향은 다음 구조로 처리한다.

| 최초 발견 1회 정신력 영향전투 중에는 행동 영향 이후 재판단탐색 중에는 상태 변화 시 재판정 |
| :---- |

탐색 상태 변화 예시:

* 미확인 타일 확인  
* 위험 대상 발견  
* 흥미 오브젝트 발견  
* 목표 오브젝트 사라짐  
* 파티원 피격  
* 경로 차단 확인  
  현재 방 조사 완료

# **6\. 흥미도 시스템**

## **6-1. 정의**

흥미도는 인류가 특정 대상이나 위치를 조사, 회수, 탐사할 가치가 있다고 판단하는 정도이다.

## **6-2. 적용 대상**

흥미도 적용 대상은 다음과 같다.

* 던전  
* 방  
* 타일  
* 비전투 오브젝트  
* 특정 유닛  
* 시체  
* 흔적

특정 유닛은 인류 입장에서 가치 있는 유닛만 해당한다.   
이는 데이터 테이블의 IsInterestTarget 플래그로 지정한다.

가치 높은 특정 유닛 예시:

* 보스  
* 네메시스  
* 희귀 유닛  
* 퀘스트/목표 대상 유닛  
* 특수 자원, 시체, 흔적을 남기는 유닛

## **6-3. 흥미도 기본값**

흥미도 기본값은 오브젝트 데이터에 직접 입력한다.

오브젝트 기본 흥미도는 등급별 권장 범위를 둘 수 있다.

| 등급 | 권장 흥미도 범위 |
| :---- | :---- |
| 낮은 관심 대상 | 1\~99 |
| 일반 오브젝트 | 100\~299 |
| 중요 오브젝트 | 300\~599 |
| 고가치 오브젝트 | 600\~799 |
| 핵심 오브젝트 | 800\~999 |

수치는 예시이며, 레벨디자인 과정에서 조정한다.

## **6-4. 타일 흥미도 구조**

인류 유닛이 탐사하지 못한 모든 타일은 탐사한 타일보다 높은 일정 수치의 흥미도를 가진다. (흥미도 \> 위험도)  
추가로 타일은 현재 타일 위에 있는 오브젝트의 흥미도 값을 가져온다.

| 오브젝트 흥미도 \= 오브젝트 데이터의 기본값타일 흥미도는 기본 탐사 흥미도와 오브젝트 흥미도를 구분한다. 타일 최종 흥미도 \= 타일 기본 탐사 흥미도 \+ 현재 타일 위 오브젝트 흥미도 단, 최종 흥미도는 0\~999 범위를 넘지 않도록 제한한다.  |
| :---- |

서로 다른 오브젝트는 같은 타일에 존재할 수 없다.

오브젝트가 이동하면 다음처럼 처리된다.

| 기존 타일: 오브젝트 흥미도 값 상실이동 후 타일: 오브젝트 흥미도 값 획득 |
| :---- |

##  **6-5. 실제값과 기록값 차이**

플레이어가 오브젝트 위치를 옮겼는데 인류가 이를 모르고 있다면, 인류는 이전 기록값을 기준으로 경로와 행동을 판단한다.

| 실제값:오브젝트가 A 타일에서 B 타일로 이동인류 기록값:오브젝트가 A 타일에 있다고 기록인류 행동:A 타일 기준으로 경로 설정 및 조사 시도 |
| :---- |

반복적인 위치 변경으로 실제값과 기록값 불일치가 누적될 경우, 오차 범위와 기록 수치 변화로 표현한다.   
오브젝트 이동 악용 방지와 관련된 비용 구조는 후속 운영/지도 기록 문서에서 다룬다.

## **6-6. 흥미도 감소 조건**

| 조건 | 처리 |
| :---- | :---- |
| 조사 완료 | 흥미도 감소 |
| 회수 완료 | 해당 타일의 오브젝트 흥미도 제거, 오브젝트는 인류 유닛이 운반 상태로 전환  |
| 오브젝트 파괴/소모 | 흥미도 0 |
| 도감 공개 단계 도달 | 일반 유닛 흥미도 감소 가능 |

조사 또는 회수 완료 후에도 기록과 실제값이 달라진 경우 예외가 발생할 수 있다.

| 시야 내 기록과 다른 흥미도 오브젝트 발견↓해당 타일 흥미도는 오브젝트 흥미도와 동일하게 상승 |
| :---- |

회수 중 유닛이 사망해 오브젝트를 떨어뜨린 경우:

| 회수 중 유닛 사망↓오브젝트가 타일에 드랍↓해당 타일 흥미도 복구 |
| :---- |

## **6-7. 유닛 흥미도와 이해도 관계**

일반 유닛의 흥미도는 이해도 상승과 도감 정보 축적에 따라 감소할 수 있다.

도감 정보가 채워질수록 일반 유닛의 탐사 가치는 감소한다.

일반 유닛 흥미도의 정확한 감소식은 대표 가중치 연산공식 문서 18장에서 작성한다.

도감 공개 단계와 UI 표시 조건은 도감 문서에서 작성한다.

IsInterestTarget \= true인 유닛은 이해도가 높아져도 흥미도를 유지하거나, 별도 감소식을 사용할 수 있다.

## **6-8. 시체/흔적 흥미도**

시체와 흔적도 흥미도 값을 가진다.

시체/흔적의 흥미도 상한은 종류별로 다르게 둔다.

강한 유닛이나 강한 공격에 의해 발생한 사망일수록, 인류가 우선 확인하도록 시체/흔적의 흥미도를 높게 설정한다.

시체/흔적 조사 시 다음 두 가지 처리가 발생한다.

| 시체/흔적 자체 흥미도 감소\+ 원인 대상 가중치 갱신 트리거 (이해도, 위험도) |
| :---- |

시체/흔적의 정확한 기본 흥미도와 위험도 단계 보정값은 대표 가중치 연산공식 문서 19장에서 작성한다. 

# **7\. 방 위험도 / 방 흥미도**

## **7-1. 방 정보 갱신**

인류가 방에 들어가면, 시야로 확인한 정보를 통해 방 내부 위험도와 흥미도 추정값이 실시간으로 반영된다.

방 전체 값을 자동으로 아는 것이 아니라, 시야에 들어온 유닛과 오브젝트만 방 위험도·흥미도 추정값에 반영한다.

## **7-2. 방 위험도/흥미도 계산**

방 위험도는 방 내부에서 인류가 파악한 유닛과 전투 오브젝트의 위험도 합산값이다.   
방 위험도는 999를 초과할 수 있다.

미탐사 방은 인류 유닛이 문 또는 출입구를 통해 방의 존재를 확인했지만,

아직 방 내부를 탐사하지 않은 방이다.

미탐사 방 확인 조건은 인류 유닛이 미탐사 방으로 이어지는 문 또는 출입구를 시야로 확인하는 것이다.

탐사 진행 중인 방은 인류 유닛이 방 내부에 진입했지만,

방 내 모든 타일이 확인되지 않은 방이다.

방 내 모든 타일이 확인되면 탐사 완료 방으로 처리한다. 

## **7-3. 타일 위험도 / 타일 흥미도 역할** 

타일 위험도와 타일 흥미도는 방 총합에는 포함하지 않는다.

* 타일 위험도 \= 이동 경로, 경계 방향, 시야 고정

* 타일 흥미도 \= 탐색 방향, 조사 후보, 미확인 구역 접근 판단

**8\. 정보 입력 경로**

## **8-1. 직접 정보**

직접 정보는 인류 유닛이 직접 확인한 정보이다.

예시:

* 직접 피격  
* 직접 목격  
* 직접 조사  
* 직접 상호작용

직접 정보는 타일, 대상, 수치로 기록된다.

## **8-2. 간접 파악**

간접 파악은 인류 유닛이 직접 본 것이 아니라, 다른 매개를 통해 추정한 정보이다.

예시:

* 전파  
* 소리  
* 상호작용 목격

소리는 간접 파악 입력 중 하나로 다룬다.   
소리 발생 조건, 소리 범위, 소리를 들은 유닛의 반응은 별도 소리/전파 문서에서 작성한다.

## **8-3. 기억 정보**

기억은 생존하여 돌아간 유닛이 다시 던전에 들어오는 경우에 사용한다.

재입장 전, 인류는 지도 기록과 개인 기억을 합친다. 이때 지도보다 개인 기록 위주의 정보로 저장한다.

세부 구조는 지도 기록/저장 문서와 기억/네메시스 문서에서 나누어 작성한다.

## **8-4. 정보 충돌 처리**

정보 충돌이 발생하면 더 직접적이고, 더 최신인 정보를 우선한다.

직접 경험 정보는 직접 목격 정보보다 우선하고,

직접 목격 정보는 간접 파악 정보보다 우선한다.

정확한 우선순위 단계와 갱신 기준은 대표 가중치 연산공식 문서 24장에서 작성한다. 

# **9\. 정보 오차 규칙**

## **9-1. 오차 종류**

정보 오차는 다음 두 가지로 처리한다.

| 오차 종류 | 의미 |
| :---- | :---- |
| 위치 오차 | 실제 위치와 다른 위치 또는 주변 타일에 기록 |
| 수치 오차 | 실제 가중치보다 높거나 낮게 기록 |

## **9-2. 정신력 저하 상태 유닛의 정보 오차 (공포 / 공황 단계)**

정신력 저하 상태 유닛은 새 정보나 갱신 정보에 오차가 발생한다.

| 정신력 저하 상태 유닛:\- 위치 오차 발생 가능\- 수치 오차 발생 가능\- 증가량 자체는 감소하지 않음 |
| :---- |

# **10\. 정보 갱신 및 전역 반영**

전역 반영 시에는 EventID와 IncidentID를 구분한다.

EventID: 대표 가중치 연산공식 문서의 이벤트 종류 ID  
IncidentID: 실제로 발생한 사건 고유 ID

같은 사건에서 직접 목격 정보와 간접 파악 정보가 함께 발생할 수 있으므로,  
전역 반영은 동일 IncidentID 기준으로 묶고,  
정보 유형별 대표 변화량을 산출한 뒤 비율값을 적용한다. 

## **10-1. 유닛 개별 정보 획득**

디펜스 도중 각 유닛이 획득하는 이해도, 위험도, 흥미도 정보량은 다르다.

유닛이 획득한 가중치 정보는 해당 유닛의 개인 판단에 즉시 반영된다.

| 유닛 A가 직접 피격↓유닛 A의 개인 위험도/이해도 정보 갱신↓유닛 A의 반응, 목표 재평가, 생존 판단에 즉시 반영 |
| :---- |

파티 공유는 즉시 자동 적용하지 않는다.   
파티 공유는 전파/명령 문서에서 별도로 처리한다.

## **10-2. 지도/도감 전역 반영**

지도와 도감에는 살아나간 유닛이 가지고 있는 정보만 반영된다.

| 개별 유닛 정보 획득↓디펜스 종료 또는 웨이브 종료↓생존/후퇴/도주 성공 유닛 정보 회수↓지도 기록 및 도감 기록 반영↓다음 웨이브 인류 판단에 적용 |
| :---- |

## **10-3. 갱신 타이밍**

가중치 갱신은 다음 시점에 발생한다.

* 전투 이벤트 발생  
* 탐색 정보 획득  
* 오브젝트 조사  
* 오브젝트 회수  
* 시체/흔적 조사  
* 전파 수신  
* 소리 감지  
* 웨이브 종료

구조:

| 유닛 개인 판단에는 이벤트 즉시 반영지도/도감 기록에는 생존 유닛 정보 기반으로 웨이브 종료 후 반영 |
| :---- |

## **10-4. 정보 유형별 이벤트 변화량** 

개별 유닛이 같은 사건을 인식하더라도 정보 유형에 따라 기록되는 변화량은 달라진다. 

| 실제 변화량은 대표 가중치 연산공식 문서의 3장 이벤트 변화량 표에 작성된 값을 사용한다. |
| :---- |

## **10-5. 다수 생존자 전역 반영**

같은 IncidentID에 대해 생존자가 2명 이상 정보를 가져온 경우,

전역 반영은 정보 유형별 공식을 적용해 계산한다.

직접 경험 정보가 가장 크게 반영되고,

직접 목격 정보가 그다음,

간접 파악 정보가 가장 낮은 비중으로 반영된다.

정확한 비율값, 중복 제거 기준, 전역 반영량 계산식은 대표 가중치 연산공식 문서 6-1\~6-4장에서 작성한다.
